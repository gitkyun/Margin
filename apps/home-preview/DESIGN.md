# Margin 디자인 기준

2026-11-03 · 승인한 워킹 목업 계획 적용

## 기준과 범위

Wanted 참고자료의 색상·글꼴 위계·모서리·절제된 표면을 Margin에 맞게 변형한다. 첨부된 48장과 영상의 관찰·채택 범위는 [참고자료 적용표](../../docs/design/reference-application.md)에 기록한다. 참고 서비스의 기능 존재와 Margin 사용성 검증은 구분한다. 기존 `wanted.md` 원본은 수정하지 않는다.

## 토큰

| 항목 | 구현 값 |
|---|---|
| 한글 | Pretendard Variable, 자체 호스팅 |
| 제목 | 페이지 28px, 구역 18~20px |
| 본문 | UI 14~15px, 긴 기록 16px, 보조 12~13px |
| 라이트 | 바탕 #F7F8FA, 표면 #FFFFFF, 본문 #20232A, 보조 #646B78 |
| 다크 | 바탕 #121416, 표면 #1B1D21, 본문 #EDEDEF, 보조 #9A9FAA |
| 주 행동 | 라이트 #0066FF, 다크 버튼 #286BE8, 흰 글자 |
| 모서리 | 입력·버튼 10px, 카드 16px, 대화상자 20px |
| 배치 | 사이드바 236px, 상단 70px, 데스크톱 본문 여백 36px |
| 표면 효과 | 읽기·편집·PDF는 불투명, 상단·메뉴에만 제한된 반투명 |
| 전환 | 120~200ms, 동작 감소 설정에서 최소화 |

글꼴은 서비스의 한글 가독성을 위해 Wanted Sans 대신 Pretendard를 기본으로 채택했다. 두 테마는 같은 데이터·위계·기능을 사용한다. 시스템 설정이 기본이며 계정 설정 → 화면에서만 변경한다.

## 구성

- 홈은 다음 미팅과 준비 작업을 크게, 교수 응답과 질문·자료를 보조 영역에 배치한다.
- 목록은 제목·상태·기한·출처를 행 단위로 읽는다. 장식용 분석 차트나 연구 완성도 점수를 만들지 않는다.
- 미팅 원문은 넓게 읽는다. AI는 사용자가 요청할 때 옆에 열고, 실행 대상과 제안·가정을 명시한다.
- 검토는 항목·차수·설명·파일·응답을 함께 읽는다. 좁은 화면에서는 자료와 응답 영역을 전환한다.
- 원문을 읽거나 PDF를 볼 때 장식 배경을 사용하지 않는다. PDF 자체는 다크에서도 원래 색을 유지한다.
- 로딩은 실제 목록·본문 배치를 유지하는 스켈레톤, AI 처리에는 작은 도트와 상태 문구를 쓴다. AI 퍼센트는 표시하지 않는다.

## 구성요소와 출처

shadcn/ui와 Radix를 버튼·폼·메뉴·대화상자·시트의 출발점으로 사용했다. 도메인 화면·PDF·스냅샷·차수·업로드 재연결은 Margin 코드로 구현했다. 아이콘은 Disarto 일반형을 기본으로 하고 공통 UI 내부의 일부 상태 아이콘은 shadcn 원형을 유지한다. [사용 고지](THIRD_PARTY_NOTICES.md)를 따른다.

승인한 디자인 기준은 구현 지침이다. 사용성 검증 통과나 실제 교수 사용 경험을 의미하지 않는다. 실제 확인 결과는 [design-qa.md](design-qa.md)에 남긴다.

## 2026-11-04 확장: 진입과 플로팅 탐색

사용자의 신규 피드백으로 기존 Wanted 기반의 중립색·Pretendard·파란 주 행동을 유지하면서 탐색 표면을 확장했다. 원본 파일을 대체하지 않고 이 절에 변경 이유를 남긴다.

- 소개의 페이지 제목 44~66px, 섹션 제목 31~43px. 작업 화면 제목 26~28px 유지.
- 라이트 바탕 #EFF1F5, 본문 #242B38, 보조 #5C6472. 다크 바탕 #101215, 본문 #ECEEF3, 보조 #A6ADBA.
- 탐색 레일 기본 238px(좁은 데스크톱 216px), 접힘 66px, 바깥 여백 14px. 탐색·본문 프레임 20px, 읽기 구역 16px.
- 글라스는 blur 24px/saturate 1.25의 서리 표면과 얇은 테두리. 본문·입력·PDF는 불투명. 광학 굴절은 채택하지 않음.
- 새 주 버튼 48px, 작업 버튼 40px, 모바일 보조 버튼 최소 42px. 기존 모든 터치 대상의 44px 검증 완료를 뜻하지 않음.
- Motion reducedMotion=user. 소개 도트는 화면 밖에서 멈추고 동작 감소에서는 정지.
- 버튼·입력·텍스트 영역은 자체 RMS CSS로 변경. 기존 Radix의 접근 동작을 유지하며 다른 남은 래퍼는 단계적으로 정리한다.

페이지·상태·참고자료별 판단은 [개편 설계](../../docs/design/experience-revision-20261104.md)에 기록했다. 기존 검토 보고서의 미해결 항목을 디자인 완료로 숨기지 않는다.

## 2026-11-05 우선 적용 값

이 절은 위의 과거 표면 효과보다 우선한다. 로그인 후 사이드바·본문·메뉴는 불투명하다. LiquidGlass는 소개 헤더에만 적용한다. 계정 메뉴에는 화면 설정으로 이동하는 행동만 둔다.

- 다크: 캔버스 #141517, 사이드바 #1B1C1F, 표면 #202124, 입력/보조 #2A2C30, 경계 #393B40, 본문 #F1F2F4, 보조 #B1B5BD. 주 버튼 #286DE8, 링크/선택 #83B1FF.
- 선택자 최소 42px, 터치 조건 44px. 상태 배지와 누르는 필터를 구별한다. RMS 글자 두께 600.
- 홈은 현재 단계 → 다음 미팅(결과/작업/질문) → 확인할 내용 → 작업/문서/활동 순서다. 집계는 실제 기록을 사용한다.
- 구현 스타일은 `src/expansion.css`를 기존 스타일 뒤에서 적용한다. 폴더·글쓰기·달력은 기능별 파일과 함께 유지한다.
- [실제 효과·라이브러리 적용](../../docs/design/implementation-map-20261105.md), [검증 범위](../../docs/development/verification-20261105.md)를 따른다.

## 2026-11-06 Margin 브랜드 적용 — 최신 기준

서비스의 사용자 노출 이름은 Margin이다. `src/components/brand/Brand.tsx`의 제공 SVG 심벌·워드마크와 16종 캐릭터 매핑을 사용한다. `brand.css`를 마지막에 불러오며 라이트/다크는 원본 파랑/흰색 자산으로 전환한다. 기존 Wanted 기반 글꼴·본문 위계·파란 행동 색과 구름·도트 푸터 구성은 유지한다.

연구 도우미는 홈 진입, 대화 시작, 실제 작업 진행, 후보 검토, 저장 완료, 중단·오류에 사용한다. 캐릭터는 장식이며 상태 문구를 함께 제공한다. 교수 확인이나 연구의 정확성을 캐릭터 표정으로 판정하지 않는다. 검토 깊이는 서버가 허용한 모델 값에만 연결한다. 배경이 포함된 PNG를 투명 이미지처럼 합성하지 않는다.

실제 적용 위치와 원본·검증 경계는 [Margin 적용 기록](../../docs/design/margin-brand-20261106.md)에 정리했다. 배포는 계속 보류한다.
