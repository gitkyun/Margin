# RMS 디자인 기준

2026-11-03 · 승인한 워킹 목업 계획 적용

## 기준과 범위

Wanted 참고자료의 색상·글꼴 위계·모서리·절제된 표면을 RMS에 맞게 변형한다. 첨부된 48장과 영상의 관찰·채택 범위는 [참고자료 적용표](../../docs/design/reference-application.md)에 기록한다. 참고 서비스의 기능 존재와 RMS 사용성 검증은 구분한다. 기존 `wanted.md` 원본은 수정하지 않는다.

## 토큰

| 항목 | 구현 값 |
|---|---|
| 한글 | Pretendard Variable, 자체 호스팅 |
| 제목 | 페이지 28px, 구역 18~20px |
| 본문 | UI 14~15px, 긴 기록 16px, 보조 12~13px |
| 라이트 | 바탕 #F7F8FA, 표면 #FFFFFF, 본문 #20232A, 보조 #646B78 |
| 다크 | 바탕 #121416, 표면 #1B1D21, 본문 #EDEDEF, 보조 #9A9FAA |
| 주 행동 | 라이트 #0066FF, 다크 버튼 #286BE8, 흰 글자 |
| 모서리 | 입력·버튼 10px, 카드 16px, 대화상자 20px |
| 배치 | 사이드바 236px, 상단 70px, 데스크톱 본문 여백 36px |
| 표면 효과 | 읽기·편집·PDF는 불투명, 상단·메뉴에만 제한된 반투명 |
| 전환 | 120~200ms, 동작 감소 설정에서 최소화 |

글꼴은 서비스의 한글 가독성을 위해 Wanted Sans 대신 Pretendard를 기본으로 채택했다. 두 테마는 같은 데이터·위계·기능을 사용한다. 시스템 설정이 기본이며 계정 메뉴에서 변경한다.

## 구성

- 홈은 다음 미팅과 준비 작업을 크게, 교수 응답과 질문·자료를 보조 영역에 배치한다.
- 목록은 제목·상태·기한·출처를 행 단위로 읽는다. 장식용 분석 차트나 연구 완성도 점수를 만들지 않는다.
- 미팅 원문은 넓게 읽는다. AI는 사용자가 요청할 때 옆에 열고, 실행 대상과 제안·가정을 명시한다.
- 검토는 항목·차수·설명·파일·응답을 함께 읽는다. 좁은 화면에서는 자료와 응답 영역을 전환한다.
- 원문을 읽거나 PDF를 볼 때 장식 배경을 사용하지 않는다. PDF 자체는 다크에서도 원래 색을 유지한다.
- 로딩은 실제 목록·본문 배치를 유지하는 스켈레톤, AI 처리에는 작은 도트와 상태 문구를 쓴다. AI 퍼센트는 표시하지 않는다.

## 구성요소와 출처

shadcn/ui와 Radix를 버튼·폼·메뉴·대화상자·시트의 출발점으로 사용했다. 도메인 화면·PDF·스냅샷·차수·업로드 재연결은 RMS 코드로 구현했다. 아이콘은 Disarto 일반형을 기본으로 하고 공통 UI 내부의 일부 상태 아이콘은 shadcn 원형을 유지한다. [사용 고지](THIRD_PARTY_NOTICES.md)를 따른다.

승인한 디자인 기준은 구현 지침이다. 사용성 검증 통과나 실제 교수 사용 경험을 의미하지 않는다. 실제 확인 결과는 [design-qa.md](design-qa.md)에 남긴다.
