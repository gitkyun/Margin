# 구조와 권한

브라우저 React 앱 → Supabase Auth 및 권한 검사 RPC → DB/비공개 Storage. AI는 인증된 Edge Function에서 Gemini를 호출합니다. API 키는 브라우저에 전달하지 않습니다.

연구 소유자와 활성 공동 편집자는 공동 기록을 편집합니다. 개인 메모·AI 대화·미채택 후보는 작성자만 봅니다. 교수는 지정된 검토와 일정 응답만 접근합니다. 화면에서 숨기는 것으로 권한 검사를 대신하지 않습니다.

자료는 등록 메타데이터와 변경 불가 보존 버전을 분리합니다. 외부 링크는 당시 내용 보존을 보장하지 않습니다. 검토는 당시 설명·파일·항목별 차수를 보존하고 재확인은 새 차수로 기록합니다.

작업 완료·반영 기록·교수 응답·댓글 해결·읽음은 독립적입니다. 공동 문서 저장은 버전 충돌을 검사합니다. AI 제안 채택은 실행 영수증으로 중복 적용을 방지합니다.

보관은 기존 검토 접근을 유지합니다. 휴지통은 외부 접근을 중지하며 복원해도 공유를 자동 재개하지 않습니다. 완전 삭제는 소유자·휴지통·이름 확인 후 DB 삭제 작업과 파일 정리를 재시도 가능한 작업으로 처리합니다.

적용된 DB 이력은 실제 서버 버전과 일치합니다. 기존 SQL은 수정하지 말고 추가 마이그레이션으로 변경합니다. 인증 정책·서버 비밀값·클라우드 계정 설정은 관리자가 소유합니다.
