# UI 기준과 참고자료

## 사용할 자료

| 자료 | 역할 | 출처 |
|---|---|---|
| shadcn/ui | 재사용할 UI 컴포넌트의 구조·상태·접근 동작 | [공식 문서](https://ui.shadcn.com/docs) |
| GetDesign의 Wanted 페이지 | 색상·간격·글자·표면·상태 표현의 시각적 참고 | [지정 참고 페이지](https://www.getdesign.kr/services/wanted) |

2026-11-02에 자료를 확인했다. GetDesign 페이지는 원티드의 공식 배포본이 아니라고 명시한다. RMS의 시각 기준을 정하는 참고자료로 사용하고 원티드 공식 제품·디자인 시스템을 제공하는 것으로 표현하지 않는다.

## RMS에 적용할 방향

- 2026-11-04 사용자 요청에 따라 새 화면은 RMS 자체 스타일로 구현한다. 버튼·입력·텍스트 영역은 직접 구성하고, 기존 Radix 기반 메뉴·대화상자의 키보드·포커스 동작을 유지한다. shadcn을 필수 기준으로 삼지 않는다.
- Wanted 참고의 파란 강조색, 중립색 중심 표면, 타이포그래피 위계, 얇은 경계선과 절제된 그림자를 출발점으로 삼는다. 세부 값은 앱 테마를 만들 때 기록한다.
- 색상·간격·글자·라운드는 공통 토큰으로 정의한다. 화면마다 다른 값을 반복 지정하지 않는다.
- 상태는 색상과 문구를 함께 쓴다. 포커스와 오류 안내를 유지한다.
- AI 영역은 필요할 때 열고 원문·제안을 비교할 수 있게 한다. 문서와 자료를 읽을 공간을 확보한다.
- 채용 카드·보상금·브랜드 로고 등 참고 서비스 고유 내용은 RMS에 옮기지 않는다.

## 화면 구성 기준

[IA·화면 목록](../product/information-architecture.md)의 학생 메뉴·교수 검토 구조·화면ID·보조 영역을 기준으로 배치한다. 화면ID마다 새 페이지를 만들지 않고 목록·상세와 편집 영역을 재사용한다. 메뉴 이름·탭·경로는 작성 기준안이며 시연 필수·선택 구현·후속 범위를 구분한다.

## 설계할 주요 화면

1. 다음 미팅 준비: 보여줄 결과·작업·자료·막힌 이유·질문.
2. 미팅 기록·피드백: 원문 대조·정리·수정 방안 비교.
3. 작업·수정 결과: 진행·처리 설명·보존 파일·확인 위치.
4. 교수 검토: 지정 계정 접근·항목별 결과·댓글·차수.

구체적인 동작은 [기능명세서](../product/functional-specification.md)를 따른다. 이 문서는 UI 구현 방향이며 실제 화면·사용성·접근성 검증 완료를 뜻하지 않는다.
