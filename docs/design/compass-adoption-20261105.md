# Compass 적용 판단 · 2026-11-05

## 확인한 범위

사용자가 지정한 [컴포넌트 갤러리](https://compass.designcompass.org/components), [레지스트리 안내](https://compass.designcompass.org/docs/registry), 공식 버전 `1.0.14` 레지스트리의 검색·선택자·탭·버튼 소스, [라이선스 정책](https://compass.designcompass.org/license)을 확인했다. 정책 본문은 공식 공개 페이지의 클라이언트 번들에서 확인했다. 로그인하거나 유료 자료를 취득하지 않았다. 갤러리에서 실제 컴포넌트를 클릭한 사용성 검증은 아니다.

Compass도 Radix·React·Tailwind와 Pretendard를 사용한다. RMS의 현재 구성과 공통점이 많다. 전체 레지스트리에는 Next와 전역 토큰 등이 포함되어 있어 설치를 그대로 실행하면 Vite 앱의 스타일과 구성을 크게 바꾸게 된다. 제품 화면 전체를 새 라이브러리로 교체하지 않고 필요한 상호작용을 현재 컴포넌트에 구현했다.

## 실제 적용

| 참고한 요소 | RMS 변경 | 적용 위치 |
|---|---|---|
| SearchField의 돋보기·지우기·입력 복귀 | 공통 검색 필드, 검색어가 있을 때 지우기, 누른 뒤 다시 입력할 수 있도록 포커스 유지 | 연구 검색 대화상자, 긴 선택 목록 검색 |
| 선택자의 여백·오른쪽 선택 표시 | 넓은 내부 여백, 메뉴 제목, 긴 항목 줄바꿈, 일정한 체크 영역, 열린 입력의 테두리·포커스 강조 | 미팅·우선순위·담당자 등 공통 Choice |
| Segmented Tabs의 둥근 선택 표면 | 알약형 필터, 이동하는 선택 배경 유지, 호버 구분, 다크 모드의 밝기·경계 분리 | 미팅 상태·연구 목록·AI 탭 등 Segments |

선택 메뉴는 현재 저장값에서 키보드 이동을 시작한다. 짧은 목록은 방향키·Home·End로 이동하고 Enter로 선택한다. 긴 목록은 입력 위치를 유지하며 방향키로 후보를 이동한다. 결과가 없으면 Enter로 다른 값을 선택하지 않는다. 검색 중 Esc는 검색어를 지우고, 빈 검색에서 Esc를 누르면 닫힌다. 실제 브라우저·스크린리더 검사는 별도다.

버튼의 80% 축소 효과나 전역 폰트·파란색·모서리 토큰은 가져오지 않았다. RMS의 문서 작성 화면에 큰 눌림 효과를 반복하면 조작이 산만해지고, 이미 정한 Wanted 기반 토큰과 충돌하기 때문이다. 연구 화면의 불투명 표면과 기존 데이터·권한·저장 흐름도 유지한다.

## 소스와 이용 조건

Compass 정책은 명시적으로 MIT인 코드와 별도 조건의 자료를 구분한다. 공개 레지스트리에 접근할 수 있다는 사실만으로 모든 파일을 MIT라고 판단하지 않았다. 이번에는 Compass 코드를 배포 소스에 복사하지 않고 검색·선택·탭의 패턴을 RMS의 기존 Radix·Motion·Disarto로 직접 구현했다. Compass 패키지나 Plus 자료를 설치한 것으로 표기하지 않는다. 조사용 원본은 비공개 `.local/compass-review/`에만 두고 전달 ZIP에서 제외한다.

구현: `SearchField.tsx`, `experience.tsx`, `WorkspaceShell.tsx`, `expansion.css`. 자동 행동 검사는 `tests/controls.test.tsx` 다섯 개다. 화면의 최종 간격·대비·포커스 모양은 [최신 검증 기록](../development/verification-20261105.md)의 미완료 항목으로 남긴다.
