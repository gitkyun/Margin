# RMS 진입·탐색·AI 경험 개편

## 기준

주 사용자는 학생이며 교수는 지정된 검토의 협업 상대다. 이번 개편은 기존 기록·파일·검토 차수를 유지하고 서비스 진입과 탐색을 확장한다. 기존 원본 PRD, 첨부 이미지와 참고 문서는 보존한다.

사용자 확정: 소개 화면을 첫 진입으로 제공, 플로팅 사이드바, 절제된 글라스, 로그인·가입·프로필·AI 사용량·AI 대화·연구 설정 설계. 가입은 화면 흐름만 시연하며 실제 계정 생성과 메일 발송은 하지 않는다. Gemini 키는 사용자가 추후 연결한다. 잘못 만든 연구·자료는 보관 후 복원하는 방식을 기본으로 확정했다.

AI 대화는 자유롭게 질문하되 선택한 연구 기록 안에서 답하도록 설계했다. PDF 전체·다른 연구·비공개 전체 기록을 자동 첨부하지 않는다. AI 답변의 연구 기록 자동 반영·교수 자동 전송은 하지 않는다. 대화를 계속 쓰는 행동과 정리 후보를 채택해 피드백/작업을 만드는 행동은 구분한다.

## 시각 구성

- 소개: 간결한 제목과 제품의 실제 흐름을 보여주는 조작 가능한 예시. 가상 사례 표시. 고객 수·성공률·후기·요금 등 확인하지 않은 홍보 수치는 사용하지 않는다.
- 탐색: 첨부된 Disarto 사이드바의 여백·접힘·선택 표시를 참고한다. 업무용 메뉴를 RMS에 복제하지 않는다.
- 글라스: 떠 있는 내비게이션·팝오버의 레이어 구분에 사용. 내용은 읽기 좋은 불투명 표면. 초기 서리 표면을 유지하다가, 사용자 추가 요청으로 LiquidGlass의 WebGL 굴절을 분리된 장식 표면에 적용했다. 실시간 페이지 전체나 연구 내용을 캡처하지 않는다.
- 모션: Motion의 동작 감소 설정, 작은 상태 전환. 도트는 Canvas로 실제 그리며 화면 밖에서는 멈춘다.
- 버튼·입력·텍스트 영역: RMS 자체 CSS. 기존 Radix 메뉴·대화상자의 포커스·키보드 동작 유지. shadcn CLI·추가 템플릿 사용 없음. 남은 기존 래퍼까지 전면 교체한 것은 아니다.

## 추가 기능의 권고 순서 — 미확정

1. 보관함 확장: 보관·복원 기본 정책과 연구 보관은 확정·구현했다. 자료·질문·작업의 연결 관계별 보관 처리는 후속 구현이다. 기존 작업 영구 삭제의 교체, 보존 버전 삭제 조건도 별도로 설계해야 한다.
2. 수정 이어하기: 교수 의견 → 내 작성본 편집 → 바뀐 부분 확인 → 필요한 항목 재확인. 같은 결과로 새 검토 요청을 중복 생성하는 흐름을 줄인다.
3. 검토 초안: 보내기 전 항목 구성을 저장하고 이어 작성. ‘나에게만 보임’과 ‘공유 중’ 분리.
4. 연구 일정: 다음 지도·논문 제출·투고를 한 일정으로 보되 할 일 기한을 자동으로 바꾸지 않는다.
5. 대화 기록: 서버 보관 범위·삭제·AI 처리 동의를 정한 뒤 여러 기기 동기화. 현재 임시 대화를 영구 저장이라고 안내하지 않는다.

많은 메뉴를 먼저 만드는 대신, 이 기능들이 기존 기록과 어떤 상태를 공유하고 어떤 기록을 남기는지부터 정한다.

## LiquidGlass 추가 지정 · 2026-11-04

사용자가 [ybouane/liquidglass](https://github.com/ybouane/liquidglass)를 지정했다. 공식 README와 실제 1.0.3 패키지 소스를 확인했다. 공개 소개 헤더와 데스크톱 사이드바의 배경에만 적용하고, 글자·버튼·검색·입력은 실제 DOM으로 유지한다. 연구 원문·PDF·개인 자료는 캡처 루트 밖에 둔다.

설정: refraction 0.22, blur 0.16, chromatic aberration 0.008, edge highlight 0.16, specular 0.12, Fresnel 0.28, bevel 9px. 드래그·버튼 변형·매 프레임 DOM 캡처 없음. 화면 밖·숨긴 탭·동작 감소에서는 엔진을 해제하고 CSS 서리 표면으로 돌아간다. 라이브러리는 별도 청크로 로드한다. 실제 기기의 성능과 브라우저별 일관성까지 검증한 값은 아니다.

사용자 화면 지적 반영: 연구 미선택 화면의 중복 상단 ‘내 연구’ 링크를 제거했다. 선택한 연구 안에서만 전환기를 보여 주며, 목록 메뉴는 하나다. RMS 로고 글자 굵기는 650으로 낮췄다.
