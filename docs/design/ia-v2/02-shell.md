# 02. 틀(셸)

로그인 후 모든 화면이 공유하는 틀입니다. 상단 줄, 본문 판, 사이드 창, 아이콘 줄, 녹음 줄, 그 위에 뜨는 창을 정합니다. 따로 표시하지 않은 내용은 **[제안]**입니다.

참고한 실측(토스증권 웹, 2026-11-15, 읽기만 함): 상단 줄 52px, 메뉴 항목 36px(안쪽 여백 8/12, 14px 굵게), 본문 판 모서리 12px·바깥 여백 12px, 오른쪽 창 312px + 아이콘 줄 56px, 목록 한 줄 44px, 1280px 이상에서는 창이 본문을 밀고 그보다 좁으면 본문 위에 겹쳐 뜸.

## 1. 배치와 치수

### 1.1 데스크톱(1200px 이상)

```
0        12                                   W-56-p-12   W-56-p     W-56    W
│ 상단 줄 52 ────────────────────────────────────────────────────────────────│
│        ┌───────────── 본문 판 ─────────────┐ 12 ┌── 사이드 창 p ──┐┌ 줄 56 ┐│
│   12   │                                  │    │                ││        ││
│        └──────────────────────────────────┘    └────────────────┘└────────┘│
│                                   아래 여백 12 (녹음 줄이 있으면 그 위로 12)      │
```

| 요소 | 값 | 비고 |
|---|---|---|
| 상단 줄 높이 | 52px | 배치 상수 `--header-height`. 바깥 면 위에 그대로 놓임(자체 배경·선 없음) |
| 바깥 면 | 별칭 `--canvas`가 가리키는 Montage 배경 | 다크는 Montage가 바꿈 |
| 본문 판 | 별칭 `--surface`, 모서리 `--radius-16`, 그림자 `--panel-shadow` | 토스는 12px이지만 `patterns.md`의 "셸 16 · 묶음 12" 단계를 따름. 판 안의 카드는 12 |
| 판 바깥 여백 | `--spacing-12` (왼쪽·아래·사이드 창과의 사이) | 위쪽은 0(상단 줄 바로 아래) |
| 사이드 창 폭 `p` | 기본 312px, 글 편집(W2)·자료 보기(W3)에서는 440px | 312~640px 끌어서 조절 |
| 사이드 창 면 | 본문 판과 같은 면·모서리·그림자 | 테두리 없음(면 + 그림자만) |
| 아이콘 줄 | 56px, 바깥 면 위 | 버튼 40×40, 위에서 `--spacing-8` 간격 |
| 녹음 줄 | 44px, 화면 맨 아래 전체 폭 | 녹음 중·저장 중·저장 실패일 때만 |

본문 판 폭: 창이 닫혀 있으면 `W − 12 − 56`, 열려 있으면 `W − 12 − 12 − p − 56`.

| 창 폭(W) | 사이드 창 닫힘 | 312 열림 | 440 열림 |
|---|---|---|---|
| 1440 | 1372 | 1048 | 920 |
| 1280 | 1212 | 888 | 760 |
| 1200 | 1132 | 808 | 680 |

화면 안의 열을 접을지는 **창 폭이 아니라 본문 판 폭**으로 정합니다(컨테이너 쿼리 `container-type: inline-size`). 기준값은 아래 네 단계뿐이고, 화면 문서는 단계 이름으로만 가리킵니다. 다른 기준값을 새로 만들지 않습니다.

| 판 폭 단계 | 범위 | 어떤 창 폭에서 나오나(계산) |
|---|---|---|
| 좁음 | 680 미만 | 휴대폰 |
| 보통 | 680~879 | 768(판 700), 1280 + 440 창(760), 1200 + 312 창(808) |
| 넓음 | 880~1039 | 1024(956, 창은 겹쳐 뜸), 1280 + 312 창(888), 1440 + 440 창(920) |
| 아주 넓음 | 1040 이상 | 1440 + 312 창(1048), 창을 닫은 1200 이상 |

화면별로 무엇이 접히는지:

| 화면 | 아주 넓음 | 넓음 | 보통 | 좁음 |
|---|---|---|---|---|
| 홈 H1 | 두 열(목록 + 오른쪽 320) | 두 열 | 한 열 | 한 열 |
| 미팅 M1 | 세 열(220 · 남는 폭 · 340) | 목록이 접힌 두 열 | 한 열 + `원문 \| 요약·할 일` 전환 | 같음 |
| 글·자료 목록 W1 | 분류 200 + 목록 + 미리보기 360 | 분류 + 목록 | 분류 + 목록 | 목록만 |
| 글 편집 W2 | 목차 200 + 본문 + 여백 48 | 같음 | 목차 접힘 | 같음 |
| 자료 보기 W3 | 보기 + 정보 열 | 같음 | 정보 열 접힘 | 같음 |
| 연구 흐름 F1 | 단계 카드 가로 | 같음 | 같음 | 세로로 쌓임 |

1024px 태블릿에서 미팅 목록이 접히는 것은 의도입니다(가운데 원문 열을 400px 아래로 줄이지 않기 위해).

판 안쪽: 높이는 `100dvh − 52 − 12`(녹음 줄이 있으면 44를 더 뺌), 안쪽 여백은 `--spacing-24`(좁음은 `--spacing-16`), 열 사이는 선(`--line`) 하나. **여러 열 화면(M1·W1·W2·W3)은 열마다 따로 스크롤하고, 한 열 화면(H1·F1·좁음 단계)은 판 전체가 스크롤합니다.**

### 1.2 폭 구간

| 구간 | 상단 줄 | 사이드 창 | 아이콘 줄 | 메뉴 |
|---|---|---|---|---|
| 1200px 이상 (`lg`) | 전체 | 본문을 밂 | 있음 | 상단 |
| 768~1199px (`sm`~`md`) | 찾기 칸이 992 미만에서 아이콘으로 | **본문 위에 겹쳐 뜸**(아이콘 줄 옆, `--shadow-pop`, 뒤는 옅게 가림). 바깥을 누르거나 Esc로 닫힘 | 있음 | 상단 |
| 767px 이하 | 연구 이름 · 찾기 · 종 · 계정 | 화면 전체를 덮는 시트 | 없음 | 아래 탭 줄(§6) |

지금 코드는 992px(`md`)부터 패널이 본문을 밉니다. 사이드 창 + 아이콘 줄이 368px을 차지하므로 기준을 1200px(`lg`)로 올립니다.

### 1.3 사이드 창 위치 [확정 D2]

설정 › 화면 › 사이드 창 위치에서 '오른쪽'(기본)과 '왼쪽'을 고릅니다. 왼쪽이면 `[아이콘 줄][사이드 창][본문 판]` 순서로 뒤집히고, 그 밖의 규칙은 같습니다. 탭 이동 순서(DOM 순서)도 화면 순서를 따라 바뀝니다. 저장은 계정 설정(`preferences.panelSide`), 휴대폰에서는 적용하지 않습니다.

## 2. 색·글자·모서리

새 값을 만들지 않습니다. 아래는 **역할**이고, 구현할 때 `src/design/tokens.css`의 별칭이 가리키는 Montage 시맨틱 변수를 직접 씁니다.

| 역할 | 별칭(참고) | 쓰는 곳 |
|---|---|---|
| 바깥 면 | `--canvas` | 상단 줄·아이콘 줄 뒤 |
| 판 | `--surface` | 본문 판, 사이드 창 |
| 옅은 채움 | `--surface-muted`, `--hover-fill` | 목록 줄 올림, 칩, 찾기 칸 |
| 고른 줄 | `--selected-fill` | 고른 기록, 켜진 아이콘 |
| 선 | `--line` | 판 안의 열 사이, 표 |
| 글자 3단 | `--text`, `--text-secondary`, `--text-tertiary` | 본문 / 보조 / 날짜·수 |
| 강조 | `--brand` | 주 버튼, 켜진 아이콘, 형광펜 아님 |
| 상태 | `--success`, `--warning`, `--danger` | 의미는 `patterns.md` 그대로 |

| 글자 | Montage 토큰 | 크기/굵기 | 쓰는 곳 |
|---|---|---|---|
| 목록 본문 | `label2` | 13 / 600 | 목록 줄 제목, 표 |
| 보조 | `caption1` | 12 / 500 | 날짜, 수, 줄 아래 설명 |
| 메뉴·탭·버튼 | `label1` | 14 / 600 | 상단 메뉴, 탭, 칩 |
| 본문 읽기 | `body2` 읽기용(`body2-reading`) | 15 / 400, 줄 높이는 Montage 읽기용 값 하나 | 원문, 요약. 연구 도우미 답변은 Kokonut 원본 값(15/28)을 그대로 씀 |
| 카드 제목 | `headline2` | 17 / 600 | 카드·창 머리 |
| 화면 제목 | `heading2` | 20 / 700 | 기록 제목, 글 제목 |
| 큰 수 | `title3` | 24 / 700 | D-Day, 남은 할 일 수 |

모서리: 판 16, 카드·묶음 12, 메뉴 항목·찾기 칸 10(`--radius-10`, 토스 실측. `patterns.md`의 네 단계에 이 값을 더하는 개정은 [10](10-build-plan.md) §6), 버튼은 Montage 값, 배지·칩은 알약. 목록 한 줄 높이 44px(제목 한 줄 + 보조 한 줄이면 56px).

**목록 줄이 좁을 때**: 줄 폭이 400px 미만(사이드 창 안, 휴대폰)이면 할 일·기록 줄은 56px 두 줄로 바꿉니다. 윗줄 제목(말줄임 없이 두 줄까지), 아랫줄 기한 · 출처. 공통 줄 부품(`TaskRow`, `RecordRow`)이 스스로 판단합니다(컨테이너 쿼리).

**탭과 보기 전환**: 화면의 큰 구획을 바꾸는 것(홈 목록 탭, 사이드 창 안의 `할 일 | 피드백`)은 Montage `Tab`, 같은 내용의 보는 방식을 바꾸는 것(`전사 | 메모`, `결정 | 질문`, 휴대폰의 `원문 | 요약·할 일`)은 Montage `SegmentedControl`입니다.

**형광펜 색**: Montage에는 노랑 원자 색이 없고, 상태색 주황은 '보류·미확정' 뜻이라 쓰지 않습니다. `tokens.css`에 별칭 `--mark-fill` 하나를 두고 값은 Montage 원자 `lime` 계열에 투명도를 준 것으로 합니다. 투명도라 라이트·다크에서 같은 정의를 쓰고(`.dark` 블록 없음), 다크에서 글자 대비 4.5:1을 넘는지 확인합니다([10](10-build-plan.md) §7 V8). 형광펜은 `<mark>`로 그리고, 화면 낭독에는 '형광펜' 숨김 글자를 앞에 붙입니다. 색만으로 구분하지 않도록 오른쪽 열의 형광펜 줄과 짝을 이룹니다([04](04-meetings.md) §5.3).

## 3. 상단 줄

```
[마진 로고] [연구 이름 ▾]   홈   미팅•   할 일   글·자료      [ 찾기            ⌘K ]      [+] [종³] [김]
```

### 3.1 왼쪽

| 요소 | 동작 |
|---|---|
| 로고 | 홈(`/r/:id`)으로. 연구 밖(`/r`)에서는 `/r`로. 크기는 공개 화면 머리의 로고와 같게(`AGENTS.md`의 로고 크기 규칙). 접근성 이름 '마진(Margin) 홈' |
| 연구 이름 버튼 | 최대 200px, 넘치면 말줄임(전체 이름은 `title`). 누르면 메뉴: 진행 중인 연구(최근 연 순 8개까지, 지금 연구에 체크) / 모든 연구 보기(`/r`) / 새 연구 만들기(`/r/new`). 저장 안 한 내용이 있으면 이동 확인을 먼저 띄움 |
| 메뉴 4개 | `홈` `미팅` `할 일` `글·자료`. 높이 36, 안쪽 여백 8/12, 모서리 10. 지금 화면은 글자색 `--text`, 나머지는 `--text-secondary`. 올리면 `--hover-fill`. `aria-current="page"` |
| 메뉴 켜짐 규칙 | 홈: `/r/:id`, `/r/:id/flow` · 미팅: `/r/:id/meetings…`, 연구 소유자가 연 `/reviews/…`, `/schedule/…` · 할 일: `/r/:id/tasks…` · 글·자료: `/r/:id/docs…` |
| 메뉴의 점 | '미팅'에만. 안 읽은 교수 응답·검토 댓글이 있을 때(§3.4) |
| 올렸을 때 미리보기 | 지금의 `lib/nav-preview.ts` 말풍선을 네 메뉴에 유지. 홈: 현재 단계 · 미팅: 다음 미팅 날짜 · 할 일: 남은 할 일 n개(오늘 기한 n개) · 글·자료: 최근 고친 글 제목 |

### 3.2 연구 밖 화면과 교수 계정

| 상황 | 상단 줄 |
|---|---|
| `/r`(내 연구), `/r/new` 제외 | 로고 · (메뉴 없음) · 찾기 · 종 · 계정. 아이콘 줄·사이드 창 없음 |
| `/r/new` | 지금처럼 틀 없이 로고와 '내 연구로 돌아가기'만 |
| 교수 계정(내 연구 0개, 받은 검토 요청 있음) | 로고(접근성 이름 '마진(Margin) 받은 검토 요청') · 찾기('검토 요청 찾기') · 종 · 계정. **학생 메뉴 4개를 보여 주지 않음** |
| 교수가 연 `/reviews/:id`, 연구 밖 사람이 연 `/schedule/:id` | 지금처럼 그 화면이 자체 머리를 그림. 계정 메뉴의 '화면 설정'은 설정 창을 엶 |

### 3.3 찾기

- 가운데 찾기 칸(폭 280~360, 높이 36, 옅은 채움)은 입력 칸처럼 보이는 **버튼**입니다. 누르거나 ⌘K를 누르면 지금의 찾기 창(`CommandPalette`)이 뜹니다. 992px 미만에서는 돋보기 아이콘 버튼이 됩니다.
- 찾기 창 내용은 지금과 같고(최근 본 기록, 만들기, 이동, 본문 찾기, 다른 연구, 초성 찾기), '이동' 항목만 바꿉니다: 홈 / 미팅 / 글·자료 / 연구 흐름 / 할 일 / 결정·질문 / 연구 도우미 / 설정.
- 결과를 고르면: 기록·글·자료는 그 화면으로, 할 일·피드백·결정·질문·수정 결과는 지금 화면에 `?detail=`을 붙여 항목 상세를 엽니다.

### 3.4 알림과 교수 응답 표시

- 종 아이콘에 안 읽은 알림 수. 누르면 지금의 알림 시트(안 읽음 / 전체, 모두 읽음). 줄을 누르면 저장된 주소(`events.href`)로 가고, 예전 주소는 [01](01-structure.md) §3.3 규칙으로 새 자리에 도착합니다.
- 교수 응답은 메뉴가 줄어도 묻히면 안 됩니다. 안 읽은 교수 응답·검토 댓글이 있으면 **네 곳**에 표시합니다.

| 자리 | 표시 |
|---|---|
| 상단 종 | 수 |
| 상단 '미팅' 메뉴 | 점 |
| 미팅 목록의 '검토 요청' 칩과 해당 줄 | 점 |
| 홈 알림 줄의 주 버튼 | '추가 수정 필요'가 있으면 주 행동이 '교수 응답 보기'로 바뀜([03](03-home.md) §3) |

읽음 처리는 지금과 같습니다(검토 한 건을 열어 그 차수를 봤을 때). 종을 여는 것만으로 교수 응답이 읽음이 되지 않습니다.

## 4. 사이드 창과 아이콘 줄

### 4.1 아이콘 줄

| 순서 | 아이콘 | 이름(말풍선·접근성 이름) | 배지 |
|---|---|---|---|
| 1 | 반짝임 | 연구 도우미 | 확인할 AI 제안이 있으면 점. 답을 만드는 중이면 도는 표시 |
| 2 | 체크 상자 | 할 일 | 남은 할 일 수(99+) |
| 3 | 말풍선 | 결정·질문 | 열린 질문 수 |
| 4 | 폴더 | 자료 | 없음 |
| (아래) | 편지 | 의견 보내기 | `mailto:` (지금 바닥 문의와 같은 주소) |
| (아래) | 톱니 | 설정 | 설정 창 |

- 글자 없이 아이콘만 둡니다(토스와 같은 배치. 56px 폭에 12px 미만 글자를 넣지 않기 위해). 올리거나 초점이 가면 이름 말풍선이 뜨고, 터치 기기에서는 길게 누르면 뜹니다. 처음 쓰는 사람에게는 화면 안내([03](03-home.md) §8)가 아이콘 줄을 한 번 짚어 이름을 알려 줍니다. 버튼은 `aria-pressed`(켜짐)와 `aria-controls`(사이드 창)를 가집니다.
- 꺼진 아이콘을 누르면 그 탭으로 열립니다. **켜진 아이콘을 다시 누르면 창이 닫힙니다.** `]`는 마지막 탭으로 열고 닫습니다.
- 아이콘 줄 전체는 `role="toolbar"`(접근성 이름 '옆 창 열기', 세로 방향)이고, 위·아래 화살표로 버튼 사이를 옮깁니다(초점 하나만 Tab 순서에 들어가는 방식).
- 이 아이콘들은 다른 곳에서 다른 뜻으로 쓰지 않습니다. 미팅 목록의 서면 피드백 줄은 말풍선이 아니라 종이 아이콘을 씁니다.

### 4.2 창의 구조

```
┌ 사이드 창 ──────────────────────┐
│ 연구 도우미          [⋯] [×]    │ ← 머리 48: 탭 이름 + 그 탭의 동작 + 닫기
├────────────────────────────────┤
│                                │
│  (탭 내용: 06 문서)              │ ← 세로로 넘치면 이 안에서만 스크롤
│                                │
└────────────────────────────────┘
 ↔ 안쪽 가장자리를 끌어 폭 조절
```

- 탭은 넷(연구 도우미·할 일·결정·질문·자료). 탭을 바꿔도 각 탭의 스크롤 위치, 쓰던 글, 진행 중인 AI 요청은 그대로입니다(탭을 `hidden`으로 숨길 뿐 없애지 않음. 지금 `MarginPanel`이 내용을 살려 두는 방식과 같음).
- 창을 닫아도 진행 중인 AI 요청은 멈추지 않습니다. 멈춤은 '멈추기' 버튼으로만 합니다.

### 4.3 항목 상세(덮는 층)

- 주소에 `?detail=<종류>:<id>`가 생기면 사이드 창 내용 위에 항목 상세가 덮입니다. 머리는 `[←] 피드백 [⋯] [×]`.
  - `←`: 상세만 닫고 아래 탭으로 돌아감(주소에서 `detail` 제거).
  - `×`: 상세를 닫고, 상세 때문에 창이 열렸던 것이면 창도 닫음.
- 상세 안에서 다른 항목을 누르면(예: 피드백 상세의 할 일) `detail` 값이 바뀌고(주소를 새로 쌓음, `push`), 뒤로 가기로 앞 항목에 돌아갑니다.
- 창이 닫혀 있을 때 항목을 누르면 창이 열리고 상세가 보입니다.
- 편집 중인 내용이 있으면 닫기·다른 항목 열기·탭 바꾸기 전에 이동 확인을 띄웁니다.

**주소 쌓기 규칙** (설정 창도 같음)

| 어떻게 열었나 | 열 때 | `←`·`×`·Esc로 닫을 때 |
|---|---|---|
| 앱 안에서 줄·버튼을 눌러 | `push` | `history.back()` (뒤로 가기와 같은 결과) |
| 주소를 붙여 넣거나 알림·메일·`G` 단축키·찾기 창으로 | `replace`(찾기 창·단축키) 또는 처음 들어옴 | 주소에서 `detail`만 지우고 `replace` |

앱이 "앱 안에서 열었다"를 알 수 있도록 `push`할 때 `history.state`에 `{ layer: 'detail' }`을 남깁니다.

**초점**: 열면 상세 머리의 제목으로 초점이 갑니다. 닫으면 연 줄·버튼으로 돌아가고, 그 요소가 없으면(주소로 들어왔거나 줄이 사라짐) 그 탭의 첫 조작 요소로, 탭이 없으면 `main`으로 갑니다.

### 4.4 폭 조절

지금의 `PanelResizer`를 그대로 씁니다. 최소 312(지금 320에서 낮춤), 최대 640, 키보드 한 번에 16px, 두 번 누르면 기본값. 본문 판이 480px 아래로 줄어드는 폭은 허용하지 않습니다(끌어도 더 넓어지지 않음).

### 4.5 기억하는 것

| 무엇 | 어디에 | 키 |
|---|---|---|
| 열림/닫힘 | 이 브라우저 | `margin-panel-open` (`1`/`0`) |
| 마지막 탭 | 이 브라우저 | `margin-panel-tab` |
| 폭(일반 화면) | 이 브라우저 | `margin-panel-width` (지금 키 그대로) |
| 폭(글 편집·자료 보기) | 이 브라우저 | `margin-panel-width-docs` |
| 왼쪽/오른쪽 | 계정(서버) | `preferences.panelSide` |

처음 쓰는 사람의 기본값: 창 폭 1440px 이상이면 열림, 그보다 좁으면 닫힘. 탭은 연구 도우미. 저장소를 못 쓰면(사파리 비공개 등) 기본값으로 동작하고 오류를 내지 않습니다.

폭은 탭마다 따로 기억하지 않습니다(탭을 바꿀 때 폭이 튀지 않게). 연구 도우미 입력창이 312px에서 넘치면([10](10-build-plan.md) §7 V7) 탭별 예외를 두지 않고 **일반 화면 기본 폭 자체를 360으로** 올리고 §1.1 폭 표와 판 폭 단계 계산을 다시 합니다.

### 4.6 구현 중 임시 규칙

지금 여섯 화면이 `MarginPanel`로 패널 내용을 넣습니다. 화면을 하나씩 옮기는 동안에는 사이드 창이 그 내용을 **다섯 번째 임시 탭**(이름은 그 화면이 준 `label`)으로 받아 줍니다. 모든 화면을 옮긴 뒤 이 통로와 `MarginPanel`의 `publish` 방식을 지웁니다([10](10-build-plan.md) 5단계).

- 임시 탭은 화면이 `MarginPanelSection`을 보낼 때만 아이콘 줄 맨 아래(의견 보내기 위)에 '이 화면' 아이콘(사각형 안 선)으로 나타나고, 말풍선 이름은 그 `label`입니다. 지금 상단 줄의 패널 버튼(`WorkspaceShell`)이 하던 일을 이 아이콘이 대신합니다.
- 임시 탭의 열림은 `margin-panel-open`을 따릅니다. 화면이 주는 `open` 값은 그 화면에 처음 들어올 때 한 번만 반영합니다.
- 아이콘 줄의 네 탭 중 내용이 아직 없는 탭(0단계의 연구 도우미·할 일·결정·질문·자료)은 **아이콘을 보이지 않습니다**. 빈 탭을 열 수 없게 합니다. 각 탭은 그 내용이 들어오는 단계에서 나타납니다. 단, 0단계부터 연구 도우미 아이콘은 지금 `/assistant` 화면으로 가는 버튼으로 둡니다(4단계에 창으로 바뀜).

## 6. 휴대폰(767px 이하) [확정 Q1: 아래 탭 줄을 둔다]

```
┌──────────────────────────────┐
│ [연구 이름 ▾]   [+][찾기][종][김] │ 52
├──────────────────────────────┤
│                              │
│   화면(1열)                    │
│                              │
├──────────────────────────────┤
│ ● 12:04 [지금 표시][일시정지][끝내기] │ 44 (녹음 중에만)
├──────────────────────────────┤
│  홈   미팅   할 일  글·자료 연구 도우미 │ 56 + 안전 영역
└──────────────────────────────┘
```

- 아래 탭 다섯 칸(360px에서 칸당 72px): **홈 · 미팅 · 할 일 · 글·자료 · 연구 도우미**. 메뉴 넷은 데스크톱 상단 메뉴와 같은 화면으로 갑니다. 각 칸은 아이콘 + 12px 이름(줄바꿈 없음, 좌우 안쪽 여백 2px, 일본어 이름 길이도 확인), 누를 수 있는 높이 48px 이상. '할 일' 칸에 남은 할 일 수 배지, '미팅' 칸에 교수 응답 점.
- 만들기(+)는 상단 줄 오른쪽(찾기 앞)에 있고, 누르면 만들기 메뉴(§3.5)를 아래에서 올라오는 시트로 엽니다.
- 다섯째 칸 '연구 도우미'는 **사이드 창을 담은 시트**를 엽니다. 시트 맨 위에 `연구 도우미 | 결정·질문 | 자료` 세그먼트(할 일은 아래 탭에 따로 있으므로 뺌)가 있고 마지막에 본 세그먼트로 열립니다. 홈 맨 위의 바로가기 줄(`결정·질문` `자료`)은 같은 시트를 해당 세그먼트로 엽니다.
- 시트 높이는 보이는 화면 높이(`100dvh`) 기준이고, 연구 도우미 입력창은 가상 키보드 바로 위에 붙습니다. 녹음 줄은 시트에 가려지지 않습니다(시트가 녹음 줄 위에서 끝남).
- 항목 상세는 아래에서 올라오는 시트(높이 92%)입니다.
- 상단 줄 왼쪽의 연구 이름은 남는 폭을 모두 쓰고(`min-width: 0`, 말줄임) 오른쪽 버튼 넷(40px씩, 합 160)이 줄지 않습니다. 360px에서 연구 이름 몫은 약 150px입니다.
- '의견 보내기'는 휴대폰에서 계정 메뉴 맨 아래에 둡니다.
- 화면 안의 여러 열은 한 열로 접히고, 열 사이는 화면 위쪽의 세그먼트로 바꿉니다(각 화면 문서의 '좁은 화면' 절).
- 사이드 창 위치 설정은 적용하지 않습니다.

## 8. 겹침 순서와 Esc

값은 `src/styles.css`의 기존 `--z-*` 토큰을 씁니다(새 토큰 없음). 아래로 갈수록 위에 뜹니다.

| 층 | 토큰(값) | 비고 |
|---|---|---|
| 본문 판, 미는 사이드 창 | 없음(문서 흐름) | |
| 판 안의 붙는 머리·도구 막대 | `--z-sticky` (5) | |
| 상단 줄, 녹음 줄 | `--z-topbar` (20) | 서로 겹치지 않는 자리라 같은 층 |
| 겹쳐 뜬 사이드 창, 휴대폰 시트 | `--z-sheet` (40) | 상단 줄 아래·녹음 줄 위 사이에만 그려서 둘을 가리지 않음 |
| 메뉴·팝오버·대화상자·설정 창·찾기 창 | Montage 부품의 포털 값 | Montage가 `--z-sheet`보다 위에 그리는지 0단계에서 확인([10](10-build-plan.md) §7 V9). 아니면 `calc(var(--z-sheet) + 1)` |
| 알림·되돌리기 알림 | `--z-toast` (60) | |
| 본문 바로가기 링크 | `--z-skip` (100) | |
| 화면 안내 | `--z-tour` (200) | |

Esc 순서: **초점이 있는 입력이 먼저 씁니다**(한글 조합 취소, 제목 그 자리 편집 취소, 이어쓰기 제안 닫기, 선택 메뉴 닫기). 입력이 쓰지 않았을 때만 가장 위에 뜬 것 하나를 닫습니다: 메뉴·팝오버 → 대화상자 → 설정 창·찾기 창 → 항목 상세 → (겹쳐 뜬) 사이드 창. 본문을 미는 사이드 창은 Esc로 닫지 않습니다.

## 9. 접근성

- 구조: `header`(상단 줄) · `nav`(이름 '주요 메뉴') · `main#main` · `aside`(이름 = 지금 탭 이름) · `role="toolbar"`(이름 '옆 창 열기'). 맨 앞에 '본문으로 이동' 링크, 사이드 창이 열려 있으면 그 뒤에 '옆 창으로 이동' 링크.
- 탭 이동 순서는 화면 순서와 같습니다: 상단 줄 → 본문 → 사이드 창 → 아이콘 줄(사이드 창이 왼쪽이면 아이콘 줄 → 사이드 창 → 본문). 녹음 줄은 맨 끝입니다.
- 사이드 창을 열면 초점이 창의 첫 조작 요소로, 닫으면 열기 전에 있던 자리로 돌아갑니다(지금 `useMarginPanelHost` 동작 유지).
- **겹쳐 뜬 사이드 창(768~1199)은 초점을 가두지 않습니다.** 뒤를 어둡게 가리지 않고, 바깥을 누르거나 Esc로 닫힙니다. 그래서 창을 연 채로도 녹음 줄의 [일시정지]·[끝내기]에 키보드로 닿습니다. 초점을 가두는 것은 대화상자·설정 창·찾기 창·휴대폰 시트이고, 이들은 녹음 줄을 초점 순서 끝에 함께 넣습니다(녹음 줄이 보일 때).
- **올렸을 때만 나오는 버튼 금지**: 줄 위에 마우스를 올렸을 때 나오는 버튼(할 일 줄의 [연구 도우미와 상의]·[⋯], 알림 줄의 [할 일 추가] 등)은 줄에 초점이 들어와도 보입니다. 터치 기기(`@media (hover: none)`)에서는 줄 끝의 [⋯] 하나를 늘 보이고, 올렸을 때의 버튼은 모두 그 메뉴 안에 같이 둡니다. 오른쪽 버튼 메뉴(우클릭)는 [⋯]와 내용이 같습니다.
- **끌기만으로 되는 조작 금지**(WCAG 2.2 2.5.7): 순서 바꾸기는 줄 메뉴의 '위로'·'아래로'(탭은 '왼쪽으로'·'오른쪽으로'), 크기 조절은 [넓히기]·[줄이기] 버튼이나 키보드 화살표를 함께 둡니다.
- **알려 주는 변화**: 화면 낭독에 알리는 것은 정중한 알림 영역(`role="status"`) 하나로 모읍니다. 알리는 것: 되돌리기 알림, AI 답 완료·실패, 저장 실패, 녹음 시작·일시정지·끝, 자동 저장 충돌. 알리지 않는 것: 실시간 전사 글자, 굴러가는 숫자, 저장 중·저장됨(머리의 상태 글자로 충분). 되돌리기 알림은 초점이나 마우스가 올라가 있는 동안 시간이 멈춥니다.
- 배지의 수는 접근성 이름에 넣습니다('할 일, 남은 할 일 4개'). 점만 있는 표시도 글로 알립니다('미팅, 새 교수 응답 있음').
- 한글 조합 중 Enter로 보내거나 저장하지 않습니다(`lib/ime.ts`).
- 누를 수 있는 것은 최소 24×24px, 휴대폰의 주 조작은 44px 이상.

## 10. 움직임

`--motion-*` 토큰만 씁니다. `prefers-reduced-motion: reduce`에서는 아래 '줄였을 때' 열을 따릅니다.

| 무엇 | 움직임 | 줄였을 때 |
|---|---|---|
| 사이드 창 열기·닫기(밀 때) | 폭이 `enter` 200ms / `exit` 160ms로 바뀜 | 바로 |
| 사이드 창 열기·닫기(겹칠 때) | 아이콘 줄 쪽에서 16px 밀려 나오며 나타남 200ms, 사라짐 160ms | 투명도만 120ms |
| 사이드 창 폭 312↔440(글 편집에 들어갈 때) | 폭이 200ms로 바뀜 | 바로 |
| 항목 상세 | 16px 밀려 들어옴 200ms, 나감 160ms | 투명도만 120ms |
| 탭 바꾸기 | 120ms 교차 | 바로 |
| 메뉴의 점, 배지 수 | 수가 바뀌면 숫자가 굴러감(`@number-flow/react`) | 바로 바뀜 |
| 할 일 끝내기 | 체크 그려짐 120ms → 줄 긋기 200ms → 300ms(`--motion-duration-page`) 머문 뒤 줄이 160ms로 접힘. 머무는 동안 다시 누르면 취소 | 체크와 줄 긋기만, 접힘은 바로 |
| 짚기(오른쪽 줄 ↔ 원문 위치, 알림에서 들어온 항목) | `--selected-fill`이 200ms로 켜지고 600ms 유지한 뒤 160ms로 꺼짐(한 번만) | 2초 동안 켜져 있다가 바로 꺼짐 |
| 형광펜 칠하기 | 고른 글자 위로 색이 왼쪽에서 오른쪽으로 120ms | 바로 |
| AI 제안이 확정됨(점선 → 실선) | 테두리가 120ms로 바뀜 | 바로 |
| 요약 도착 | 요약 구획이 200ms로 펼쳐지고 글자가 투명도로 나타남 | 바로 |
| 원문이 녹음 위치를 따라 내려감 | 부드러운 스크롤 | 바로 이동 |
| 녹음 줄 | 아래에서 올라옴 200ms | 바로 |

계속 도는 움직임은 실제로 진행 중일 때만 씁니다(녹음 점, AI 요청 중 표시).

## 11. 문서 제목
