# 05. 글·자료 (W1~W3)

주소 `/r/:id/docs`. 지금의 '글쓰기'와 '자료'를 한 목록으로 합칩니다. 글 편집 화면은 라이너·매니패스트의 틀(열어 둔 문서 탭, 두 줄 도구, 목차, 본문 안 수정 제안)을 따릅니다(D8). 초안의 형태를 바꾸는 스위치는 두지 않습니다(D7). 따로 표시하지 않은 내용은 **[제안]**입니다.

## 1. 세 화면

| 화면 | 주소 | 하는 일 |
|---|---|---|
| W1 목록 | `/r/:id/docs` | 글과 자료를 찾고, 만들고, 올리고, 폴더로 정리 |
| W2 글 편집 | `/r/:id/docs/w/:documentId` | 쓰기, 버전, 연구 도우미의 수정 제안 받기 |
| W3 자료 보기 | `/r/:id/docs/m/:materialId` | PDF 읽기, 버전, 어디에 썼는지 보기 |

W2·W3에 들어가면 사이드 창 기본 폭이 440px이 됩니다(D9, [02](02-shell.md) §4.5).

| 종류 | 왼쪽 | 제목 아래 | 표시 |

### 3.2 열어 둔 탭

- 글이나 자료를 열면 탭이 생깁니다. 8개까지, 넘으면 가장 오래 안 본 탭이 빠집니다. 연구별로 이 브라우저에 기억합니다.
- 맨 왼쪽 [≡ 목록]은 W1로. [+]는 새 글 창.
- 탭의 ×는 탭만 닫습니다(글은 지워지지 않음). 저장 안 한 내용이 있으면 먼저 저장을 시도하고, 실패하면 이동 확인.
- 탭을 끌어 순서를 바꿀 수 있고, 탭 메뉴의 '왼쪽으로'·'오른쪽으로'로도 바꿉니다(끌기만으로 되는 조작 금지, [02](02-shell.md) §9). 가운데 버튼으로 누르면 닫힙니다.
- 탭은 최소 96px, 제목은 말줄임. 탭이 판 폭을 넘으면 탭 줄이 가로로 스크롤되고 양 끝이 흐려집니다.
- 보관되었거나 권한이 없어진 글의 탭은 다음에 열 때 조용히 빠집니다.

### 3.4 본문과 도구

- 도구 줄 1은 지금의 `EditorToolbar`(되돌리기·다시, 문단 종류, 굵게·기울임·취소선, 목록·번호 목록·인용, 표, 서식 지우기)입니다. 표는 지금처럼 TipTap 표를 씁니다. 발표·표 '형태'를 바꾸는 스위치는 없습니다(D7).
- 글자를 고르면 뜨는 메뉴:

| 버튼 | 하는 일 |
|---|---|
| 고쳐 쓰기 | 지금의 Kokonut `ai-inline-edit`(미리 정해 둔 지시 + 단어 비교). 그대로 |
| 연구 도우미에게 묻기 | 사이드 창에 고른 문단을 근거로 붙임(지금은 연구 도우미 화면으로 넘어가던 것) |
| 할 일 추가 | 고른 글을 인용으로 가진 할 일을 만듦. `documentId`와 그 위의 제목(`sectionAnchor`)이 함께 저장돼 여백에 표시됨 |

- 이어쓰기 제안(Kokonut `ai-autocomplete`): 지금과 같음(Tab 전체, → 한 단어, Esc 닫기).
- 저장 충돌: 지금의 처리 그대로(저장된 것 쓰기 / 내 것 유지). 공동연구자가 고친 새 판을 30초 주기에서 발견했을 때, 내가 고치는 중이 아니면 내용을 바꾸고 "공동연구자가 고친 내용으로 바꿨어요."를 띄우고, 고치는 중이면 저장할 때 충돌 창으로 처리합니다.
- 쓰던 내용 되살리기(이 브라우저에 남은 초안): 지금과 같음.

### 3.5 여백의 표시와 '피드백 n/m 다룸'

- 이 글에 연결된 할 일(`tasks.documentId === 이 글`)은 그 제목(`sectionAnchor`) 높이의 여백에 체크 상자로 보입니다. 체크는 그 자리에서, 누르면 항목 상세.
- 그 할 일이 딸린 피드백은 번호 동그라미로 보입니다. 누르면 피드백 상세(원문 인용, 녹음 구간).
- 제목이 바뀌어 `sectionAnchor`를 찾지 못하면 맨 위 여백에 모아 둡니다.
- 도구 줄 2의 **"피드백 3/5 다룸"**: 이 글에 연결된 피드백 5개 가운데 상태가 '수정 결과 있음'·'보류'·'고치지 않음'인 것이 3개라는 뜻입니다. 누르면 목록이 펼쳐지고 각 줄이 상세로 이어집니다. 연결된 피드백이 없으면 이 표시는 없습니다.
- 이 수는 학생이 표시한 상태를 센 것이고 교수 응답과는 다릅니다. 교수 응답은 피드백 상세에 따로 보입니다.

### 3.6 연구 도우미의 수정 제안

두 단계로 넣습니다.

**먼저(3단계 앞쪽): 지금 기능 그대로.** [문장 점검] → 고른 부분 또는 글 전체를 보내고 → 지금의 비교하고 적용하는 창.

**그다음(3단계 뒤쪽): 본문 안 제안.** `ai-assist`의 새 모드 `suggest_edits`([08](08-data.md) §5.3)가 준비되면 창 대신 본문 안에 표시합니다.

| 요소 | 모양·동작 |
|---|---|
| 제안 한 건 | 지울 글자는 취소선(`--danger` 옅은 바탕), 넣을 글자는 밑줄(`--brand` 옅은 바탕). 색만이 아니라 취소선·밑줄로도 구분됨 |
| 제안에 커서나 마우스를 올림 | 작은 카드: 이유 한 줄(어느 피드백 때문인지 링크) · [적용] [적용 안 함] |
| 도구 줄 2 | "수정 제안 2개" · ‹ › 로 앞뒤 제안으로 · [모두 적용] [모두 적용 안 함] |
| 단축키 | Alt+] 다음, Alt+[ 이전, ⌘/Ctrl+Enter 적용, ⌘/Ctrl+Backspace 적용 안 함 |
| 적용 | 글에 반영되고 되돌리기(⌘Z)로 되돌릴 수 있음. 그 제안은 '선택'으로 남음 |
| 제안이 있는 자리를 직접 고침 | 그 제안은 닫힘("직접 고쳐서 제안을 닫았어요."는 띄우지 않고 조용히) |
| 글이 다른 곳에서 바뀜 | 맞지 않게 된 제안은 빠지고 "글이 바뀌어 제안 n개를 닫았어요. 다시 제안받을 수 있어요." |

제안을 받는 곳: [문장 점검], 연구 도우미 창의 `/수정 제안` 명령, 피드백 상세의 [이 글에 수정 제안받기]. 어느 경우든 보낼 글과 근거를 사용자가 확인하고 보냅니다. 제안은 본인만 보고, 적용해야 글이 바뀝니다.

### 3.7 비교 보기

버전을 고르면 본문 자리가 비교 보기로 바뀝니다(주소 `?compare=<버전 id>`). 지금의 단어 비교·슬라이더 비교를 그대로 씁니다. 머리: "v2(11월 10일)와 지금" · `단어 비교 | 슬라이더` · [이 버전으로 되살리기] (지금 내용을 덮지 않고 새 버전으로 되살림. 지금 동작) · [닫기].

| 초안의 근거 | 연구 도우미 초안이면 근거로 쓴 기록(`draftedFrom`) 목록. 누르면 그 기록 |
| 쓰인 곳 | 이 글을 '보여 줄 글·자료'로 고른 미팅 |

### 3.9 연구 도우미가 만든 초안

- 연구 도우미의 답을 '글로 저장'하면 종류 '메모', `origin: 'ai'`인 글이 생기고 W2에서 열립니다.
- 글 맨 위 띠: "연구 도우미가 쓴 초안이에요. 근거로 쓴 기록 3개 [보기]". 사람이 한 글자라도 고치면 `humanEditedAt`이 찍히고 띠가 사라집니다(정보 보기에는 "초안에서 시작"이 남음).
- 초안은 '나만 보기'로 만들어집니다.

## 4. W3 자료 보기

```
[≡ 목록] [연구계획서 v3 ×] [Kim2023.pdf ×] [+]
Kim2023.pdf   [참고]   v2 ▾                    [새 버전 올리기] [내려받기] [⋯]
┌ PDF (남는 폭) ───────────────────────────────────┬ 정보 300 ─────────────┐
│  ‹ 3 / 18 ›   − 100% +                          │ 버전                   │
│                                                 │  v2 · 11월 10일 · 2.1MB │
│                                                 │  v1 · 11월 2일 · 1.9MB  │
│                                                 │ 이 버전을 쓴 기록         │
│                                                 │  제6차 논문 지도(준비)   │
│                                                 │  수정 결과 ‘표 2 보완’   │
│                                                 │ [연구 도우미에게 읽게 하기]│
└─────────────────────────────────────────────────┴───────────────────────┘
```

- PDF 보기는 지금의 `PdfViewer`(쪽 넘기기, 확대, 내려받기, 쪽 글자 보기) 그대로입니다. 주소에 `?ver=`, `?page=`가 남습니다.
- 버전을 바꾸면 그 버전의 파일과 "이 버전을 쓴 기록"이 바뀝니다.
- ⋯: 정보 편집(이름·종류·링크) / 폴더로 옮기기 / 보관.
- [연구 도우미에게 읽게 하기]: 사이드 창을 열고 이 파일의 지금 쪽을 근거로 붙입니다(지금의 '자료 읽기'와 쪽 고르기).
- 링크 자료: PDF 자리에 주소 카드와 [링크 열기] (새 탭, http·https만) [복사].
- 정보 열은 판 폭이 보통 이하(864px 미만)면 접혀 머리의 [정보] 버튼이 됩니다.
- PDF를 불러오는 동안은 쪽 모양의 뼈대와 "PDF를 불러오고 있어요." 한 줄(지어낸 진행률 없음).
