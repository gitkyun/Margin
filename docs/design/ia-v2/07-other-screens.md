# 07. 그 밖의 화면

설정 창, 내 연구, 연구 만들기, 연구 흐름, 교수 화면, 공개 화면입니다. 대부분 **지금 내용을 그대로 두고 담는 틀만 바꿉니다.** 따로 표시하지 않은 내용은 **[제안]**입니다.

## 1. 설정 창 (G1)

지금은 설정이 두 화면(`/account`, `/r/:id/settings`)에 나뉘어 있고 탭이 아홉 개입니다. 토스처럼 **한 창, 왼쪽 목록 + 오른쪽 내용**으로 합칩니다.

### 1.1 틀

```
┌ 설정 ─────────────────────────────────────────────────────────── [×] ┐
│ 내 계정              │ 화면                                            │
│   프로필             │ ─────────────────────────────────────────────  │
│ ▸ 화면               │ 테마            [라이트] [다크] [시스템]          │
│   알림               │ 언어            [한국어] [日本語]                 │
│   연구 도우미         │ 시각 표기        [24시간제] [12시간제] [기기 설정]  │
│   사용량·플랜         │ 효과음          (○ )                            │
│   단축키             │ 사이드 창 위치    [오른쪽] [왼쪽]                  │
│ 이 연구 · 대학원생의…  │                                                │
│   연구 정보           │ 테마·언어·시각 표기·효과음은 이 브라우저에만,       │
│   함께하는 사람        │ 사이드 창 위치는 계정에 저장돼요.                  │
│   미팅 주기           │                                                │
│   보관·삭제           │                                                │
│ ───────────          │                                                │
│ 사용 안내 · 자료와 개인정보 │                                            │
└──────────────────────┴────────────────────────────────────────────────┘
```

| 항목 | 값 |
|---|---|
| 크기 | 폭 920px, 높이 680px. 창이 작으면 `min(920, 100vw − 48)` × `min(680, 100vh − 48)` |
| 왼쪽 목록 | 220px, 바깥 면과 같은 중립 배경. 선택한 항목은 중립 채움과 굵은 글자. 묶음 이름은 글자만 |
| 면 | 대화상자 면 + `--shadow-pop`, 모서리 16. 뒤는 옅게 가림 |
| 휴대폰 | 화면 전체 시트. 목록에서 항목을 누르면 내용 화면, [← 설정]으로 목록 복귀. 닫기 버튼은 두 화면의 같은 자리에 표시 |
| 주소 | `?settings=<구획>`. 열려 있는 동안 주소에 남고 뒤로 가기로 닫힘. 구획을 바꾸면 `replace`(뒤로 가기 한 번에 창이 닫힘) |
| 닫기 | ×, Esc, 바깥 누르기. 저장 안 한 내용이 있으면 이동 확인("저장하지 않고 이동할까요?") |
| 구획 바꾸기 | 저장 안 한 내용이 있으면 같은 이동 확인. 지금 연구 설정의 "먼저 저장하거나 취소해 주세요" 알림 방식은 쓰지 않음(계정 쪽과 통일) |
| 접근성 | `role="dialog"`, 제목과 연결, 초점 가두기, 닫으면 연 버튼으로. 왼쪽 목록은 ↑/↓로 이동 |

- '이 연구' 묶음은 연구 안(`/r/:id/…`)에서 열었을 때만 보입니다. 내 연구(`/r`)나 교수 계정에서는 '내 계정'만 보입니다.
- 틀린 구획 값은 무시하고 주소에서 지웁니다(창을 열지 않음). 연구 구획(`research` 이하 넷)을 연구 밖 주소에서 받으면 `profile`로 엽니다([01](01-structure.md) §3.2와 같은 규칙).

### 1.2 구획과 저장 방식

내용·문구·검증은 지금 화면 그대로 옮깁니다(조사 기록의 설정 절). 표의 '저장'은 지금 방식을 유지한 것입니다.

| 구획(값) | 내용 | 저장 | 달라지는 점 |
|---|---|---|---|
| 프로필(`profile`) | 표시 이름, 로그인 이메일(바꿀 수 없음), 비밀번호 변경 | 이름: [저장] / 비밀번호: [비밀번호 변경] | 없음 |
| 화면(`display`) | 테마, 언어, 시각 표기, 효과음, **사이드 창 위치** | 고르면 바로 | 테마를 세 가지(라이트·다크·시스템) 고르는 부품으로 통일(지금 계정 화면은 두 가지 전환 버튼이라 '시스템'을 못 골랐음). 언어를 바꾸면 화면을 새로 불러오므로, 저장 안 한 글이 있으면 먼저 이동 확인 |
| 알림(`notifications`) | 네 종류 스위치 | 바꾸면 바로, 실패하면 되돌림 | 없음 |
| 연구 도우미(`assistant`) | 기본 모델·답변 깊이, 나만의 연구 도우미(이름·말투·개인 지침) | [저장] 각각 | 구획 이름을 'AI 기본 설정'에서 '연구 도우미'로 |
| 사용량·플랜(`usage`) | 내 AI 크레딧(잔액·이번 달 사용·예약, 이력), 이번 달 AI 사용량, 저장 공간, 플랜(Free / Pro·Team 출시 예정) | 읽기 전용 | 플랜 카드 셋을 세로로 쌓음(창 폭 때문) |
| 단축키(`shortcuts`) | `?` 도움말과 같은 표 | — | 새 구획(내용은 기존) |
| 연구 정보(`research`) | 연구 이름·설명·목적·질문·투고 목표일·키워드·인용 양식 + 지도교수(5명까지) + "연구 흐름에서 단계 편집" 링크 | 정보: [저장] [취소] / 지도교수: 넣고 빼면 바로 | '연구 단계' 탭을 없애고 링크로 |
| 함께하는 사람(`people`) | 공동연구자 목록(접근 해제·초대 취소), 이메일 초대(역할, 5초 되돌리기, 다시 보내기, 링크 복사), 보낸 초대 | 지금 그대로 | 구획 이름을 '공동연구자'에서 '함께하는 사람'으로(지도교수 초대도 여기 있으므로) |
| 미팅 주기(`schedule`) | §1.3 | 바꾸면 바로 | 새 구획 |
| 보관·삭제(`danger`) | 연구 완료로 표시·되돌리기(지금 내 연구 카드의 '완료로 표시'와 같은 동작, 소유자), 연구 보관·복원, 휴지통으로 옮기기 | 확인 창 | 휴지통으로 옮긴 뒤 `/r?view=trash`로. 완전 삭제는 지금처럼 휴지통에서만 |

- 소유자가 아니면 소유자 전용 조작(공동연구자 초대·해제, 보관·휴지통)은 비활성이고 이유를 보여 줍니다(지금 문구).
- 보관한 연구에서는 연구 구획이 읽기 전용이고 `danger`의 [연구 복원]만 동작합니다.
- 미리보기 모드에서는 저장이 필요한 조작이 비활성이고 지금 문구("미리보기에서는 설정을 저장할 수 없어요.")를 씁니다. 사이드 창 위치는 그 자리에서만 바뀌고 저장되지 않습니다.

### 1.3 미팅 주기 [확인 필요 Q7]

| 칸 | 내용 |
|---|---|
| 스위치 | "정해진 미팅 요일이 있어요" (기본 꺼짐) |
| 요일 | 월~일 가운데 하나 |
| 시각 | 시각 입력(`lib/time-format.ts` 형식) |
| 간격 | 매주 / 2주마다 / 3주마다 / 4주마다 |
| 미리보기 | "다음 차례: 11월 25일 (수) 14:00" — 계산은 아래 |

다음 차례 계산(`lib/recurrence.ts`, 테스트 포함):

1. 기준일 = 날짜가 있는 미팅(서면 피드백·취소한 미팅 제외, [08](08-data.md) §4.0) 가운데 가장 늦은 날짜. 없으면 오늘.
2. 후보 = 기준일 **다음 날부터** 처음 오는 설정 요일 + (간격 − 1)주.
3. 후보가 오늘보다 이르면 간격만큼(7 × 간격 일) 계속 더해 오늘 이후가 되게 합니다.
4. 이미 잡힌 다음 미팅(§4.1의 다음 미팅)이 있으면 그 날짜를 기준일로 씁니다(같은 날을 두 번 권하지 않게).
5. 날짜는 서울 기준(`seoulToday`)으로 셉니다.

설명: "‘다음 미팅 잡기’를 열 때 날짜를 미리 채워요. 미팅을 자동으로 만들지 않아요."

## 2. 내 연구 (R1)

주소 `/r`. 내용은 지금 그대로입니다(`origin/main` 기준: 진행 중인 연구 · 완료된 연구 · 보관함 · 휴지통 탭과 개수, 카드 메뉴, 받은 검토 요청, 받은 초대, 열린 시간 조율, 휴지통 이동·복원·완전 삭제, 삭제 마무리).

| 달라지는 점 | 내용 |
|---|---|
| 틀 | 상단 줄(로고 · 찾기 · 종 · 계정)만. 메뉴 4개·아이콘 줄·사이드 창 없음. 본문은 판 하나(최대 폭 1040) |
| 카드 메뉴 '연구 설정' | `/r/:id?settings=research`(그 연구의 홈 위에 설정 창) |
| `?settings=` | 이 화면에서도 설정 창이 열림('내 계정'만) |

연구가 하나도 없고 받은 검토 요청·초대도 없으면 지금처럼 `/r/new`로 갑니다.

## 3. 연구 만들기 (R2)

주소 `/r/new`. 네 단계 질문, 건너뛰기, 지도교수 이메일, 기본 단계 6개와 첫 '지도 미팅' 만들기, 서비스 소개 다시 보기(`?intro=1`), 실패 시 이어서 저장 — 모두 지금 그대로입니다.

| 달라지는 점 | 내용 |
|---|---|
| 오른쪽 미리보기(`HomePreview`) | 새 홈 모양으로 다시 그림: 머리 + 다음 미팅 카드 + 할 일 탭 세 줄. 답할 때마다 바로 반영되는 동작은 같음 |
| 홈으로 커지는 전환(`lib/expand-home.ts`) | 도착하는 화면이 새 홈. 미리보기 창이 본문 판 자리로 커짐. 동작 줄이기에서는 바로 이동(지금과 같음) |
| 3단계 "다음 지도 미팅은 언제인가요?" | 날짜를 정했으면 그 요일·시각을 미팅 주기의 기본값으로 **권하지 않음**(묻지 않은 것을 저장하지 않음). 미팅 주기는 설정에서 직접 켬 |

[사실, 2026-11-19 5단계 구현] 오른쪽 미리보기(`components/onboarding/HomePreview.tsx`)를 새 홈 모양으로 다시 그렸습니다: 상단 줄(로고 · 연구 이름 · 메뉴 넷, 홈 켜짐) → 머리(이름 · 설명, 오른쪽에 '현재 단계' · '지도교수 n명' 칩) → 다음 미팅 카드(오른쪽에 주 버튼) → 목록 카드(`할 일 · 알림 · 최근 미팅` 탭과 할 일 세 줄 뼈대). 예전의 왼쪽 메뉴와 '이번 주'·'남은 할 일' 카드는 뺐습니다. 질문마다 그 자리로 확대해 들어가는 동작은 같습니다. 홈으로 커지는 전환은 이미 새 홈(`.app-shell`)에 도착하고, 3단계 미팅 날짜를 미팅 주기의 기본값으로 권하는 동작은 없어 손대지 않았습니다.

## 4. 연구 흐름 (F1)

주소 `/r/:id/flow`. 지금의 '일정' 화면(`PlanningPage`)에서 **시간 조율 탭만 미팅으로 보내고** 나머지를 그대로 옮깁니다. 메뉴에는 없고 홈의 '연구 흐름' 카드·현재 단계 칩·D-Day 칩, `G P`, 찾기 창에서 들어옵니다. 상단 메뉴는 '홈'이 켜집니다.

```
← 홈    연구 흐름    투고 D-42                               [AI 계획 제안] [단계 추가]
단계·주요 목표 | 달력
보기: 카드 | 월별 | 관계도
┌ 1 주제 정의 ✓ ┐ ┌ 2 선행연구 ✓ ┐ ┌ 3 연구 설계 ● 현재 ┐ ┌ 4 자료 수집·분석 ┐ …
주요 목표
  ◆ 중간발표 원고 · 12월 3일 · 할 일 2/5 · 글 1
```

| 탭 | 내용(지금 기능) | 누르면 가는 곳이 바뀌는 것 |
|---|---|---|
| 단계·주요 목표 | 단계 카드(현재 단계 정하기, 순서 바꾸기, 편집, 보관), 기본 단계 6개로 시작, 월별 보기, 관계도(Q3), 주요 목표(만들기·편집·삭제, 할 일·글 연결), AI 계획 제안(고칠 수 있는 미리보기 → 적용), AI 없이 고르게 나누기 | 주요 목표의 할 일 → `?detail=task:<id>`, 글 → W2 |
| 달력 | 월·주·목록 보기. 미팅, 할 일 기한, 단계·주요 목표 날짜. 날짜 없는 미팅 목록 | 미팅 → 그 기록, 할 일 → 항목 상세, **날짜를 누르면 '다음 미팅 잡기' 창이 그 날짜로 열림** |

- 주소에 `tab`, `view`, `phase`가 남습니다. 홈에서 단계를 눌러 오면 그 단계 카드가 한 번 강조됩니다(지금은 `?phase=`를 읽지 않아 이 동작이 없음 — 이번에 넣음).
- AI 계획 제안은 지금처럼 사용자가 눌러 실행하고, 미리보기를 고친 뒤 적용해야 단계가 바뀝니다. 불가 상태는 [09](09-states.md) §2.
- 판 폭이 좁음(664px 미만, [02](02-shell.md) §1.1)이면 단계 카드가 세로로 쌓이고, 관계도는 "넓은 화면에서 볼 수 있어요."로 대신합니다(지금 동작이 있으면 그대로).

[사실, 2026-11-19 5단계 구현] 머리를 '← 홈 · 연구 흐름'으로, 탭을 `단계·주요 목표 | 달력`으로 바꾸고 시간 조율 탭을 뺐습니다. 투고 목표일이 있으면 설명 줄 앞에 "투고 D-n"을 붙입니다. 예전 `tab=schedule`(그리고 `/planning?tab=schedule`)은 미팅 목록의 '시간 조율' 보기(`meetings?type=poll`)로 옮기고, 그 보기의 [시간 조율 시작]과 기록 추가 메뉴의 '시간 조율'은 그 자리의 창(`new=poll`, `components/meetings/PollCreate.tsx`)을 엽니다. 달력의 할 일은 이 화면 위에 항목 상세로 엽니다. `?phase=` 강조는 이미 있었습니다. 판 폭이 좁을 때의 배치와 날짜를 눌렀을 때 '다음 미팅 잡기' 창을 그 날짜로 여는 동작은 지금(미팅 화면의 만들기 창으로 이동) 그대로입니다.

## 5. 교수 화면 (X1, X2)

교수 화면은 **내용을 바꾸지 않습니다.** 교수용 학생 목록·대시보드를 만들지 않고, 학생 메뉴를 붙이지 않습니다.

| 화면 | 지금 | 새 틀에서 |
|---|---|---|
| X1 받은 검토 요청(`/r`, 내 연구가 없고 받은 요청이 있는 계정) | 사이드바에 받은 요청 6개 + 본문 목록 | 상단 줄(로고 · '검토 요청 찾기' · 종 · 계정)만. 본문 목록은 그대로(제목, 학생 · 연구 · 검토 항목 수 · 날짜, 응답 전 n개 / 모두 응답함, 새 알림). 받은 초대·열린 시간 조율 구획도 그대로 |
| X2 검토 한 건(`/reviews/:requestId`, 그 연구가 내 연구가 아닌 계정) | 틀 없이 자체 머리 | 그대로. 계정 메뉴의 '화면 설정'이 `/account` 대신 설정 창(`display`)을 그 자리에서 엶 |
| 시간 조율(`/schedule/:pollId`, 연구 밖 참석자) | 틀 없이 단독 | 그대로 |
| 교수의 찾기 창 | 받은 요청 · 받은 검토 요청 · 계정 설정 · 사용 안내 | '계정 설정'이 설정 창을 엶 |
| 교수의 설정 창 | — | '내 계정' 묶음만 |

교수이면서 자기 연구도 있는 계정은 학생 틀을 쓰고, `/r`에 '받은 검토 요청' 구획이 함께 보입니다(지금과 같음).

검토 화면 안의 규칙(결과는 '수정 내용 확인'·'추가 수정 필요', 뒤의 것은 이유 필수, 최신 차수에만 응답, 댓글·핀·해결, 응답 변경 이력, 공유 중지 시 접근 불가 화면)은 손대지 않습니다.

## 6. 공개·로그인·가입·초대 화면

주소·내용·동작 모두 그대로입니다. 아래만 마지막 단계에서 맞춥니다.

| 대상 | 맞출 것 |
|---|---|
| 소개(`/`)·기능 둘러보기(`/features`)의 제품 미리보기 그림, 연구 만들기의 소개 그림(`IntroStage`) | 왼쪽 사이드바가 있는 예전 틀을 그리고 있음. 새 틀(상단 메뉴, 오른쪽 창)로 다시 그림. "예시 그림이에요" 표시는 유지 |
| 사용 안내(`/guide`)의 세 절(미팅 기록하기 / 수정 방법 고르기 / 교수님께 검토 요청하기) | 메뉴 이름과 위치 설명을 새 구조로 고침 |
| 사용 안내의 '화면 안내 다시 보기' | 그대로(홈에서 `?tour=1`) |
| 로그인 뒤 돌아갈 주소(`next`) | 새 주소도 `/r` 아래라 허용 목록을 바꿀 필요 없음 |

[사실, 2026-11-19 5단계 구현] 연구 만들기의 소개 그림(`IntroStage`)은 왼쪽 레일을 위쪽 줄로 바꾸고 단계 아이콘의 파란 면이 옆으로 미끄러집니다. 소개·기능 둘러보기의 제품 미리보기 창은 왼쪽 아이콘 줄을 빼고 창 위에 메뉴 넷(홈 · 미팅 · 할 일 · 글·자료)을 두어 장면의 메뉴를 켭니다(미팅 원문·검토 → 미팅, 수정 방법 → 할 일, 글 → 글·자료). 사용 안내의 세 절은 새 메뉴와 버튼 이름으로 고쳤고, 수정 방법 절의 "선택한 원문으로 AI 정리를 요청"은 연구 도우미가 기록을 전부 읽는 지금 동작(D13)에 맞게 바꿨습니다.

이번 범위 밖이지만 조사에서 확인된 어긋남(따로 고칠 일로 남김): 소개·개인정보 화면의 "가입은 초대 링크로만", "지금은 AI가 연결되지 않아" 문구가 실제 동작(초대 없이 가입 가능, AI 연결됨)과 다릅니다.
