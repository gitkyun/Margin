# 09. 상태표

화면이 정상일 때 말고 어떻게 보여야 하는지를 한곳에 모았습니다. 구현·검수할 때 이 표의 줄을 하나씩 확인합니다. 문구는 `docs/design/ux-writing.md` 형식(무엇이 안 됐는지 + 왜 + 어떻게 하면 되는지, 해요체, 입력이 남아 있는지)을 따릅니다. "지금 문구"라고 적은 것은 코드에 이미 있는 문장을 그대로 쓴다는 뜻입니다.

## 1. 모든 화면에 공통인 상태

| C19 | 항목이 아주 많음 | 기록·할 일·피드백·알림이 수백 건 | 목록은 50줄씩 그리고 끝에 [더 보기]. 찾기·필터는 전체에서. 대화 목록은 최근 100개(지금 한도) | 더 보기 |
| C20 | 휴대폰 가상 키보드 | 입력 칸에 초점 | 시트·창 높이는 보이는 화면 높이(`100dvh`, `visualViewport`) 기준. 입력창이 키보드 위에 붙고, 아래 탭 줄은 키보드가 있는 동안 숨김 | — |

## 2. 연구 도우미(AI)를 쓰는 모든 자리에 공통인 상태

해당 자리: 사이드 창 연구 도우미, 기록의 [정리하기], 피드백 상세의 수정 방법 제안, 글의 문장 점검·이어쓰기·고쳐 쓰기·수정 제안, 연구 흐름의 AI 계획 제안. 판단은 지금의 `lib/ai-availability.ts`, 문구 변환은 `lib/server-messages.ts`를 씁니다. **어떤 경우에도 결과·진행률·사용량을 지어내지 않습니다.**

## 3. 화면별 상태

### 3.1 홈 (H1)

| 상태 | 보이는 것 |
|---|---|
| 기록이 하나도 없음 | [03](03-home.md) §9. "아직 기록이 없어요." + [다음 미팅 잡기] (주) + 글자 링크 '녹음 시작' · '서면 피드백 붙여넣기' |
| 다음 미팅 없음 | 카드: "다음 미팅이 아직 없어요." + [다음 미팅 잡기] |
| 할 일 0 / 알림 0 / 최근 미팅 0 / 최근 글·자료 0 | 각 탭의 빈 문구([03](03-home.md) §9) |
| 단계 없음 | 연구 흐름 카드: "단계와 주요 목표 정하기" |
| 목적·질문 없음 | 연구 방향 카드의 빈 문구 + [적기] |
| 주 행동의 대상이 그사이 사라짐 | 누르면 대상이 없을 때: 홈을 새로 계산해 다음 순서의 주 행동을 보여 줌 |
| 공동연구자의 '나만 보기' 기록 | 수·목록에 포함하지 않음 |

### 3.2 미팅 (M1)

| 자리 | 상태 | 보이는 것 |
|---|---|---|
| 목록 | 기록 없음 | "아직 미팅 기록이 없어요." + [기록 추가] |
| 목록 | 찾기·칩 결과 없음 | "조건에 맞는 기록이 없어요." + [조건 지우기] |
| 목록 | `type=review`인데 검토 요청 없음 | "아직 검토 요청이 없어요." + [교수님께 검토 요청]. 수정 결과도 없으면 "수정 결과를 남기면 검토를 요청할 수 있어요." |
| 기록 | 없는 id, 다른 연구의 기록 | 오른쪽에 "이 기록을 열 수 없어요. 보관했거나 볼 수 없는 기록이에요." 목록은 그대로 |
| 기록 | 보관한 기록을 주소로 엶 | 위에 띠 "보관한 기록이에요." + [복원]. 읽기 전용 |
| 기록 | 취소한 미팅 | 띠 "취소한 미팅이에요." + [취소 되돌리기] |
| 준비 | 준비한 것이 하나도 없음 | 각 구획의 빈 문구: "가져갈 할 일이 없어요." "보여 줄 글·자료가 없어요." "물어볼 질문이 없어요." |
| 준비 | 연결한 할 일·자료·질문이 보관·삭제됨 | 그 줄을 흐리게 "보관한 할 일" + [빼기]. 저절로 빼지 않음 |
| 준비 | 다른 창에서 같은 준비를 고침 | C9. 목록 조작은 되돌린 뒤 새로 불러옴 |
| 원문 | 전사도 메모도 없음(기록 완료인데 비어 있음) | "아직 적은 내용이 없어요." + 메모 칸 + [녹음 시작] |
| 원문 | 전사 불러오기 실패 | 전사 자리에 C11. 메모 보기는 동작 |
| 원문 | 남이 녹음한 기록 | "전사문은 녹음한 사람만 볼 수 있어요." 음성 공유가 켜져 있으면 재생은 됨 |
| 원문 | 음성 파일 불러오기 실패 | 재생 줄에 "녹음을 불러오지 못했어요." + [다시 시도]. 전사는 보임 |
| 원문 | 메모가 50,000자에 가까움 | 49,000자부터 칸 아래 "49,120 / 50,000자". 넘으면 저장을 막고 "50,000자까지 저장할 수 있어요." |
| 원문 | 형광펜 200개 | "형광펜은 한 기록에 200개까지 칠할 수 있어요." |
| 원문 | 표시의 위치를 못 찾음 | [08](08-data.md) §4.6. 밑줄 없이 오른쪽 열에만 |

### 3.3 검토 요청·시간 조율 (M3, M4)

## 5. 겹쳐 일어나는 경우

| 경우 | 처리 |
