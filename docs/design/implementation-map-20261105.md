## 효과와 라이브러리의 실제 사용

| 요청한 참고/라이브러리 | 실제 반영 | 구분 |
|---|---|---|
| Wanted 참고 | Pretendard·주 행동 파란색·중립색·얇은 경계·정보 위계 | RMS 토큰으로 변형. 공식 Wanted 디자인 시스템 구현이라는 뜻은 아님 |
| LiquidGlass | 소개 헤더의 장식 배경만 광학 처리 | 실제 `@ybouane/liquidglass@1.0.3`. 로그인 후 굴절 제거 |
| Magic Card | 소개 기능·홈 AI 요약·AI 오버뷰의 절제된 포인터 강조 | Motion으로 직접 만든 유사 패턴. Magic UI 공식 소스나 패키지를 설치한 것은 아님 |
| Animated List | 실제 알림·작업 이력의 등장 | Motion 자체 구현. 가짜 사건·반복 대기 없음 |
| Dock | 글쓰기 하단 서식 바와 버튼 반응 | Motion 자체 구현. 기본 터치·키보드 행동 유지 |
| Progressive Blur | 하단 도크와 스크롤 경계 | CSS 그라데이션. 독립 라이브러리 없음 |
| Dither Field·영상 도트 | 소개의 회전 점 구체와 AI 작업 중 도트 | Canvas 자체 구현. Dither Field의 디더링 소스는 채택하지 않음 |
| Theme Toggler | 계정 설정의 테마 선택 | 현재 테마 코드·Segments 사용. Magic UI 별도 토글러는 미사용 |
| Typing Animation | 미사용 | AI 응답을 일부러 늦추지 않음. 소개 기능 예시 전환 사용 |
| File Tree | 실제 중첩 폴더 탐색 | 데이터 기반 자체 트리. 보관·복원 가능 |
| Aceternity cloud shader | 미사용 | WebGL 구름 의존성을 더하지 않고 기존 도트·CSS 배경 유지 |
| Radix | 메뉴·선택자·대화상자의 열기·닫기·포커스 | 신규 shadcn 화면 템플릿 추가 없음. 과거 공통 래퍼는 보존 |
| Compass 1.0.14 | 검색 지우기·입력 복귀, 선택 메뉴의 여백·체크 영역, 둥근 필터·다크 선택 표면 | 공식 레지스트리와 정책 확인 후 RMS 자체 구현. 전체 설치·소스 복사 없음. [적용 판단](compass-adoption-20261105.md) |
| 브라우저 음성 인식 | ko-KR 실시간 중간/확정 문장·재연결 | Web Speech API. 외부 제공자 서버 처리 가능성을 동의 화면에 안내. Gemini 생성 호출과 별개 |
| Tiptap | 실제 문서 편집 | 무료 코어. 유료 버전관리 서비스는 미사용 |
| React PDF / PDF.js | 한글 고정 PDF 생성 / 업로드 PDF 열람 | 다른 역할. 새 파일도 비공개 Storage에 보존 |
| FullCalendar | 무료 월·주·목록 보기 | 유료 리소스/타임라인 플러그인 없음 |
| React Flow | 단계 연결과 위치 편집 | 기본 시간순 보기와 분리 |

정적인 그림을 연구 분석 결과처럼 표시하거나, 연구 품질 점수·가짜 사용량·지원하지 않는 회사 모델을 만들지 않았다. 움직임은 동작 감소 설정을 따르도록 작성했지만 OS·실기기 조합 검사는 남아 있다.

## 이번에 고친 저장 문제

- AI 채택과 실제 기록 생성이 한 번의 서버 처리로 끝나도록 수정. 같은 채택 재시도는 같은 기록 반환.
- 실행 전에 중단 요청이 도착하거나 중단 후 결과가 늦게 도착해도 후보를 자동 생성하지 않음.
- 개인 첨부의 실제 Storage MIME와 기록의 MIME가 다르면 거부.
- 공동 문서의 오래된 저장을 거부하고 오류 응답이 끊긴 경우에도 최신본 대조.
- 제목만 바꾼 초안, 재접속 전 작성본, 업로드 완료 후 자료 연결 실패 복구.
- 선택 문단 정보가 없거나 버전이 달라지면 전체 원고로 몰래 대체하지 않고 재선택 안내.

참고 사이트 관찰과 RMS 적용 판단은 [Modulify 확인 기록](modulify-audit-20261105/README.md)에 정리했다. 사용자가 추가로 지정한 Compass의 적용 범위는 위 별도 기록을 따른다. 후속 작업은 실제 검증과 발견된 오류 수정이다.
