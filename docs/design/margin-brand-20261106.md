# Margin 브랜드·연구 도우미 적용 · 2026-11-06

## 적용 기준

사용자가 제공한 Margin SVG와 16개 표정 PNG를 사용했다. 서비스 표기는 **Margin**, AI의 역할명은 **연구 도우미**로 둔다. 캐릭터의 별도 이름은 확정하지 않았다. 연구의 판단·교수의 확인을 캐릭터가 대신하는 것으로 표현하지 않는다.

원본은 수정하지 않았다. SVG 9개는 `public/brand/source-svg`, 캐릭터 16개는 `public/brand/mascot`에 복사했다. 원본 파일명·복사 경로·SHA-256은 `public/brand/sources.json`에 기록했다. 원본 경로·계정 정보는 공개 자산에 넣지 않는다.

## 로고와 표면

| 위치 | 실제 적용 |
|---|---|
| 소개·기능·플랜·사용 안내·로그인·가입의 공통 헤더/푸터 | 제공한 심벌 + SVG 워드마크 |
| 로그인 후 사이드바 | 같은 심벌·워드마크. 기존 연구 전환·접힘 동작 유지 |
| 교수 검토·접근 불가 화면 | 같은 브랜드. 교수의 제한된 검토 탐색 유지 |
| 브라우저 제목·파비콘 | Margin 문구·제공 심벌 SVG |
| 소개 하단의 파란 시작 영역 | 흰 심벌 |
| 검토용 PDF 작성자 메타데이터 | Margin. 연구 문서 내용에 로고·캐릭터를 삽입하지 않음 |

라이트 심벌은 `Margin_Symbol 1.svg`, 다크·반전 심벌은 `Margin_Symbol 4.svg`를 사용한다. 워드마크는 라이트 `margin.svg`, 다크 `margin-2.svg`를 사용한다. 이 별칭 파일들도 원본 바이트를 그대로 유지한다. 이전 RMS 저장 키·주소·파일명·서버 설정은 호환을 위해 바꾸지 않는다.

캐릭터 PNG는 투명 이미지가 아니라 **파란 배경이 포함된 정사각형**이다. 배경을 임의로 삭제하지 않고 둥근 타일로 사용한다. 큰 환영 장면 100px, 작업 현황 80px, 홈 진입 64px, 작업 패널 40px, 대화 작성자 28px, 탐색 24px로 위계를 구분한다. 일반 버튼·모든 빈 목록·교수 응답에 반복해서 넣지 않는다.

03 question, 05 working, 14 happy, 15 approved는 파일과 공통 상태 매핑을 보존하되 현재 화면에 억지로 배치하지 않았다. 특히 15 approved를 교수 확인·논문 품질 판정으로 사용하지 않는다.

실제 실행 중에만 작은 호흡 효과가 켜진다. 일반 대기 상태는 정지하며 동작 감소 설정에서는 효과를 끈다. 이미지가 상태 설명을 대신하지 않도록 장식 이미지로 처리하고 옆 문구로 상태를 전달한다.

## 모델·검토 방식

Liner·Modulify 참고에서 가져온 것은 **작업 문맥, 첨부, 모델, 처리 방식을 가까이 두는 구조**다. 코딩 도구의 용어·모델 목록·캐릭터는 가져오지 않는다.

- 대화창: `도움받을 작업` → `AI 모델` → `검토 깊이` → 전송/중단.
- 미팅·피드백 보조 패널: 접어서 여는 `이번 검토 설정`에서 모델과 깊이를 선택하고 실제 요청에 전달한다.
- 계정 설정: 기본 모델·기본 검토 깊이를 저장한다.
- 작업 오버뷰의 화면명은 `작업 현황`, 수정 설계는 `수정 방안`, 집필 검토는 `원고 검토`로 다듬었다.

| 사용자에게 보이는 말 | 서버 값 | 설명 |
|---|---|---|
| 핵심만 | minimal | 핵심과 다음 행동 중심 |
| 차근차근 | medium | 근거·이유를 함께 검토 |
| 꼼꼼하게 | high | 자세한 검토에 쓰며 시간이 더 걸릴 수 있음 |

선택지는 서버의 현재 모델 기능 목록에 있는 값만 표시한다. 지원하지 않는 깊이는 숨기고, 모델을 바꾸면 가능한 값으로 정리한다. 모델명·버전은 실제 모델 식별자를 유지한다. 연결되지 않은 타사 모델, 가짜 지능 등급·정확도·사용량은 추가하지 않았다. 위 설명은 검토 방향을 이해시키기 위한 UI 안내이며 일정한 품질·길이를 보장하는 수치가 아니다.

## 변경 경계와 확인

- 기존 로그인·저장·권한·원문 범위·제안 채택·교수 결과 구조는 유지했다.
- 녹음·한국어 전사 구현은 수정하지 않았다.
- 원본 25개와 복사본의 해시 일치, 모든 자산의 빌드 포함, 파비콘 일치, SVG XML을 확인했다.
- TypeScript와 배포용 빌드 통과. 22개 파일의 자동 검사 91개 통과.
- 큰 앱/PDF 청크 경고는 기존대로 남아 있다. 로딩 시간 실측을 한 것은 아니다.
- 사용자가 화면 검증을 직접 맡기로 해 이번 변경의 브라우저 시각 검사를 반복하지 않았다.
- Gemini 실호출은 키 연결 전이므로 검증하지 않았다. 모델 UI와 요청 전달 구현을 실제 생성 성공으로 보고하지 않는다.
- 배포·GitHub 수정·푸시는 실행하지 않았다. 배포는 사용자의 재개 요청을 기다린다.
