# 다른 AI가 만든 RMS 화면 확인 · 2026-11-05

출처: https://rms.modulify.website

공개 사이트의 소개·연구 홈·글쓰기·버전 비교·검토 화면과 모바일 소개를 열어 관찰했다. 실제 계정으로 로그인해 서버 저장·AI·교수 응답·권한을 검증하지 않았다. 공개 예시는 표시된 화면의 동작만 확인한 근거다.

| 관찰 | RMS에 반영한 판단 |
|---|---|
| 홈에서 연구의 현재 위치와 준비 항목이 가까이 있음 | 단계·다음 미팅을 먼저 두고 실제 결과/작업/질문을 나눠 배치 |
| 숫자보다 항목의 다음 행동이 잘 보임 | 실제 연결 기록의 제목과 바로가기 노출. 근거 없는 품질/진행 점수 제외 |
| 글쓰기와 비교가 같은 작업 맥락 안에 있음 | 편집·버전 비교·복원·PDF를 같은 문서에서 처리 |
| 검토 자료와 응답이 나란히 있음 | 학생 공통 셸을 유지하고 교수는 공유 항목 중심으로 읽기 |
| 공개 소개가 기록→수정→검토 흐름을 설명함 | 기존 RMS 소개의 기능 예시와 이동을 유지하고 기능 카드 반응 보강 |

RMS의 회원가입 범위·개인 기록 비공개·지정 교수 접근·검토 차수 보존·실제 AI 여부는 기존 사용자 결정과 서버 규칙을 따른다. 참고 사이트의 UI가 쉽다는 사용자 검증 결과로 확대하지 않는다. 외부 사이트의 브랜드 자산·소스는 복제하지 않았다.
