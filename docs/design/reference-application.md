# 첨부 참고자료 적용표

2026-11-03 · 승인된 계획의 관찰과 채택 범위

번호는 사용자가 제공한 48장 이미지 순서다. 아래는 화면에서 보인 요소의 관찰과 RMS 설계 선택이다. 해당 서비스에 로그인해 동작을 검증했거나 RMS 사용자가 쉽게 쓸 것이라는 실증 결과가 아니다. 브랜드·원본 사진·이미지 픽셀은 배포 앱에 복제하지 않았다.

| 번호 | 화면에서 관찰 | RMS 적용 | 제외·후속 |
|---|---|---|---|
|1|작업 요약·현재 처리·세부 구획|AI 실행 대상과 결과를 분리|캐릭터·도구 사용 통계 제외|
|2|핵심 상태와 보조 수치의 위계|검토 결과를 먼저 표시|연구 점수·게이지 제외|
|3|요약→필터→상세 목록|검토 상태 필터와 원본 이동|분석 차트 제외|
|4|입력과 결과가 같은 영역|필요할 때 여는 AI 보조|상시 채팅창 제외|
|5|작은 움직임과 짧은 상태 문구|AI 처리 중 도트와 상태|평상시 정지·퍼센트 없음|
|6|펼침·접힘·현재 위치가 분명한 메뉴|학생 사이드바의 주요 배치 참고|업무와 무관한 메뉴 제외|
|7|크기 다른 구획의 정렬|다음 미팅 중심 비대칭 홈|통계 대시보드 제외|
|8|도트로 분포 표시|작은 처리 표시의 질감만|가짜 연구 분포 없음|
|9|재생 위치와 실제 상태|후속 녹음 UI 참고|현재 가짜 파형 없음|
|10|선택과 결과가 가까움|AI 범위와 실행 요약 인접|비용 계산기 기능 제외|
|11|같은 작업의 다른 상태 비교|당시 검토본과 현재 결과 구별|실시간 공동편집 제외|
|12|필터·목록·상세 구획|검토 목록 상태 필터|장식 지표 제외|
|13|설정 탐색과 입력 분리|연구·계정 설정|불필요한 설정 축소|
|14|단계와 세부 행 연결|후속 로드맵 참고|전환율 그래프 제외|
|15|선택한 항목과 차이 설명|수정 방안 비교|인기·최적 뱃지 없음|
|16|공유 대상·권한·링크 분리|지정 교수·중지·복사 구분|공개 링크 기능 없음|
|17|미팅 핵심과 추가 정보 접기|미팅 목록·상세 위계|녹음·참석 응답 제외|
|18|선택 항목 옆에 대화|검토 항목과 댓글 동시 읽기|별도 메신저 제외|
|19|숫자·메타정보의 절제된 강조|날짜·버전·차수 숫자 정렬|긴 한글 고정폭 글꼴 없음|
|20|대상과 비교 열이 명확|자료·피드백 목록 열|순위표 제외|
|21|실행 작업과 상태 인접|AI 대상·진행·중단 같은 영역|에이전트 운영 통계 없음|
|22|빈 공간에서 다음 행동 안내|첫 연구·미팅·자료 안내|커뮤니티 기능 없음|
|23|작은 영역에 실제 요약|홈의 실제 건수|근거 없는 완성도 없음|
|24|상태·최근 변경·세부 밀도|파일·저장 상태|서버 운영 지표 없음|
|25|알림 종류와 수신 설정|서비스 내 새 응답 표시|외부 알림은 후속|
|26|9번과 같은 팟캐스트 화면|후속 녹음·전사 참고|현재 파형 없음|
|27|기본 입력과 옵션·완료 분리|연구·미팅 생성 폼|가격·커뮤니티 설정 없음|
|28|파일별 진행·실패·취소|PDF 업로드와 연결 재시도|실제 전송만 백분율 표시|
|29|계정 행동과 공간 전환 묶음|계정 메뉴·테마, 연구 전환 분리|유료 요금 메뉴 없음|
|30|작업 제목·상태·기한 위계|할 일 목록의 주요 참고|하위 작업 없는 진행률 없음|
|31|다크 설정에도 같은 구획|두 테마의 구조·행동 일치|밝기만 바꾼 별도 기능 없음|
|32|관계와 판단 대상 노출|피드백→작업→결과 링크|기본 노드 그래프 없음|
|33|선택 행 행동 분리|목록 행동 위치 참고|교수 일괄 승인 없음|
|34|요약에서 실제 처리 목록 이동|홈→원래 항목 직접 이동|AI 신뢰도 점수 없음|
|35|간결한 그림과 문장|작은 빈 상태 표현 참고|사진·픽셀 복제 없음|
|36|제목과 행 구분의 위계|미팅·자료 행 목록|과도한 카드 중첩 축소|
|37|주의 항목과 다음 행동 인접|새 교수 응답 우선|예측 차트 없음|
|38|안정된 검색·필터·열|자료·피드백·요청 목록|통합 검색은 후속|
|39|본문과 검토 준비를 병렬 배치|검토 설명·PDF·응답의 주요 참고|기관 승인 단계 제외|
|40|요청 대상·제목·상태 행|검토 요청 목록|요청 전체 승인 상태 없음|
|41|정보와 대응 버튼 인접|추가 수정 응답→수정 결과|불필요한 운영 지표 없음|
|42|제품 설명·화면·진입 위계|후속 소개 페이지 참고|현재 로그인 후 화면에 미적용|
|43|오류 후 복귀 행동 분명|없음·접근 불가와 복귀|장식 이미지 복제 없음|
|44|작업 목록과 재사용 항목 구획|목록 구획만 참고|템플릿 마켓 없음|
|45|필터를 열어도 본문 위치 유지|복잡한 필터의 후속 참고|필터 전용 큰 사이드바 없음|
|46|유리 표면과 도트 질감|일부 부유 영역·로그인 참고|본문 장식 배경 없음|
|47|알림 옆 패널과 원래 화면 유지|알림 패널 주요 참고|별도 전체 화면 이동 없음|
|48|사건·작성자·변경 내용 함께 표시|무엇이 바뀌었는지 알림 문장|댓글 해결과 교수 결과 분리|

영상의 점 형태는 AI 처리 중 작은 도트로 변형한다. 평소에는 정지하고 동작 감소 설정을 따른다. 영상 자체나 입체 효과를 제품 기능으로 추가하지 않는다.

Wanted 원본 스타일을 그대로 사용하는 대신 한글 가독성을 위해 Pretendard를 기본으로 쓴다. 확정 토큰과 구현 규칙은 [앱 DESIGN.md](../../apps/home-preview/DESIGN.md), 실제 확인 기록은 [화면 검증](../../apps/home-preview/design-qa.md)을 따른다.

## 공식 출처와 구현 선택

- [shadcn/ui](https://ui.shadcn.com/docs): 공통 입력·메뉴·대화상자·시트·표·상태 구성의 출발점. 도메인 흐름은 자체 구현한다.
- [Disarto Icons](https://github.com/Disarto/disarto-icons): MIT 일반형 아이콘, 선택한 export만 정적 import한다.
- [Pretendard](https://github.com/orioncactus/pretendard): 자체 호스팅과 OFL 고지.
- [PDF.js](https://github.com/mozilla/pdf.js): 실제 파일 페이지·확대·텍스트·다운로드.
- [Morphing Icons](https://benji.org/morphing-icons-with-claude): 상태 전환 아이디어 참고, 코드 복제 없음.
- [Skullet](https://skullet.lochie.me/): 이번 의존성으로 채택하지 않음.
- [GetDesign Wanted 참고](https://www.getdesign.kr/services/wanted): 비공식 시각 참고. 채용 제품 기능·마케팅 문구를 요구사항으로 가져오지 않는다.
