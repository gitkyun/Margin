# 워킹 목업 화면별 동작

2026-11-03 · 승인된 초기 시연 범위의 구현 기준

## 공통

현재 대상→필요한 정보→지금 할 행동→연결 이력 순서로 배치한다. 저장하는 폼은 서버 값과 작성 초안을 분리하고 취소는 초안만 버린다. 네트워크 저장 성공 전 완료로 표시하지 않는다. 실패하면 입력과 재시도 경로를 남긴다. 응답 유실 재시도에는 같은 초안 UUID·요청 키를 사용한다. 다른 창의 변경은 충돌로 알린다.

메모는 800ms 이후와 포커스 이동 시 자동 저장한다. 미저장 메모는 세션 임시 보관하고 저장 원문의 내용·차수를 함께 보관한다. 충돌하면 자동 저장을 멈추고 저장본·내 작성본을 비교한 뒤 선택한다. AI 생성 중단·늦은 응답은 원문이나 저장 기록을 바꾸지 않는다.

## 화면과 경로

| 화면·경로 | 먼저 보이는 정보 | 입력과 행동 | 저장·취소·실패·연결 |
|---|---|---|---|
| 로그인 `/login` | 이메일·비밀번호와 발급 계정 안내 | 두 입력 필수, 로그인 | 실패 이유 안내. 성공 후 원래 검토 경로 복귀. 외부 복귀 주소 금지 |
| 연구 선택 `/r` | 내 연구 이름·설명·남은 작업 | 연구 만들기: 이름 필수, 설명 선택 | 저장 후 새 연구 홈. 취소하면 생성하지 않음 |
| 홈 `/r/:id` | 다음 미팅 목표→새 교수 응답→준비 작업→질문·자료 | 미팅 준비·원문·응답 원래 항목으로 이동 | 표시 건수는 같은 실제 기록. 할 일 완료로 교수 상태를 바꾸지 않음 |
| 미팅 목록 `/r/:id/meetings` | 일정·기록 상태·미리보기 | 미팅 이름 필수, 날짜·시각 선택. 날짜 미정 생성 가능 | 생성 후 해당 미팅 준비. 오류 입력 유지. 목록 검색·상태 필터 |
| 미팅 상세 `.../meetings/:meetingId` | 준비 / 기록 / 결정·질문 | 준비 목표와 작업·보존 버전·질문 선택. 메모는 별도 | 준비 저장은 질문과 연결을 한 트랜잭션에 저장. 취소 시 원본 유지. 다음 미팅 선택은 명시적 |
| 피드백 `.../feedback/:feedbackId` | 피드백 원문·출처→학생 메모→수정 방안→작업 | 직접 피드백 제목·내용 필수. AI 범위 확인 후 실행 | 채택은 방안 저장이며 반영 완료 아님. 방법을 할 일로 옮길 때 학생이 제목·내용 편집 |
| 할 일 `.../tasks/:taskId` | 제목·설명→진행·기한·우선순위→미팅 | 제목 필수, 설명·기한·연결 선택 | 할 일은 복제하지 않고 여러 미팅에 연결. 이월은 준비 연결 변경이며 기한 자동 변경 없음 |
| 자료 `.../materials/:materialId` | 파일/외부 링크→버전→실제 PDF→연결 기록 | 자료 이름 필수, 유형. 파일 또는 안전한 URL. PDF 최대20MiB | 업로드와 기록 연결 구분. 전송 성공 뒤 연결만 실패하면 재전송 없이 재연결. 이전 파일 불변 |
| 수정 결과 `.../results/:resultId` | 바꾼 내용→피드백·작업→근거·위치→검토 이력 | 제목·설명 필수. 문서 수정은 보존 PDF·확인 위치 필수 | 개인 결과를 수정해도 보낸 차수는 불변. 저장 후 검토 요청으로 선택 |
| 검토 목록 `.../reviews` | 제목·지정 교수·공유 상태·항목별 응답 건수 | 결과 여러 개 선택, 요청 제목·교수 이메일 필수 | 공개 미리보기에서 보낼 범위를 확인한 뒤 저장. 링크 복사, 발송은 사용자가 수행 |
| 학생 검토 `/reviews/:requestId` | 항목 목록→차수·당시 설명·파일→응답·댓글 | 댓글·답글, 자기 결과 편집으로 이동, 항목별 재확인 | 학생은 교수 응답 불가. 재확인 새 차수. 중지 후 이후 접근 차단. 다운로드 회수는 불가 |
| 교수 검토 같은 주소 | 보낸 학생·요청→선택 항목→당시 파일→응답 | 수정 내용 확인 / 추가 수정 필요, 후자는 이유 필수. 댓글·답글 | 지정 계정만 접근. 최신 차수 응답, 변경 전 작성자·시각 이력 보존. 비공개 메모·후보는 없음 |
| 공통 알림·설정 | 새 응답 대상·변경·시각 / 계정·테마 | 관련 항목으로 이동, 테마, 로그아웃 | 읽음은 개인 상태. 학생 반영·작업 완료·교수 결과·댓글 해결과 독립 |

## 상태 문구

- `저장 중` → 실제 서버 성공 후 `저장됨`. 로컬은 `로컬 저장됨`으로 구별한다.
- 저장 실패: `저장하지 못했습니다. 작성한 내용은 남아 있습니다.` + 다시 저장.
- AI: 사용할 원문·길이·차수를 먼저 표시한다. 원문에 있는 내용 / 제안 방법 / 가정을 구분한다.
- 없음·검색 결과 없음·불러오기 실패·접근 불가는 서로 다른 상태다.
- 교수 표현은 ‘승인·재검토’로 바꾸지 않는다. 요청 전체를 승인했다고 표현하지 않는다.

## 화면 크기와 후속

1440·1280에서는 읽기·보조 구획을 병렬 배치하고 768에서는 구획을 줄이며 390에서는 한 열·메뉴 접기를 사용한다. 검토는 작은 화면에서 자료/응답 탭으로 전환한다. PDF가 확대되면 파일 영역 내부에서만 스크롤한다.

로드맵·마일스톤·투고 일정, 녹음·전사, 전체 통합 검색, 소개 페이지는 초기 대표 시연 이후 확장한다. 기존 기획 범위에서 삭제한 결정은 아니다. 화면 위계와 실제 사용성은 배포 시연·사용자 검증에서 다시 확인한다.
