# 마진 UI 품질 기준

화면을 만들거나 고친 뒤 확인하는 기준입니다. 문구 기준은 [UX 라이팅 원칙](ux-writing.md), 시각 값(색·크기·모서리·테마)은 [디자인 기준](README.md)의 Montage를 따릅니다. 코드 검사가 통과해도 아래 항목은 **렌더링된 화면에서** 확인합니다.

## 1. 확인 범위

| 항목 | 기준 |
|---|---|
| 너비 | 360 · 390(모바일), 768(태블릿), 1024 · 1440(데스크톱) |
| 테마 | 라이트 · 다크 (시스템 설정 기본). 첫 화면부터 저장한 테마로 그려지는지, 새로고침 후 유지되는지 |
| 동작 | 실제로 스크롤·입력·클릭·키보드 이동 |
| 상태 | 빈 화면, 로딩, 저장 중·저장 실패, 오류, 긴 내용 |
| 움직임 | `prefers-reduced-motion: reduce`에서 멈추거나 줄어드는지 |

로그인 후 화면은 Supabase 환경값 없이 실행한 **미리보기 모드**에서 데모 데이터로 확인할 수 있습니다(실제 서버 저장 검증을 대신하지 않음).

```bash
cd apps/home-preview
VITE_SUPABASE_URL= VITE_SUPABASE_PUBLISHABLE_KEY= npm run dev -- --port 5174
```

미리보기 연구 ID는 브라우저마다 새로 만들어집니다. `/r`에서 연구를 연 뒤 주소를 씁니다.

## 2. 한국어 줄바꿈과 잘림

마진에서 가장 자주 생기는 문제입니다.

**전역 규칙** (`src/styles.css`의 `body`)

- `word-break: keep-all`: 단어 중간(‘연/구’)에서 줄을 바꾸지 않습니다.
- `overflow-wrap: break-word`: 공백 없는 긴 파일명·URL은 끊어서 영역 밖으로 나가지 않게 합니다. 좁은 flex/grid 안의 긴 토큰에는 해당 요소에 `overflow-wrap: anywhere`를 씁니다.
- 제목 `text-wrap: balance`, 본문·라벨 `text-wrap: pretty`: 마지막 줄에 한두 글자만 남는 것을 줄입니다(지원 브라우저에서 점진 적용).

**확인할 것**

- 제목·설명의 마지막 줄에 조사나 한두 글자만 떨어지지 않는가
- 버튼·탭·배지·카드·모달 글자가 잘리거나 줄바꿈되어 높이가 들쭉날쭉하지 않은가
- 긴 연구 제목·파일명·피드백·댓글이 영역을 벗어나지 않는가
- 고정 높이·`overflow: hidden`·`line-clamp`·`white-space: nowrap`이 **중요한 내용**을 숨기지 않는가. 목록의 보조 설명은 줄일 수 있지만 원문은 상세 화면에서 전부 읽을 수 있어야 합니다.
- 문구를 바꾼 뒤 주변 요소가 밀리거나 겹치지 않는가

**고치는 순서**: 문장 길이 → 컨테이너 크기·배치 → 줄바꿈 규칙. 글꼴을 줄이거나 문장을 잘라서 맞추지 않습니다. 강제 개행(`<br>`)은 소개 화면의 큰 제목에만 쓰고, 좁은 화면에서 어색하면 너비별로 풀어 줍니다.

## 3. 접근성 (WCAG 2.2 AA)

| 항목 | 기준 |
|---|---|
| 색 | Montage 시맨틱 토큰을 그대로 씁니다. 대비를 맞추려고 별도 색을 만들지 않습니다(2026-11-09 결정). 대비 검사는 참고로만 기록합니다. |
| 누를 수 있는 크기 | 최소 24×24px(문장 속 링크 제외). 주 버튼 44px 이상 권장. |
| 이름 | 보이는 글자가 있으면 접근성 이름에 그 글자가 들어가야 합니다(2.5.3). 아이콘 버튼은 동작을 이름으로. |
| 키보드 | 모든 동작을 Tab·Enter·Space·Esc로. 포커스 표시가 보여야 하고 순서가 화면 순서와 같아야 합니다. ‘본문으로 이동’ 링크 유지. |
| 대화상자 | 열면 포커스가 안으로, Esc로 닫히고 닫으면 연 버튼으로 돌아옵니다. |
| 폼 | 모든 입력에 보이는 라벨. 오류는 입력 옆에 글자로(색만으로 표시하지 않음). |
| 상태 구분 | 상태를 색만으로 구분하지 않고 글자를 함께 씁니다. |
| 움직임 | 동작 줄이기 설정에서 장식 애니메이션을 멈춥니다. |
| 한글 입력 | 조합 중(IME) Enter로 전송·저장되지 않아야 합니다(`isComposing` 확인). |

## 4. 디자인 시스템 일관성

- 색·간격·모서리·버튼 높이·너비 기준은 [디자인 기준](README.md)의 Montage 토큰과 컴포넌트를 씁니다. 화면 하나에만 임시 값을 넣기 전에 Montage에서 고를 수 있는지 먼저 봅니다.
- `[data-slot="button"]`으로 버튼 모양을 덮지 않습니다(배치만).
- 9~11px 글자는 장식용 미리보기 외에는 쓰지 않습니다.

## 5. 검수 도구

| 도구 | 쓰는 곳 |
|---|---|
| 브라우저 직접 확인 | 모든 변경. 스크롤·입력·클릭·키보드 |
| `apps/home-preview/scripts/qa/screens.mjs` | 미리보기 모드에서 25개 화면 × 너비 × 테마 캡처, 아래 자동 검사, 역할별 계산된 스타일 비교(`capture` → `compare`). 설치된 Chrome만 쓰고 결과는 임시 폴더에 둡니다(커밋하지 않음). 화면 목록은 `scripts/qa/routes.mjs` |
| axe-core | WCAG 2.2 AA 자동 검사(대비·이름·구조) |
| Stageshow `scripts/layout.mjs` | 컨트롤·여백 맞춤 검사. `film.mjs --gate`는 Stageshow 키트로 만든 무대(`.ss-stage`)에서만 동작하므로 일반 화면에는 쓰지 않습니다. |

자동 검사로 찾는 것: 마지막 줄 한두 글자(줄 폭 < 글자 크기×2.3), `overflow`·`ellipsis`·`line-clamp`로 숨겨진 글자, 가로 스크롤, 화면 밖으로 나간 글자, 24px 미만 대상, 보이는 글자와 접근성 이름 불일치, axe 위반.

자동 검사는 시작점입니다. 결과마다 화면을 직접 보고 판단합니다.

## 6. 반복해서 생긴 문제와 해결

2026-11-08~09 전체 검수(5개 너비 × 라이트·다크 × 21개 화면, 교수 검토 화면 포함)에서 나온 문제와 해결입니다. 비슷한 화면을 만들 때 같은 실수를 반복하지 않도록 남깁니다.

| 문제 | 원인 | 해결 (위치) |
|---|---|---|
| 하단 푸터가 흐리게 보임 | 푸터 `opacity: .75` | 푸터 불투명. 글자색은 Montage 토큰(2026-11-09부터) |
| ‘연/구’처럼 단어 중간 줄바꿈, 마지막 줄 한두 글자 | 앱 본문에 `keep-all` 없음 | `body { word-break: keep-all; overflow-wrap: break-word }`, 제목 `balance`, 본문 `pretty` (`styles.css`) |
| 긴 제목이 편집 버튼을 화면 밖으로 밀어냄(1440px에서도) | flex 제목 칸이 `min-width:auto`, 셸 `overflow: clip`이 넘침을 숨김 | 제목 칸 `min-width:0`, `.page-title { overflow-wrap:anywhere }` |
| 긴 이름이 대화상자를 화면보다 넓힘 | 대화상자 grid 자동 열이 가장 긴 토큰 폭을 가짐 | `grid-template-columns: minmax(0,1fr)`, 자식 `min-width:0` |
| 다른 화면의 클래스 이름을 재사용해 카드가 한 줄로 찌그러짐 | `.feedback-origin`(인라인 라벨용)을 카드에 사용 | 카드 범위 재정의. 새 클래스 이름은 검색 후 정함 |
| 360px 설정 탭이 2~3줄로 찌그러짐 | 가로 flex 항목이 줄어듦 | 한 줄 가로 스크롤, 항목 `flex:none; nowrap` |
| 좁은 입력창 선택 버튼이 ‘연구 …’로 잘림 | 4개 컨트롤이 한 줄 고정 | 480px 이하에서 선택 버튼만 첫 줄로 (`order:-1`) |
| 새 슬로건이 360px에서 4줄 | 52px 고정 | `clamp(34px, 11.6vw, 52px)`로 두 줄 유지 |
| 대화상자를 닫으면 포커스가 페이지 맨 앞으로 | 상태로 연 대화상자 + 자식의 `autoFocus`가 Radix보다 먼저 포커스를 옮김 | `Dialog`/`Sheet` 루트가 열리는 렌더에서 포커스를 기억했다 복귀 (`components/ui/dialog.jsx`, `sheet.jsx`) |
| 한글 조합 중 Enter로 질문 추가·선택·전송 | `keydown`에서 `isComposing` 미확인 | `!e.nativeEvent.isComposing` (`src/lib/ime.ts`의 `isImeComposing`, 테스트: `tests/ime.test.tsx`) |
| 24px 미만 텍스트 링크·요약 | 인라인 링크 높이 18~21px | `min-height: 24px`(셸·푸터·PDF 요약·이력 버튼) |
| 선택 상자 이름이 보이는 값과 다름 | `aria-label`이 라벨만 | ‘라벨, 현재 값’으로 이름 지정 (`components/experience.tsx`) |
| 서버 오류가 합니다체·영문 필드 키(‘title 입력을…’)로 보임 | DB/Edge Function 문구를 그대로 표시 | `src/lib/server-messages.ts`로 변환, 모든 throw 지점에서 적용 |
| 녹음 2시간 안내와 달리 50MB 초과로 저장 실패 가능 | 브라우저 기본 비트레이트 64~128kbps | `audioBitsPerSecond: 32000` (2시간 약 29MB) |

**의도적으로 남긴 것**: 목록의 보조 설명(할 일, 수정 결과)은 좁은 화면에서 2줄까지만 보이고 상세 화면에서 전부 읽습니다. 체크박스(17~18px)는 주변 간격으로 24px 원이 겹치지 않아 WCAG 2.5.8 간격 예외에 해당합니다. 검사 스크립트의 `sr-only` 라벨 잘림은 의도된 숨김입니다.

**검수 결과 요약(2026-11-09 개편 시점)**: axe 위반 320곳 → 10곳 이하, 마지막 줄 한두 글자 44곳 → 1곳, 가로 스크롤 0건(전 너비·테마). Montage 전환 뒤 색 대비 수치는 다시 재지 않았고 기준에서 뺐습니다.
