## B. 공통 틀 (셸)

- 상단 줄 구성: 경로(연구명 > 화면명) · 패널 버튼(일부 화면) · **언어 전환 버튼 2개(🇰🇷한국어 / 🇯🇵日本語)** · 사용 안내(?) · 알림.
- 언어 버튼을 누르면 **페이지 전체가 새로 고쳐진다**(실행 중이던 스크립트가 끊김). 입력 중인 내용이 있으면 사라진다.
- 계정 메뉴(왼쪽 아래 아바타): 프로필 설정 / AI 사용량 / 화면 설정 / 사용 안내 / 로그인 화면으로. 언어는 여기에 없다.
- 모바일 상단 줄: 메뉴 버튼 · 경로 · 패널 버튼 · 언어 전환 2개 · ? · 알림. 언어 전환이 줄의 약 40%를 차지하고 경로가 '연.'으로 잘린다. 연구 도우미에서는 화면 이름 '연구 도우미'와 패널 아이콘이 겹쳐 보인다.
- 1165px에서 사이드바는 60px 레일. '메뉴 펼치기'를 누르면 본문을 덮는 형태로 열리고 화면 전체 크기의 '메뉴 접기' 바탕 버튼이 생긴다.
- ⌘K 명령 팔레트(600×497): 새 연구 만들기, 내 연구, 계정 설정, 사용 안내, 연구 3개. Esc로 닫히고 초점이 '연구 찾기' 버튼으로 돌아온다.
- 알림 대화상자(560×400): 닫기, 읽지 않음/전체, '검토 알림 빼고 모두 읽음', 알림 1건.

## C. 내 연구 `/r`

- 보기 전환: 진행 중인 연구 / 보관함 0 / 휴지통 0. 주소가 `?view=archived`, `?view=trash`로 바뀐다.
- 빈 보관함·빈 휴지통에도 '연구 만들기' 버튼이 본문에 다시 나온다(머리에도 있음).
- 연구 카드: 카드 전체 링크 + '연구 설정' 버튼 + 더보기(⋯). 더보기 메뉴의 항목은 **'휴지통으로 옮기기' 하나뿐**이다.
- 휴지통으로 옮기기: 대화상자(560×340)에서 **연구 이름을 직접 입력해야** 버튼이 켜진다. 복원할 수 있는 동작인데 이름 입력을 요구한다. 옮긴 뒤 알림 '휴지통으로 옮겼어요. 휴지통에서 복원할 수 있어요.'(되돌리기 버튼 없음).
- 휴지통 보기의 카드: 복원 / 완전히 삭제. 카드 자체도 링크지만 눌러도 이동하지 않는다.

## D. 연구 만들기 `/r/new` (4단계)

- 왼쪽 질문, 오른쪽 미리보기. 답한 단계는 위에 '고치기' 줄로 접힌다.
- 1단계: 연구 이름(필수), 한 줄 설명, 지도교수 이메일. 이름 없이 '계속' → 입력란 아래 오류와 알림이 **동시에** 뜬다(같은 문장 두 번).
- 2단계: 단계 6개 + '나중에 정할게요'. 제목 '지금 어느 단계인가요?'가 화면 글에 두 번 들어 있다.
- 3단계: 날짜를 정했어요 / 아직 안 잡혔어요 / 방금 미팅을 마쳤어요. '날짜를 정했어요'를 고르면 날짜·시간 입력이 나온다(시간은 날짜를 넣기 전까지 꺼짐, 달력 버튼 이름이 영어 'Toggle date picker'). **날짜를 비운 채 '계속'을 누르면 안내 없이 '아직 안 잡혔어요'로 바뀌어 넘어간다.**
- 4단계: 연구 목적, 연구 질문(비워도 됨). 마지막 단계 버튼도 '계속'.
- 확인 화면 '이렇게 시작할게요' → '내 연구 홈으로' → 새 연구 홈.
- 모든 단계에 '건너뛰고 빈 연구로 시작'이 있다.
- '아직 안 잡혔어요'로 답해도 '지도 미팅'(날짜 미정, 준비 중)이 한 건 자동으로 만들어진다.

## E. 새 연구의 홈 (빈 상태)

- 구성: 이름·설명, '적어 두기', 현재 단계, 공동연구자 초대, 미팅 준비하기, 시작하기 0/4(닫기 가능), 다음 미팅, 남은 할 일, 확인할 내용, 주간 띠, 최근 문서.
- **숫자가 빠진 문장**: '미팅까지 준비할 일 / 0개 완료', '남은 할 일 개 남음 · 개 완료'.
- 빈 안내가 동시에 5개 보인다(보여줄 결과, 준비할 일, 할 일, 새 소식, 문서) + 시작하기 4항목.

홈의 링크·버튼 19개를 모두 눌렀다.

| 누른 것 | 결과 |
|---|---|
| 적어 두기 | 연구 설정 › 기본 정보로 이동(연구 목적을 쓰려면 설정 화면까지 감) |
| 현재 단계 · 선행연구 | 계획·일정 `?phase=…` |
| 공동연구자 초대 | 연구 설정 `?tab=members` |
| 미팅 준비하기(머리) | 미팅 상세 `?tab=prepare` |
| 지도 미팅 / 자료 0개 / 질문 0개 / 미팅 준비하기(카드) | **네 개 모두 같은 곳**(미팅 상세 준비 탭) |
| 미팅 목록 | 미팅 목록 |
| 미팅 기록 남기기 | 미팅 상세 `?tab=record#meeting-recording` |
| 피드백 한 건 정리하기 | 피드백 목록(추가 대화상자는 열리지 않음) |
| 할 일 만들기 / 할 일 추가 | 할 일 화면으로 **이동한 뒤** '할 일 추가' 대화상자(560×661, 입력 8개)가 열림 |
| 전체 보기 | 할 일 화면 |
| 원고나 자료 올리기 | 자료 목록(등록 대화상자는 열리지 않음) |
| 지난주 / 다음 주 / 날짜 | 홈 안에서 주간 띠만 바뀜 |
| 글쓰기 | 글쓰기 목록 |
| 아직 문서가 없어요 · 새 연구 계획서 만들기 | 글쓰기 `?new=1` + '연구 계획서 만들기' 대화상자(560×306) |

- 같은 '만들기'인데 할 일·문서는 대화상자가 바로 열리고, 피드백·자료는 목록까지만 간다.

## F. 미팅 (데모 연구)

목록(요소 10개 전부 누름)
- 머리: 결정 기록 / 미팅 만들기. '결정 기록'은 오른쪽 여백 패널(340px)을 연다. 패널 안 링크 높이 16px.
- 미팅 만들기 대화상자(560×417): 이름, 날짜, 시간(날짜 전까지 꺼짐). 달력·시계 버튼 이름이 영어(Toggle date picker / Toggle time picker).
- 상태 필터(전체/예정/지난 미팅/날짜 미정/취소됨)는 주소에 `?status=`로 남는다.
- 지난 미팅 행을 열기만 해도 알림 '이 브라우저에 저장됨'이 뜬다(저장한 것이 없는데 뜸).

상세 · 준비 탭(13개)
- '준비 편집', '할 일 고르기', '자료 고르기' **세 버튼이 같은 대화상자**(미팅 준비 편집, 560×661)를 연다. 대화상자 안 체크 버튼 7개에 접근성 이름이 없다.
- 할 일 행 앞의 네모는 체크박스처럼 보이지만 누를 수 없고, 행 전체가 할 일 상세로 가는 링크다.
- 자료 행 → 자료 상세 `?version=…`. 질문 추가 → 대화상자(560×464).
- 탭은 주소에 `?tab=record`, `?tab=questions`로 남는다. '기록' 탭으로 바꾸기만 해도 '이 브라우저에 저장됨' 알림.

상세 · 기록 탭
- 녹음 시작 → '녹음을 시작할까요?' 대화상자(동의 체크 2개, 이름 없음. 체크 전에는 시작 버튼 꺼짐).
- 'AI로 메모 정리' → 오른쪽 패널의 '도우미' 탭이 열린다(근거 카드, '제안받기'는 미리보기에서 꺼짐). 패널 탭은 준비 3 / 도우미.

상세 · 결정·질문 탭

## G. 피드백·수정

- 탭 '피드백 / 수정 결과'. '수정 결과'를 누르면 주소가 `/results`로 바뀌고 머리 버튼이 '피드백 추가'에서 '수정 결과 작성'으로 바뀐다(탭인데 다른 화면).
- 피드백 상태 필터(전체/시작 전/진행 중/수정 결과 있음/보류)는 주소에 남지 않는다(미팅·할 일 필터는 남음).
- 피드백 추가 대화상자(560×489): 제목, 내용.
- 수정 결과 작성 대화상자(560×661): 제목, 내용, 수정 종류, 파일, 새 PDF 올리기, 볼 위치, 체크 버튼 6개(이름 없음).
- 수정 결과 상세(6개): 목록으로, 수정 결과 편집, 검토 요청 만들기, 응답 보기 등.
- **'검토 요청 만들기'를 누르면 검토 요청 화면으로 옮겨 가 대화상자가 열리고, 브라우저 뒤로 가기를 눌러도 수정 결과 상세로 돌아오지 않는다.**

## H. 검토 요청

- 만들기 1단계(560×661): 제목(필수), 검토할 교수(필수), 검토받을 수정 결과(체크 버튼, 이름 없음). 제목 없이 다음 → 알림과 대화상자 안 문장으로 오류가 두 번.
- 2단계 '공유할 내용 확인': 교수에게 공개될 내용 요약, '돌아가서 수정' / '검토 링크 만들기'.
- 만들면 `/reviews/:id?item=…&round=…`로 이동하고 알림 '검토 링크를 만들었어요. 링크를 복사해서 교수님께 직접 전달해 주세요.'
- 상세(16개): 뒤로(21×21), 새로고침, 공유 설정, 링크 복사, 항목 목록, 차수 선택, 다시 확인 요청, PDF 이전·다음·축소·확대·내려받기(각 28×28), 이 페이지 텍스트 보기, 댓글.
- 공유 설정 대화상자(540×520): 교수 이메일, 설정 저장, **공유 중지**(대화상자 안에 있음).
- 다시 확인 요청 대화상자(540×607): '수정 결과에서 고치기' 링크, 확인 체크, '2차 검토 요청'.
- 링크 복사는 이 환경에서 실패 알림이 떴다(자동 클릭이라 실제 실패 여부는 미확인).
