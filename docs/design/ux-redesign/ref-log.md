마진 관찰 기록(observation-log.md)과 같은 방식으로, 화면마다 누를 수 있는 요소를 나열하고 하나씩 눌러 무엇이 열리는지 적었다. 남의 계정이라 결제·거래·전송·삭제·설정 변경·새 항목 저장은 누르지 않았다(창이 열리는 것만 보고 닫음).

## 1. Liner Scholar (scholar.liner.com, 무료 계정)

### 1.1 전체 틀
- 데스크톱 1165px: 왼쪽 사이드바 260px + 본문. 상단 띠 배너(행사 안내, 닫기 가능). 오른쪽 위에 '크레딧 충전하기'가 늘 보인다.
- 사이드바 순서: 홈(로고) · 접기 / 새 채팅 / 프로젝트 / 내 라이브러리 / 업데이트(배지 2) / 에이전트 ›(접힘, 펼치면 9개: 가설 생성, 가설 평가, 인용 추천, 문헌 조사, 연구 흐름 탐색, 설문 생성, 설문 시뮬레이션, 피어 리뷰, 선행연구 조사) / 고정됨 / 최근 기록(스레드 목록) / 친구 초대 카드 / 프로필 줄 + 알림 / Liner 제품 탐색.
- 사이드바 '접기'를 누르면 48px 아이콘 레일이 되고, 왼쪽 끝에 마우스를 대면 사이드바가 본문 위로 덮어서 다시 나온다.
- 업데이트: 사이드바 항목을 누르면 오른쪽으로 360×480 팝오버가 열리고 날짜별 새 기능 카드(제목·설명·자세히 보기)가 쌓여 있다.
- 알림: 360×228 팝오버('알림이 없어요').
- 프로필 메뉴(236×419 팝오버, 사이드바 위로 열림): 이메일 / 개인 스페이스 / 팀 플랜 시작하기 / 개인 설정 / **테마 › / 언어 ›** / 내 크레딧 / 요금제 / Liner API / 고객센터 / 로그아웃.
- 개인 설정: 화면 가운데 800×600 창. 왼쪽 하위 메뉴(내 프로필, 로그인과 보안, 기관, 하이라이트 설정, 구독, 이용약관·개인정보·가이드 링크, 로그아웃) + 오른쪽 폼. 프로필 폼은 입력란마다 지우기(×) 버튼, '저장하기'는 바뀐 것이 없으면 꺼져 있다.

### 1.2 홈(새 채팅)
- 가운데 제목 한 줄 + 모드 탭 3개(물어보기 / 글쓰기 / 논문 읽기) + 큰 입력창(맥락 추가 +, 스킬, 풀 텍스트, 음성).
- 모드 탭에 마우스를 대면 280×258 설명 카드(그림 + 한 줄 설명)가 뜬다. '논문 읽기'를 누르면 입력창이 파일 올리기 영역으로 바뀐다(PDF·DOCX·HWP·TXT).
- 맥락 추가(+) 메뉴: 업로드 / 새 문서 / 커넥터.

### 1.3 스레드(대화)
- 주소 `/threads/:id`. 왼쪽 위 '돌아가기', 대화는 가운데, 오른쪽에 '결과물'(+ → 새 문서 / 새 표 / 새 마인드맵)과 '출처' 카드 두 개가 고정.
- 답 위에 '추론 완료 ›'(누르면 AI의 생각 과정이 펼쳐짐), 답 아래에 다음 행동 카드 2개('문서로 저장', '마인드맵으로 시각화')와 좋아요/별로예요.
- 답이 없는 질문에는 "무엇을 올리거나 알려 주면 되는지" 두 가지 길을 제시한다.

### 1.4 프로젝트
- 목록: 머리(제목 + 설명 2줄) → 검색 · 정렬(수정한 날짜/생성일/이름순) · '+ 새 프로젝트' → 카드(이모지, 이름, 수정 시각, ⋯ 메뉴: 이름 변경/초대하기/삭제).
- 새 프로젝트: 480×267 작은 창, 입력은 제목 하나, 설명 한 줄.
- 프로젝트 안: 경로(프로젝트 / 개인연구) + 초대하기 · 크레딧. 본문 왼쪽에 이름 + 입력창 + 최근 기록, **오른쪽 열에 '지침'(+)과 '파일'(+) 카드**. 파일 + 메뉴: 업로드 / URL·DOI / 논문만 / 새 문서 / 새 마인드맵 / 새 폴더 / Zotero. 파일마다 ⋯(이름 변경/삭제).
- 지침 추가: 600×401 창, 큰 입력란 하나 + 저장하기.
- 오른쪽 열의 파일을 누르면 **문서 작업대**가 열린다(아래 1.5).

### 1.5 문서 작업대 (가장 참고할 화면)
- 사이드바가 48px 레일로 자동 접힘. 왼쪽 약 300px에 대화, 오른쪽 넓게 문서. 문서 위에 탭(여러 문서를 탭으로 열기, + 새 탭), 전체 화면, 패널 숨기기.
- 편집 도구 줄: 되돌리기 · 배율 · 문단 형식 · 굵게/기울임/밑줄/취소선 · 더보기 · **인용 스타일(APA 등 15종 이상)** · 내보내기(PDF / Word / LaTeX).
- 그 아래 'AI' 줄: 문서 검토 / 문법 검사 / 도표 생성.
  - 문서 검토: 260×289 설명 카드 + '리뷰 시작' 버튼(한 번 더 눌러야 실행).
  - 문법 검사: **누르자마자 실행**된다. 왼쪽 대화에 `/check-grammar`가 보내지고 대화 제목이 'Grammar Check'로 생긴다. 이 계정 크레딧이 62 → 2로 줄었다(이번 탐색 중 실제로 일어난 일).
  - 도표 생성: 대화 입력창에 `/generate-figure`를 넣기만 하고 보내지 않는다(지웠다).
- AI 수정 제안 표시: 문서 본문에 지울 글은 취소선, 새 글은 초록 바탕으로 **그 자리에** 보인다. 선택한 제안 위에 '1 / 4 · 적용 안 함 · 적용', 화면 아래에 '1 / 4 · 모두 적용 안 함 · 모두 적용' 막대. 왼쪽 대화에는 제안마다 카드(파일 이름 + 바뀌기 전 → 후)가 쌓인다. → 4건 모두 적용하지 않은 채 두었다.

### 1.6 내 라이브러리
- 머리(제목 + 설명 2줄) → '모든 파일' + 새 폴더 · '+ 파일 추가'(나눔 버튼, ▾ → 파일 추가 / Zotero) → 표(체크, 제목, 저널, 저자, 날짜).
- 행을 누르면 주소는 그대로이고 **오른쪽에 상세 패널**(약 310px)이 열린다. 표는 제목 열만 남기고 좁아진다. 패널: 닫기(×), 제목, 프로젝트·형식 배지, 'PDF 열기' · '인용' · ⋯, 그 아래 제목·저자·저널·날짜·인용 수·URL 입력란(바로 편집).
- 인용: 가운데 창, 인용 스타일 선택 + 참고문헌 형식과 본문 인용 형식을 각각 복사 버튼과 함께.

### 1.7 모바일 375px

### 2.4 프로젝트 편집 화면 (가장 참고할 화면)
