# 일본어 문구 기준 (日本語 UXライティング)

> 2026-11-16 정보 구조 개편(IA v2) 설계가 확정됐습니다(구현 전). 화면 배치·메뉴·주소의 새 기준은 [docs/design/ia-v2](ia-v2/00-README.md)이고, 새로 쓰는 말의 일본어 후보는 아래 'IA v2 새 말' 표에 있습니다. 사전(`src/i18n/ja`)은 구현 단계에서 바꿉니다.

한국어 문구가 원문이고([UX 라이팅 원칙](ux-writing.md)), 일본어는 그 번역입니다. 일본어 문구는 `apps/home-preview/src/i18n/ja/*.ts` 사전에 한국어 원문을 열쇠로 넣습니다. 코드에서는 `t("한국어 원문")`으로 씁니다(`src/lib/i18n.ts`).

상태: 2026-11-11 Claude가 번역함. **일본어를 읽는 사람의 검수를 아직 받지 않았습니다.** 어색한 표현을 찾으면 사전의 값만 고치면 됩니다.

## 말투

- です・ます体(해요체에 대응). 짧고 담백하게 씁니다. 「〜してください」「〜できます」「〜しました」.
- 느낌표와 과한 경어(「〜させていただきます」「〜くださいませ」)를 쓰지 않습니다.
- 버튼·메뉴·탭은 명사나 짧은 동사로 씁니다: 「保存」「キャンセル」「次へ」「戻る」.
- 오류는 무슨 일이 있었는지와 다음에 할 일을 씁니다: 「保存できませんでした。もう一度お試しください。」
- 한국어 문장을 조각으로 나눠 놓은 자리는 일본어도 같은 순서로 자연스럽게 이어지게 씁니다.
- `{count}` 같은 자리 표시는 이름을 그대로 둡니다. 숫자·영문은 반각, 괄호·구두점은 전각(「、」「。」「（）」)을 씁니다.
- 고유 상태 구분(선택≠완료, 링크 생성≠전송, 수정 내용 확인≠승인, 저장≠버전)은 일본어에서도 섞지 않습니다.

## IA v2 새 말 — 후보(구현 때 i18n 사전과 함께 확정)

[UX 라이팅 원칙](ux-writing.md) §5 'IA v2 새 말'의 일본어 **후보**입니다. 아직 `src/i18n/ja` 사전에 넣지 않았고, 해당 화면을 구현하는 단계에서 실제 문장과 함께 사전에 넣으며 확정합니다. 기존 사전에 이미 있는 말은 그 값을 따랐습니다(메모에 표시).

| 한국어 | 일본어(후보) | 메모 |
|---|---|---|
| 기록 (미팅 목록의 대면 미팅·서면 피드백) | 記録 | 위 용어표와 같음. 기록 추가 → 記録を追加 |
| 서면 피드백 | 書面フィードバック | 기록 종류 배지 |
| 형광펜 | マーカー | 기존 사전 「형광펜 지우기 → マーカーを消す」에 맞춤 |
| 요약 | 要約 | 연구 도우미가 만든 요약 |
| 연구 흐름 | 研究の流れ | 기존 사전 값 그대로. 위 표의 ‘계획·일정’을 대신하는 화면 이름 |
| 사이드 창 위치 | サイドパネルの位置 | 설정 항목 이름 |
| 녹음 시작 | 録音を開始 | 기존 사전 값 그대로 |
| 기록 남기기 | 記録を残す | 녹음 없이 메모로 적음 |
| 기록 완료로 바꾸기 | 記録完了にする | 기존 사전 「기록 완료 → 記録完了」에 맞춤 |
| 넘어온 할 일 · 가져가기 | 前回から残ったタスク · 取り込む | 복사가 아니라 연결. 「繰り越し」(이월)는 쓰지 않음 |
| 붙이기 | 添付 | 파일·지금 보는 기록에만. 기존 사전의 ‘첨부 → 添付’와 같은 말 |
| 지금 표시 | 今の位置をマーク | 녹음 중. 「ブックマーク」는 쓰지 않음 |
| 선택 · 제안 닫기 | 選択 · 提案を閉じる | 「採用」「破棄」는 쓰지 않음 |
| 적용 · 적용 안 함 | 適用 · 適用しない | 글 안의 수정 제안에만 |
| 수정 제안 | 修正提案 | ‘수정 방법 제안’(修正方法の提案)과 구분 |
| 훑어보기 | クイック表示 | 「プレビュー」는 글·자료 목록의 미리보기 열에만 |
| 미팅 주기 | ミーティングの周期 | 「定例ミーティング」는 쓰지 않음 |
| 옆 창 열기 | サイドパネルを開く | 아이콘 줄의 접근성 이름 |

## 번역하지 않는 것

- 사용자가 적은 기록, 교수 응답, 파일 이름, 서버에 이미 저장된 알림 글.
- 미리보기 모드의 가상 데이터(`lib/demo.ts`).
- 녹음 전사 언어(한국어 실시간 전사는 그대로).
