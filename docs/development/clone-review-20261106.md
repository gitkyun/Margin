## 작업 기준

수업 폴더의 `RMS/apps/home-preview`가 기준 앱이다. `RMS_improved` 및 `RMS_improved_인계_및_변경내역_총람.md`와 관련 진단·반응형 보고서를 대조했다. 복제본·사용자 제공 자산·원본 자료는 수정하지 않았다. GitHub 공용 허브는 수정하거나 푸시하지 않았다.

## 복제본에서 확인해 제외한 문제

- 교수의 ‘수정 내용 확인’을 ‘승인’으로 바꾸는 문구는 확정한 제품 규칙과 달라 반영하지 않았다.
- ‘반영 기록 있음’을 ‘반영 완료’로 바꾸면 기록의 존재와 실제 완료를 혼동하게 되어 유지했다.
- 에디터의 가운데 정렬 버튼이 실제로는 인용문을 만들었다. 다른 정렬 버튼도 실제 정렬 명령이 아니었다.
- 이미지 삽입은 설치한 편집기 확장·저장 구조·PDF 변환까지 이어지지 않았고 원시 HTML 문자열에 입력을 넣었다. 성공 안내만 나오는 구조를 채택하지 않았다.
- 템플릿의 화면 안내와 실제 덮어쓰기 동작이 달랐으며 본문 텍스트와 편집기 JSON이 어긋날 수 있었다.
- 작업 화면의 전역 단축키는 입력·메뉴·대화상자·조합키에 영향을 줄 수 있었다. 중간 화면 폭에서 상세 보기가 숨겨지는 문제도 있었다.
- 전역 버튼 축소 효과, 다수의 강제 스타일, 작은 조작 영역은 그대로 복사하지 않았다.
- 사이드바 로고 축소와 해 번짐 추가는 이미 확정한 시각 기준과 달라 제외했다.

## 사용자 화면 의견 17개 반영

1. 로그인 화면의 교수 검토 복귀 설명 제거.
2. 수업 시연·발급 계정 설명 제거. 가입은 실제 계정 생성 없이 체험 흐름만 제공한다.
3. 사이드바·본문의 바깥 간격 통일.
4. 연구 목록 탭 위아래 간격 정리.
5. 가상 연구 불러오기 UI 제거. 기존 연구 데이터는 보존.
6. 휴지통에서 소유자만 연구 이름 확인 후 완전 삭제. 관련 기록과 비공개 파일 정리, 실패한 파일 정리의 재시도 제공.
7. 연구 도우미의 사이드바 아이콘을 다른 메뉴와 같은 선 아이콘으로 통일.
8. 메뉴 호버를 파란색으로 강조.
9. 활성 메뉴의 그림자·경계 이상 제거.
10. 피드백 기록 바로가기를 중립 표면으로 변경.
11. 현재 비밀번호 확인 후 새 비밀번호 변경 기능 추가. 확인용 임시 세션은 작업 세션과 분리.
12. 알림 스위치의 트랙·손잡이 크기와 이동 거리 통일.
13. 계정 메뉴의 두 테마 그림자 보강.
14. AI 대화의 안내·예시·입력 영역 폭과 간격 정리.
15. 자료 목록에 권한이 있는 PDF의 실제 첫 페이지 미리보기 배지 추가. 보이는 파일만 읽으며 실패하면 파일 아이콘으로 표시.
16. 문서 폭을 가운데에 두고 목차는 펼칠 때 위에 배치. 굵게·기울임·취소선·제목·목록·인용·표·서식 지우기·실행 취소·다시 실행 제공.
17. 저장 상태를 중립색 아이콘과 문구로 표시.
