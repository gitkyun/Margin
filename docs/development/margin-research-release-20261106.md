# Margin 새 주소 및 연구 홈 수정

- 배포 주소: https://margin-research.pages.dev
- 배포 ID: db96172d-0bc3-4d57-8257-9344d8a22468
- 기존 rms-classroom-demo.pages.dev는 이전 배포를 보존한다. 자동 리디렉션은 설정하지 않았다.
- 작업 위치: 수업 폴더 RMS/apps/home-preview. GitHub 수정·푸시 없음.

## 반영

1. 로그인 후 사이드바의 워드마크를 소개 헤더와 동일한 99.2 × 32px로 맞췄다.
2. 연구 홈의 구름을 제거하고 피드백 기록하기·미팅 준비하기·연구 글 쓰기 바로가기를 배치했다.
3. 기록 대상은 진행 중 기록, 유효한 다음 미팅, 날짜순 준비 미팅 순이다. 완료·취소·보관 미팅은 자동 선택하지 않는다. 대상 이름을 버튼에 표시한다.
4. 기록 대상이 없으면 미팅을 만든 뒤 녹음·메모 화면으로 이동한다. 마이크를 자동 시작하지 않는다.
5. 글쓰기의 빠른 중복 생성과 저장 실패 재시도 시 중복 생성 가능성을 줄이도록 생성 잠금 및 재사용 ID를 추가했다.
6. AI Edge Function에 새 주소의 정확한 출처를 허용했다. 기존 인증·기록 접근 검사는 유지했다. Gemini 키는 변경하지 않았다.

- TypeScript 검사 및 프로덕션 빌드 통과.
- 프런트엔드/로직 95개, DB·권한 32개, 배포 라우팅 4개: 총 131개 검사 통과.

- Cloudflare canonical deployment 성공 확인. 공개 경로·자산의 배포본 대조 결과는 deployment-http-margin-research-20261106.json을 참조한다.
