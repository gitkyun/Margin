# RMS 구현·배포 검증 · 2026-11-04

## 현재 범위

배포: https://rms-classroom-demo.pages.dev · Cloudflare Pages Direct Upload. GitHub 원격은 변경하지 않는다. 활성 소스는 수업 폴더의 `RMS/`이며 GitHub 로컬 허브에는 공유 소스만 동기화한다.

소개·로그인·가입 시연·프로필·테마·사용량·연구 설정·보관/복원·기록 기반 AI 대화·제목 찾기를 추가했다. 기존 실제 기록·PDF·교수 검토 차수·지정 계정 권한은 유지한다. 가입은 실제 계정 생성이나 메일 발송을 하지 않는다. Gemini 키는 사용자 요청으로 미등록이며 실제 AI 생성 성공은 아직 검증하지 않았다.

## 자동 검사

- TypeScript와 프로덕션 빌드 통과.
- Vitest 45개(12파일) 통과. 원문·AI 계약·차수·알림·입력 보호 등.
- PostgreSQL PGlite 19개 통과. RLS, RPC, 검토 보존, AI 제한/본인 집계, 연구 보관·복원 후 기록과 기존 검토 유지 포함.
- Sites 보존 경로 4개 통과. 배포는 Cloudflare Pages다.
- Prettier 통과. 신규 진입/탐색 파일의 Impeccable 정적 탐지 결과 0개. 이는 전체 접근성·디자인 합격을 뜻하지 않는다.
- 신규 라이브러리 포함 `npm ci` 성공. `@ybouane/liquidglass@1.0.3`의 postinstall에 필요한 `patch-package`는 개발 의존성이다. 런타임 패치나 유료 블록 복제는 하지 않았다.
- 기본 앱 약1MB(압축 약305KB), PDF parser 약501KB, worker 약1.27MB의 빌드 경고가 남는다. 글라스는 약52KB(압축 약17KB) 별도 지연 로드. 성능 점수나 저사양 기기 검증은 수행하지 않았다.

## 실제 서버·브라우저 검사

서버: 본인 최근24시간 AI 집계, 익명 접근 거부, 선택한 가상 메모의 AI 요청이 503 NOT_CONFIGURED로 종료되는 것을 확인했다. 가짜 답변 없음. 이전 서버 검증의 기록·비공개 파일·교수 응답·부분 재확인 결과는 [이전 기록](verification-20261103.md)과 앱의 과거 검증 절에 남긴다.

배포 브라우저에서 확인한 항목:

- 소개 화면 기능 예시 전환, 공유 헤더·푸터, 가입 미리보기 완료와 실제 계정 미생성 안내.
- 기존 발급 계정 로그아웃·로그인과 요청했던 내부 화면으로 복귀.
- 실제 연구 목록·홈·프로필·사용량·테마 전환, 메뉴 접기와 펼치기.
- 프로필 변경 취소 시 기존 표시 이름 유지.
- 연구별 AI에서 저장된 메모 하나 선택 → 질문 → 키 연결 전 오류 → 질문 유지. 재접속 뒤 탭 임시 질문 유지.
- 별도로 만든 가상 연구 `ee560b98-1730-4e78-a257-d0efdbdef7d6`의 생성 → 보관 → 보관 안내/목록 → 복원과 기존 설명 유지. 기존 사용자 연구는 수정하지 않았다.
- 자동 검사의 로그인 종료가 다른 시연 세션을 무효화하지 않도록 검사 스크립트 종료 범위를 해당 세션으로 제한했다.
