# 소개 화면 마감·검증 기록 · 2026-11-06

## 반영한 요청

- 구름은 Aceternity Cloud Shader의 실제 GLSL을 사용한다. 푸른 하늘·해 없음 유지, 소개 화면 속도는 0.25에서 0.35로 올렸다.
- 구름 영역과 ‘연구의 어느 순간에도’ 미리보기의 외곽 높이를 고정하면서 세로 공간을 넓혔다. 탭별 제목·설명·본문은 같은 행 안에서 바뀐다.
- 푸터 위 연구 시작 영역은 선명한 블루 그라데이션으로 강조했다. 푸터도 블루톤을 유지하고 배경이 위로 번지는 범위·하단 여백·카드 그림자를 조정했다.
- 푸터에 파동·포인터 반응 도트를 추가했다. 화면 밖·비활성 탭에서는 정지하고 동작 감소 설정은 정적인 장면을 사용한다.
- 공개 푸터의 라이트·다크·시스템 버튼을 실제 테마 상태에 연결했다. 로그인 후 테마 설정 위치는 계정 설정으로 유지한다.
- 맨 위로 버튼은 해시 위치 대신 실제 문서 및 부모 스크롤 영역의 맨 위로 이동한다.
- 사용자 화면 확인 뒤 푸터 위쪽에 가로 경계가 보이는 문제를 수정했다. 푸터 자체와 확장 영역에 나뉘어 있던 배경을 하나의 확장 레이어로 합쳤으며 위쪽 확장 거리·도트·카드 간격은 유지했다. 두 테마에 같은 구조를 적용했다.
- 소개 제목에 선명해지는 등장 효과와 호버 밑줄·빛 이동을 추가했다. 본문은 지연하거나 타이핑하지 않는다.
- 라이브러리·직접 작성 범위는 [Aceternity 적용 기록](../design/aceternity-sources-20261106.md)에 구분했다. 모든 참고 컴포넌트를 설치한 것으로 보고하지 않는다.

- 헤더에 Radix NavigationMenu로 주요 기능·도움말 메뉴를 만들고, 기능 둘러보기(`/features`)·플랜(`/pricing`)·사용 안내(`/guide`)·개인정보 안내(`/privacy`)를 연결했다. FAQ는 사용 안내의 해당 항목으로 이동한다. 기능 선택은 주소에 남으며 뒤로 가기로 되돌릴 수 있다.
- 비교 예시는 아래 범위 입력을 없애고 가운데 화살표를 직접 드래그하도록 바꿨다. 0~100% 끝까지 이동하며 Home·End·방향키도 지원한다. 포인터 해제 뒤 이동하지 않는 검사까지 추가했다.
- 중간 시각 영역은 하늘색·파란색으로 통일하고 다크 테마 표면을 별도로 조정했다.
- 사용자 추가 참고에 따라 푸터의 외곽·하단 블루 그라데이션과 도트를 더 선명하게 했다. 링크는 불투명한 카드 안에 세 묶음으로 배치하고, 하단에 테마·맨 위로 이동을 유지했다.

## 이번 실행 결과

- `npm run build`: TypeScript 검사와 배포 빌드 통과. 헤더·공개 페이지·비교 조작·푸터의 최종 변경 뒤 다시 실행했다.
- `npm test`: 21개 파일, 88개 검사 통과.
- `npm run test:backend`: 32개 검사 통과. 로컬 DB 검사이며 원격 서버를 새로 검증한 결과가 아니다.
- `npm run test:sites`: 4개 검사 통과.
- 변경한 소개·푸터·탐색 파일의 Prettier 검사 통과.
- 저장소 문서·로컬 링크 검사 통과. 외부 URL·화면 동작 검사가 아니다.
- 앱·PDF 관련 일부 청크가 500kB를 넘는 기존 빌드 경고는 남아 있다. 로드 성능의 실측 수치는 없다.

## 검증 경계

사용자가 최종 화면 검증을 직접 맡겠다고 명시했다. 이번 최종 수정본의 브라우저 크기·포인터·실제 스크롤·테마를 자동 확인한 것으로 보고하지 않는다. 코드 검사·배포 성공과 화면 검증은 별개다.

사용자는 녹음·한국어 전사가 문제없다고 확인했다. 이번 변경에서 녹음·전사·권한·저장 코드를 수정하지 않았으며 새로운 실제 발화 검사는 하지 않았다. Gemini 키는 사용자 결정대로 비워 두었고 실제 생성 호출 성공을 주장하지 않는다.

활성 소스는 수업 폴더의 RMS다. GitHub 공용 허브에는 수정·커밋·푸시하지 않았다. 원본 참고자료와 실제 연구 자료도 변경하지 않았다.

## 배포

사용자 요청으로 이번 공개 탐색·비교·강화된 푸터 수정본의 배포를 보류한다. 로고·파비콘·브랜드명·AI 캐릭터를 받은 뒤 반영하고 배포한다.

이번 수정본은 로컬 빌드·88개 자동 검사까지 완료했다. 자산 업로드 시도는 임시 인증 만료로 실패했으며 새 배포 생성은 실행하지 않았다. 기존 공개 주소는 이전 배포 상태다. 기존 HTTP 확인 보고서의 배포 식별자를 이번 수정본의 검증 결과로 해석하지 않는다.

## Margin 브랜드·도우미 반영 후 추가 검사

- 사용자 제공 SVG 9개·PNG 16개를 원본 변경 없이 복사했고 SHA-256을 대조했다. 25개 모두 일치하고 빌드에 포함됐다. 파비콘은 제공한 심벌과 동일하다.
- 공통 브랜드·표정 매핑, 연구 홈·소개·사이드바·교수 검토·대화·AI 패널, 모델과 검토 깊이 문구를 연결했다. 자세한 위치는 [적용 기록](../design/margin-brand-20261106.md)을 따른다.
- `npm test`: 22개 파일의 91개 검사 통과. 모델별 지원 값 변경 시 유효하지 않은 깊이를 요청하지 않도록 하는 검사, 모델 ID의 버전 유지 검사를 포함한다.
- `npm run build`: TypeScript와 Vite 빌드 통과. 기존 앱·PDF 큰 청크 경고는 유지된다.
- 백엔드·녹음·전사 코드를 바꾸지 않아 이번 브랜드 작업에서 해당 검사를 다시 실행하지 않았다. 위의 이전 실행 결과와 구분한다.
- 브라우저 시각 검증은 사용자가 수행한다. 실제 Gemini 호출은 하지 않았다.
- 로고·캐릭터를 받았지만 배포는 자동 재개하지 않았다. 로컬만 변경했으며 GitHub 수정·푸시는 없다.

- Margin 변경 파일의 Prettier 검사와 저장소 문서 검사(35개 Markdown·108개 로컬 링크) 통과.
- 로컬 미리보기 서버를 `127.0.0.1:4175`에 실행했다. 서버 실행 확인이며 브라우저 화면 검증 결과는 아니다.

## Margin 공개 배포 완료 · 2026-11-06

사용자가 “배포까지 끝내”로 배포를 재개했다. 기존 배포 보류 기록은 이 요청으로 해제됐다.

- 공개 주소: https://rms-classroom-demo.pages.dev
- Production 배포: `a56e0c75-da50-466d-8ff1-be8ac229481a` (Cloudflare 성공 상태 및 canonical 배포 확인).
- 246개 앱 파일을 배포했다. 원본 SVG 모음과 출처 대조 JSON은 로컬에 보존하고, 공개본에는 앱에서 쓰는 로고·워드마크·파비콘과 캐릭터를 포함했다.
- 원본 파일을 포함했던 앞선 배포 3회는 Cloudflare의 `Failed to publish your Function / Unknown internal error`로 실패했다. 원본 참고 파일을 제외한 배포는 성공했다. 오류의 내부 원인은 확인되지 않았다.
- 소개·로그인·연구·글쓰기·기능·플랜·도움말·개인정보 경로, JS/CSS·글꼴·파비콘·로고·캐릭터 16개를 포함한 HTTP 검사 32개가 통과했다. 공개 응답은 로컬 빌드와 SHA-256이 일치한다.
- 마이크 허용 헤더 `microphone=(self)` 유지. HTTP 응답 검사이며 브라우저 시각·로그인 후 사용자 흐름·실제 Gemini 호출 검증은 아니다.
- 상세 응답: [Margin 배포 HTTP 기록](deployment-http-margin-20261106.json).
- GitHub 공용 허브·Supabase 서버·사용자 기록은 변경하지 않았다. 임시 업로드 인증 파일은 삭제했다.
