# 승인한 서비스 경험 확장 · 구현 계약

이 문서는 2026-11-04~05 사용자가 승인한 개편 계획을 현재 소스에 연결한다. 기존 PRD·명세의 사용자 문제와 상태 구분을 보존하며, 과거 P0/P1이나 36개 기능 수를 이번 확장의 제한으로 사용하지 않는다. 구현·실제 검증 범위는 [검증 기록](../development/verification-20261105.md)을 우선한다.

## 연구와 공동 기록

소유자가 확인된 허용 계정을 이메일로 초대한다. 초대 수락 전에는 연구 내용을 읽을 수 없다. 활성 편집자는 공동 기록을 작성하고 지정 교수에게 검토를 공개·재확인할 수 있다. 소유자가 초대·해제·연구 보관·휴지통을 관리한다. 실제 이메일 초대 메일을 보내지는 않으며 대상 계정의 서비스 안 목록에 초대가 표시된다.

개인 메모·AI 대화·미채택 후보·개인 첨부는 작성자만 읽는다. 공동 기록은 공개 범위를 명시한다. 교수는 지정 검토와 초대받은 일정 조율만 읽으며 연구 멤버 권한을 자동으로 얻지 않는다. 같은 계정이 공동연구자이기도 하면 두 접근 자격을 각각 검사한다.

연구 보관은 진행 목록에서 숨기며 기존 검토 접근은 유지한다. 휴지통 이동은 다른 멤버와 교수의 접근을 중지한다. 소유자가 복원하면 기록은 돌아오지만 교수 공유는 중지 상태다. 자동 영구 삭제는 없다.

## 문서·버전·보존 파일

문서 제목·본문·공개 범위를 저장한다. 편집기는 초안을 브라우저에도 보관하고 서버 저장 성공과 구분한다. 다른 사람이 먼저 저장하면 내 작성본을 유지하고 최신본과 비교한다. 자동 병합·실시간 공동 커서는 구현 범위가 아니다.

명시적으로 저장한 버전은 덮어쓰지 않는다. 비교할 두 버전을 고르고 복원하면 새 버전을 만든다. 검토 PDF는 저장한 버전에서 생성→파일 확인→보존 파일 등록 순서다. 교수 확인은 그 PDF와 당시 설명에 남는다.

## AI 실행과 채택

대화·미팅 정리·수정 설계·집필 검토·연구 계획·자료 읽기는 선택한 원문과 버전을 실행 전에 보여준다. 미팅 정리는 메모 하나, 자료 읽기는 PDF의 선택 페이지 또는 실제 추출 텍스트를 사용한다. 선택 문단이 사라지면 전체 원고를 대신 처리하지 않는다.

클립은 연구 자료와 PDF/TXT/MD 개인 첨부를 선택한다. OCR을 실행하지 않는다. 서버가 허용한 Gemini 모델과 지원하는 생각 수준만 선택한다. 미연결 상태를 가짜 답변으로 감추지 않는다.

후보에는 원문 근거·제안·가정을 구분한다. 채택은 해당 개인 기록 생성과 후보 채택 상태를 한 번에 저장하며 재시도 중복을 막는다. 이후 공동 공개는 별도 명시적 행동이다. 교수 확인·작업 완료 상태는 채택으로 바꾸지 않는다. 중단 후 늦은 결과를 자동 적용하지 않는다.

## 일정·녹음·알림

단계 순서·현재 단계·마감·작업/문서 연결을 수정한다. 단계 이동으로 작업 기한은 자동 변경하지 않는다. 월·주·목록 캘린더와 시간순·다이어그램 보기를 구분한다.

미팅 조율은 제목·후보 시작/종료 시간·초대 계정→대상자의 가능 시간 응답→생성자/소유자의 확정 순서다. 확정을 재시도해도 미팅을 중복 생성하지 않는다. 확정 후 변경은 기존 일정 취소와 새 조율로 남긴다. 외부 캘린더 연동·메일 발송은 없다.

녹음은 동의 확인·마이크 허용 후 시작한다. 일시정지·중단·재생 확인·비공개 저장을 제공한다. 저장 실패하면 녹음 결과를 유지하고 재시도한다. 사용자가 요청한 실시간 한국어 인식을 Web Speech API로 연결했다. 인식 중 글자 표시→마지막 문장 확인→수정→비공개 전사 저장을 제공한다. 원 인식 구간과 수정문은 분리하며 음성 공유가 전사문 공개로 이어지지 않는다. 미지원·네트워크·권한 오류는 안내하고 원음과 나온 문장을 유지한다. 상세 구현과 한계는 [실시간 전사 기록](korean-transcription-proposal-20261105.md)을 따른다.

알림은 작성자·대상·변경 내용·시각과 원래 기록 이동을 제공한다. 계정별 읽음·알림 종류 설정을 보존한다. 서비스 안 알림이며 브라우저 푸시나 이메일 수신을 가장하지 않는다.

## 제한 공개 운영

가입은 과정 체험만 제공하고 계정을 발급하지 않는다. 플랜은 기능 비교·선택 미리보기이며 가격·결제·권한 변경을 실행하지 않는다. Gemini 키 연결·실호출과 최종 화면/녹음 검증은 별도 확인이 필요하다.
