# 실시간 한국어 전사 · 구현 기록 · 2026-11-05

## 확정한 동작

사용자가 “녹음하면 실제로 한국어 글씨가 뜨고 이를 저장”하도록 요청했다. 앞서 제안했던 녹음 후 Gemini 전사와 10분 제한은 이번 구현에 채택하지 않았다.

미팅의 기록 탭에서 동의를 확인하고 `녹음·전사 시작`을 누르면 음성 녹음과 한국어 인식이 함께 시작된다. 인식된 글자가 녹음 중 표시되며, 확정 전 문장은 `인식 중`으로 구분한다. 일시정지와 재개를 함께 처리하고, 인식이 끊겨도 녹음과 이미 나온 문장은 유지한다. 재연결은 사용자가 누른다.

녹음을 마치면 마지막 인식 결과를 기다린 뒤 전사문을 수정할 수 있다. `녹음·전사 저장`은 음성 파일을 Storage에, 전사문을 별도 비공개 테이블에 저장한다. 파일 업로드 후 연결에 실패하면 파일을 다시 올리지 않고 재시도한다. 저장 전에도 전사문을 TXT로 내려받을 수 있다.

저장한 전사문은 다시 열기·수정·TXT 내려받기·미팅 메모에 추가가 가능하다. 처음 인식한 구간과 확정 여부는 보존하며 수정본과 구분한다. 미팅 메모 추가는 명시적 행동이고, 공동 메모이면 공개된다는 안내 후 확인한다. 기존 작성 중 메모 뒤에 추가하며 자동 피드백 등록이나 교수 확인 변경은 하지 않는다.

## 구현 방식과 한계

브라우저 Web Speech API의 `SpeechRecognition` 또는 `webkitSpeechRecognition`을 감지하고 `lang=ko-KR`, `continuous=true`, `interimResults=true`로 실행한다. Gemini 키·새 API 키·브라우저 모델 다운로드는 이 경로에 필요하지 않다. Gemini 생성 호출이나 AI 사용량으로 집계하지 않는다.

이는 모든 브라우저에서 같은 인식 엔진을 보장하는 방식이 아니다. 지원하지 않는 브라우저는 미지원 안내와 음성만 녹음을 제공한다. 지원 API가 있어도 인식 서비스 권한·네트워크·브라우저 환경으로 실패할 수 있다. 일부 브라우저는 음성을 제공자의 서버로 보내므로 녹음 전 동의 화면에서 알린다. 오프라인 동작이나 한국어 정확도를 보장하지 않는다. 여러 화자의 이름·역할, 감정, 발언의 사실 여부는 판정하지 않는다.

실제 장치의 인식 정확도·마이크와 인식 서비스 동시 사용·Safari/Chrome 차이·인식 시작 지연은 사용자 마이크 검사 후 확인한다. 자동 검사에서 넣은 한국어 문자열은 실제 음성 인식 결과가 아니다.

## 저장·권한

- `rms_live_transcripts`: 녹음 ID, 소유자, 언어·엔진, 원 인식 구간, 수정문, 미확정 구간, 동의 시각, 경고, 수정 번호를 저장한다.
- 녹음을 공유해도 전사문은 자동 공유되지 않는다. 작성자만 읽고 고친다. 교수와 공동 편집자는 직접 API를 사용해도 읽지 못한다.
- 원 인식 구간과 동의 기록은 수정 RPC로 덮어쓸 수 없다. 수정문은 번호를 대조해 저장하며 오래된 다른 내용은 HTTP 409로 거부한다.
- 서버 응답 유실 후 같은 저장 재시도는 중복 생성하지 않는다. 휴지통에서는 접근을 막고 복원 후 기록을 유지한다.
- 작성 중 이탈 경고, 저장 실패 시 작성본 유지, 인식 중단·미확정 안내를 제공한다. 새로고침으로 저장 전 음성이 사라질 수 있으므로 저장 전에 페이지를 닫지 않도록 경고한다.

## 확인한 범위

- 인식 제어 8개, 녹음·글자 표시·수정·저장 연결 5개를 모의 이벤트로 검사했다. 실제 마이크 인식 검사와 구분한다.
- DB 검사 5개를 추가했다. 실제 Supabase에서도 새 가상 연구·1초 무음 파일·저장 검사용 한국어 입력으로 저장/수정/권한/재로그인/휴지통·복원 6항목을 확인했다. 해당 연구는 보관했다.
- Gemini 전사 API와 실시간 Live API는 연결하지 않았다. 서버 스트리밍 전사가 필요하면 별도 API 연결·비용·운영 조건을 정한 뒤 확장한다.

## 공식 근거

- [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition): 지원 범위와 서버 기반 인식 가능성.
- [중간 결과](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/interimResults): 아직 확정되지 않은 문장의 갱신.
- [언어 지정](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/lang): BCP 47 언어 태그 설정.
- [PostgREST 오류 응답](https://docs.postgrest.org/en/stable/references/errors.html#raise-errors-with-http-status-codes): 편집 충돌에 HTTP 409를 반환하는 근거.
