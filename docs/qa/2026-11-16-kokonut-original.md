## 미확인

- 사용자의 원본 데모 대비 시각 검수와 모바일.
- 실제 AI 호출·실제 마이크 입력·실제 메일 수신.
- 이번 변경의 클라우드 배포. 배포하지 않았다.

첫 연결 흐름 검사에서 이전 UI의 메뉴 역할과 “지금 보내기” 버튼을 기대하던 4개 검사가 실패했다. 원본의 실제 역할과 5초 뒤 전송/되돌리기 동작을 대상으로 수정한 뒤 최종 29개가 통과했다. 원본 UI를 이전 검사에 맞춰 변경하지 않았다.

검사 로그와 변경 전 백업은 /tmp/margin-kokonut-20261116/에 있다. 임시 폴더는 영구 보관을 보장하지 않는다. 변경 전 추가 백업은 /tmp/margin-qa-20261116/before.patch다. 기존 작업 파일을 보존했고 .claude/와 별도 ia-v2/ 작업은 이번 원본 도입에 포함해 수정하지 않았다.

## 최종 스크린샷 후속 수정 확인

- 실제 코코넛 AI Input Selector 데모의 모델 메뉴를 열어 치수와 구성을 관찰했다.
- 로컬 앱에서 접힌 사이드바·프로필 팝업을 직접 관찰하고, 개발용 시연에서 입력·응답·근거 미리보기·첨부 상태·대기 줄·검색형 입력·이어쓰기·선택 편집·전송·일정·검토 넘기기·트리머·모델 트랙·음성 대기·테마를 스크린샷으로 확인했다.
- 별도 검토 에이전트가 첨부 상태 분리, 질문 유실, 음성 닫기 문제를 찾아 root가 수정했다. 첨부 회귀 테스트 2개와 질문 보존/너비/resize 회귀 검사도 포함했다. 작업자의 보고를 그대로 완료 증거로 쓰지 않고 수정 diff와 통과 결과를 확인했다.
- 최신 main 기반 별도 배포 작업 폴더에서 단위/컴포넌트 549개, 서버 로직 65개, 데스크톱 브라우저 흐름 36개가 통과했다. 시각 확인은 위 관찰 범위에 한하며 모든 입력/오류 조합의 검수 완료를 뜻하지 않는다.
- 일반 HTML 기본 스타일을 base 레이어로 옮겨 원본 크기·색·포커스가 덮이는 원인을 고쳤다. 낮은 배경 틴트가 단색이 돼 사라진 글자와 다크 모드의 이중 투명도도 수정했다.
- 시연 주소: http://127.0.0.1:4173/dev/kokonut-review.html. 별도 개발 진입점이고 프로덕션 배포 파일에 포함하지 않는다. 예시는 가상이며 실제 AI·마이크·메일·서버 저장을 실행하지 않는다.
- 스크린샷은 사용자에게 전달하는 로컬 시각 산출물 폴더 kokonut-review에 저장했다. 실제 개인정보나 연구 자료는 사용하지 않았다.
- 이 문서의 앞선 ‘커밋/푸시/배포 없음’ 표는 최초 도입 시점 기록이다. 후속 사용자 승인으로 커밋·PR·배포를 진행하며 최종 배포 결과/커밋은 GitHub PR과 Actions 기록을 따른다.
