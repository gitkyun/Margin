### 기능 확인 통과 항목(요약)

- 정상 흐름: 연구 → 미팅 → 메모 자동 저장 → 결정 → 할 일 → 완료(새로고침 유지) → 되돌리기(새로고침 유지) → 문서 v1·v2 → 바뀐 부분 비교(추가 문단만 ‘추가’로 표시) → 검토용 PDF → 수정 결과 → 검토 요청(링크 생성, 전송 아님 안내) → 교수 ‘추가 수정 필요’+이유 → 학생 화면에 같은 글자로 표시 → ‘수정 결과에서 고치기’.
- 중복 제출(실제 두 번 누르기): 연구·결정·수정 결과·검토 요청·댓글·로그인 모두 요청 1회.
- 스크립트·태그 문자열(`<img src onerror=alert(1)>`(실제로 넣은 값은 src=x), `<script>`, `<b>`): 제목·설명·댓글에서 글자 그대로 표시, 실행 없음.
- 검증: 교수 이메일 형식 오류(브라우저 기본 검증), 가입하지 않은 이메일(서버 400 → “등록된 교수 계정의 이메일을 입력해 주세요.”), ‘추가 수정 필요’ 이유 빈칸·공백만(요청 없이 차단).
- 권한: 교수 계정으로 학생 연구·할 일·문서 주소 → “이 연구를 열 수 없어요”. 학생 계정으로 없는/남의 검토 ID → “이 검토를 열 수 없어요”. 404는 HTTP 404 + ‘첫 화면으로’.
- 인증: 로그인 안 하고 `/r` → `/login?next=%2Fr` → 로그인 뒤 원래 주소로 돌아옴. 로그아웃 뒤 뒤로 가기 → 로그인 화면. 틀린 비밀번호·없는 이메일 → 같은 안내(가입 여부 노출 없음).
- 저장하지 않고 닫기 경고: 할 일로 만들기에서 Esc → “저장하지 않고 닫을까요?”.
