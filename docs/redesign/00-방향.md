# Margin 재설계 방향 (2026-11-27, 잠정)

> **상태: 잠정.** 아래 '사용자가 정한 것'은 사용자가 레이아웃 그림만 보고 고른 것입니다. 실제로 눌러 보는 시안을 보고 다시 정합니다. 이 문서는 [IA v2 설계서](../design/ia-v2/00-README.md)를 아직 대체하지 않습니다. 시안이 확정되면 그때 IA v2·AGENTS.md를 고치는 별도 PR을 만듭니다.

## 1. 왜 다시 잡나

2026-11-24~26에 지금 앱을 화면 142개로 쪼개 결함을 찾고 "유지·보완·통합…"으로 판정했습니다. 그러나 사용자(실제로 앱을 쓰는 대학원생)의 말은 달랐습니다.

> "수정하고 QA 하라는 게 아니라 대대적 변화를 꿈꿨어. AI가 만든 거다 보니 실제 내가 쓰는 데 너무 어렵더라고." (2026-11-27)

사용자가 말한 어려움(2026-11-27, 사용자 답 그대로 요약):

- **UX 라이팅이 어렵다.** 화면 말이 시스템 말이다.
- **기록할 게 너무 많다.** "내 연구 넣고 뭐 넣고 하다가 한 주 다 가겠다."
- **흐름이 단순해야 한다.** 지금은 내가 쓰는 다른 서비스들과 너무 동떨어진 느낌이다.
- 하고 싶은 일은 하나다: **내 연구 완성하기** — 피드백 받고, 원고 쓰고, 미팅 준비하고, 기록 남기고, 교수님께 보내기.

그래서 결함을 고치는 대신 **사용 흐름과 화면 구조를 다시 짭니다.**

## 2. 누구를 위한 앱인가 (확정)

- **주 사용자는 학생**입니다. 교수님은 자주 들어오지 않습니다. 교수님 화면은 "받은 것 읽고 답하기" 하나면 됩니다.
- 피드백은 이렇게 들어옵니다: **대면 미팅에서 말로**, **카톡으로**, **한글 파일에 빨간 글씨로**.
- 사용자가 좋았다고 한 서비스: **라이너, 토스증권, 매니패스트**.

## 4. 원칙 (이 방향에서 지킬 것)

1. **사용자가 하는 일 단위로 화면을 짠다.** 데이터 종류(피드백·할 일·결정·질문·자료)별로 메뉴를 나누지 않는다. 미팅 하나, 원고 하나, 보내기 하나.
2. **입력은 붙여넣기·끌어다 놓기로.** 카톡 대화, 한글 파일, 미팅 녹음을 넣으면 도우미가 결정·할 일·질문으로 나눠 제안하고, 학생은 고르기만 한다. 칸을 하나하나 채우게 하지 않는다.
3. **피드백은 쓰는 자리 옆에.** 원고를 고칠 때 '고칠 것'이 원고 옆에 있고, 문장과 이어진다.
4. **보내기는 한 번.** 무엇을 보낼지 미리 골라 두고, 한마디도 도우미가 먼저 쓴다. 보낸 뒤에는 "보냄 → 열어 보심 → 답장"만 보인다.
5. **가끔 쓰는 것은 안쪽에.** 설정·휴지통·연구 바꾸기·사용량은 오른쪽 위 내 메뉴 안.
6. **쉬운 말.** 아래 5절.
7. **지금 앱의 안전장치는 지킨다.** AGENTS.md 제품 불변 조건(원문 보존, 자동 영구 삭제 금지, 비공개 대화는 AI에 안 보냄 등)은 이 재설계에서도 그대로다. 바꿔야 하면 사용자에게 따로 묻는다.

## 7. 재설계와 상관없이 남은 실제 문제

지난 검토 문서들이 찾은 문제 중, 화면을 바꿔도 사라지지 않는 것입니다. **지난 문서에 적힌 내용이고, 이번 정리에서 코드로 다시 확인하지는 않았습니다.** 구현 단계에서 각각 재현부터 합니다. 근거 경로는 `re-evaluation/` 기준입니다.

1. 겸임 교수가 받는 교수 이메일을 바꾸고 재확인 차수를 만들 수 있음 — 서버 `rms_set_sharing`·`rms_recheck` 권한 검사 (`03-architecture-root-causes.md`, `2026-11-25_5단계-전_화면수집_v2/README.md`)
2. 원고 복원: 제목·서식만 바꾼 상태가 백업에서 빠지고, 복원이 요청 4개로 나뉘어 중간 실패 시 어긋남 (`2026-11-26_5단계-진입검토_v1/` RC-9)
3. 저장 중 '나만 보기'로 바꾸면 화면은 '저장됨', 서버는 계속 공유 (같은 문서)
4. 충돌 창 '내가 쓴 내용 유지' 뒤 다음 저장이 상대 내용을 덮어씀 (`2026-11-26_09-교차검토_v1/`)
5. 기록에서 만든 할 일이 '직접 추가'로 보이고 기록 필터에서 빠짐 (RC-10)
6. 완료 취소 시 화면마다 '진행 중'/'시작 전'으로 갈림 (09 교차검토). 사용자 결정: 직전 상태로
7. '음성 공유'가 확인 없이 바로 공동연구자에게 공개됨 (09 교차검토)
8. 완전 삭제 확인 이름을 화면이 자동으로 채우고, 서버 비교에 공백·정규화 처리가 없음 (`06-independent-review.md`)
9. 사용량 문구가 실제 규칙(월 크레딧 + 분당 횟수)과 다름 (09 교차검토)
10. AI 답변의 인용 링크가 열리지 않거나 원문으로 못 감 (`2026-11-25_5단계-전_화면수집_v2/README.md`)
11. 역할 판정에 보내는 쪽/받는 쪽 구분이 없어 겸임 교수를 학생처럼 다룸 (RC-1)

새 화면 구조에서 1·5·6·11은 '교수님께 보내기'·'고칠 것' 설계와 바로 이어집니다.
