# 다음 작업: 눌러 보는 화면 시안

> 이 문서만 읽고도 작업할 수 있게 썼습니다. 먼저 [README](README.md)와 [00-방향](00-방향.md)을 읽어 주세요.

## 왜 시안부터인가

지금까지 정한 방향은 사용자가 **레이아웃 그림만 보고 고른 잠정안**입니다. 실제로 눌러 보고 써 봐야 맞는지 압니다. 그래서 앱 코드를 고치기 전에, 실제 크기(1440×900)로 **눌러 볼 수 있는** HTML 시안을 먼저 만듭니다. 사용자가 시안을 보고 말로 정하면, 그때 앱 구현 작업을 따로 만듭니다.

## 공통 규칙 (모든 카드)

- **건드려도 되는 곳**: `docs/redesign/prototypes/<카드 번호>-<이름>/` 새 폴더, 그리고 카드가 따로 허락한 파일.
- **건드리면 안 되는 곳**: `apps/`·`supabase/` 등 앱 코드, `docs/redesign/re-evaluation/`(지난 기록, 읽기만), 다른 카드의 폴더, `AGENTS.md`의 제품 불변 조건.
- 작업 하나 = 브랜치 하나 = PR 하나. 브랜치 이름 `design/<카드 번호>-<이름>`. main에 직접 올리지 않습니다.
- 형식: [쉬운보기 시안](re-evaluation/2026-11-27_쉬운보기_v1/)과 같은 틀을 씁니다.
  - 위쪽 버튼으로 `지금` / `바뀐 뒤 · …` 화면을 바꿉니다. `지금`은 `re-evaluation/assets/` 안 실제 캡처를 그대로 씁니다.
  - 앱 화면은 1440×900으로 그리고 줄여서 보여 줍니다(`app.css`의 `.stage`·`.screen` 참고). `app.css`는 복사해서 쓰고 원본은 고치지 않습니다.
  - 화면 아래에 "무엇이 바뀌었나 / 없어지는 것 / 확정·제안" 설명 칸을 둡니다.
- **눌러 볼 수 있게**: 버튼·체크·탭·창 열기/닫기 정도는 실제로 동작하게 합니다(순수 HTML·CSS·JS, 외부 라이브러리 없이). 저장·서버 연결은 하지 않습니다.
- **같은 이야기로**: 모든 시안은 [00-방향](00-방향.md)의 "공통 장면"(김학생, 제7차 논문 지도 11월 28일 등)을 씁니다. 실제 사람 이름·이메일·연구 자료는 쓰지 않습니다. 이메일은 `@margin.com` 체험 주소만.
- **글은 쉬운 말로**: 해요체, 한 문장 한 가지. "수정 결과", "검토 요청", "공유 범위" 같은 시스템 말 대신 사용자가 하는 일로 씁니다([00-방향](00-방향.md) 5절 말 바꾸기 표).
- **확정과 제안을 섞지 않기**: 설명 칸에 사용자가 정한 것(확정)과 내가 새로 넣은 것(제안)을 나눠 적습니다. 지금 앱에 없는 기능(예: 한글 파일 읽기)은 "기술 확인 필요"라고 씁니다.
- **참고 서비스 캡처 다루기**: `re-evaluation/` 안 참고 서비스 캡처에는 저장소 주인의 실명·이메일·IP가 찍힌 것이 있습니다. 시안 안에서 참고 그림으로 쓰는 것은 괜찮지만, 저장소 밖으로 옮기거나 외부 AI 서비스에 올리지 않습니다. 새로 찍을 때는 로그인하지 않은 공개 화면을 우선합니다.
- **검사**: 브라우저에서 1440px·1280px로 열어 모든 버튼을 눌러 보고, 콘솔 오류 0건, 깨진 이미지 0건을 확인합니다. 로컬 확인은 `docs/redesign` 폴더에서 `python3 -m http.server 8765` 후 `http://localhost:8765/...`.
- **PR 설명**: 무엇을 그렸는지, 확정·제안 목록, 사용자에게 물어볼 것(최대 3개), 확인한 것과 못 한 것.

|---|---|---|---|
| P1 | 홈 | A안(다음 미팅 큰 카드 + 할 일 + 레일·도우미)을 눌러 보게. 할 일 체크, 미팅 카드 누르면 미팅으로, 레일 열고 닫기. 연구가 막 시작된 날(미팅 0개)과 바쁜 날(할 일 12개) 두 상태도 | `02-home-directions.html`, `14_home_main_1440.png` |
| P2 | 미팅 한 페이지 | 준비 → 미팅 중 → 기록 넣기 → 정리. 카톡 대화 붙여넣기 → 결정·할 일·질문으로 나뉘는 흐름을 눌러 보게. 녹음·전사는 지금 앱에 있음(AGENTS.md 불변 조건 지킴) | `03-meeting.html`, `19_meeting_detail_1440.png` |
| P3 | 원고와 고칠 것 | 장 목록 · 원고 · 고칠 것 세 칸. 고칠 것을 누르면 해당 문장으로, '고쳤어요'로 내려가기. 한글 파일 빨간 글씨 가져오기 창 | `05-writing.html`, `25_writing_editor_1440.png` |
| P4 | 교수님께 보내기 | 보내기 창(미리 골라 둔 것 바꾸기, 한마디 고치기) → 보낸 뒤 상태 → 교수님 화면 → 교수님 답이 학생 '고칠 것'으로 들어오는 것까지 한 바퀴 | `04-send.html`, `30_review_detail_1440.png` |
| P5 | 내 메뉴와 설정 | 오른쪽 위 내 메뉴, 설정 10탭 → 4묶음(나, 이 연구, 알림, 도우미), 휴지통·되돌리기 | `06-map.html`, `31_settings_*` 캡처 |
| P6 | 처음 쓰는 날 | 가입 → 온보딩(지금 것 유지) → 첫 미팅 만들기 → 홈. 첫 화면에서 막히는 곳이 없는지 | `re-evaluation/assets/live-desktop/` 온보딩·홈 캡처 |

P1~P5는 서로 다른 폴더만 건드리므로 동시에 해도 됩니다. P6은 P1이 합쳐진 뒤 시작하는 것을 권합니다. P7은 언제든 됩니다.

## 완료 기준 (모든 카드)

- [ ] `docs/redesign/prototypes/<카드>/index.html` 하나로 열린다.
- [ ] `지금` 화면과 `바뀐 뒤` 화면을 버튼으로 바꿔 볼 수 있다.
- [ ] 카드에 적힌 동작이 실제로 눌린다.
- [ ] 설명 칸에 확정·제안·기술 확인 필요가 나뉘어 있다.
- [ ] 콘솔 오류 0건, 깨진 이미지 0건(확인한 화면 크기를 PR에 적음).
- [ ] 앱 코드·지난 기록·다른 카드 폴더를 고치지 않았다(`git diff --stat`으로 확인).
