## 시안 보는 법

GitHub 화면에서는 HTML이 그림으로 안 보입니다. 저장소를 받은 뒤:

```bash
cd docs/redesign/re-evaluation
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765/2026-11-27_쉬운보기_v1/02-home-directions.html` 처럼 엽니다.

| 파일 | 내용 |
|---|---|
| `01-home.html` | 첫 시도: 지금 홈 위에 바뀐 곳만 덧그림. 사용자 평: "보기는 좋은데 이 정도 변화를 바란 게 아니다" |
| `02-home-directions.html` | 홈 지금 / A안 / B안. **A안 선택** |
| `03-meeting.html` | 미팅 한 페이지(미팅 전 / 미팅 후). 승인 |
| `04-send.html` | 교수님께 보내기(보내기 창 / 보낸 뒤 / 교수님 화면) |
| `05-writing.html` | 원고 + 고칠 것, 한글 빨간 글씨 가져오기 |
| `06-map.html` | 지금 기능이 어디로 가는지, '안쪽(내 메뉴)'이 뭔지 |

참고 서비스 캡처는 개인정보 때문에 빠져 있어서 시안 아래 '참고한 화면'의 그림은 보이지 않습니다(설명 글은 남아 있음).
