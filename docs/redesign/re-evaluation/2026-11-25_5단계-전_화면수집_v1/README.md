# 마진 5단계 전 화면 대조와 버튼 검증

2026년 11월 25일 · 마진 기준 `4fce15e` · [새로 수집한 화면 갤러리](index.html)

**지금 설계에 써도 되는 자료는 화면 모드의 선택 방식, 사이드 창, 생성 메뉴, 검색, 파일·기록 추가, 외부 의견 폼, 공개 랜딩이다. 교수 검토, 시간 조율, 원고·PDF, 연구자 권한은 실제 흐름을 다시 맞춰볼 화면이 남아 있다.** 같은 일을 하려는 사용자가 무엇을 누르고 결과를 어디에서 확인하는지 기준으로 비교했다.

갤러리에 검수한 125장을 실었다. 토스증권 17장, 라이너 12장, 매니패스트 29장, 마진 63장, Modulify 3장, 오픈서베이 1장이다. 파일에는 제품과 조작 상태, 촬영 당시 화면 크기를 적었다. 최초 저장한 134장 중 같은 내용이 반복되거나 원하는 조작 영역이 잘린 9장은 검수 보관 폴더에 옮겼다.

5단계에서 먼저 확인할 안은 **마진 계정 메뉴의 세 선택을 화면 설정에서도 쓸 수 있게 하는 것**이다. 토스증권식 그림은 현재 화면이 어떻게 바뀌는지 보여 주고, 매니패스트식 빠른 버튼은 한 번에 바꾸는 데 유리하다. 설정창, 계정 메뉴, 새로고침, 기기 모드 변경의 네 장면이 있어야 같은 선택이 일관되게 적용되는지 판단할 수 있다. 시스템 선택 후 기기 자체를 바꿔 보는 검사는 추가로 남아 있다.

## 4. 5단계 전에 보강할 순서

1. **교수 검토와 권한.** 합성 PDF를 두 항목에 붙여 학생, 지정 교수, 편집자를 겸한 교수가 같은 링크를 열게 한다. 요청 전, 항목별 응답, 위치 댓글 해결, 한 항목만 2차, 이전 차수 열람을 한 묶음으로 찍는다. 상대는 오픈서베이 문항 댓글과 GitHub의 리뷰 재요청이 우선이다.
2. **미팅과 후속 조치.** 가상 발화에서 구절을 선택해 원문·타임스탬프를 보존한 채 피드백과 할 일로 연결하고, 완료한 뒤 원래 구절로 돌아가는 장면을 모은다. 매니패스트의 회의록과 Otter의 발화 위치가 대응한다.
3. **시간 조율.** 주최자 후보 추가, 외부 참여자 응답, 수정, 확정, 다시 열었을 때 잠긴 상태를 찍는다. 데스크톱과 390px 두 폭에서 같은 후보를 쓴다. 토스증권 일정 화면은 날짜 탐색에 쓰고, 응답은 Doodle을 붙인다.
4. **문서·PDF.** 자료 올리기 성공/일부 실패, 목록→미리보기→상세, 한 페이지 주석이 달린 PDF, 두 파일 버전 전환, 이전 버전 복원을 수집한다. 마진의 원고 자동 저장과 비교는 이미 실행했으므로 같은 장면을 추가 수집하기보다 충돌과 복원을 채운다.
5. **화면 모드·일괄 정리.** 시스템을 고른 뒤 기기 모드 변경, 새로고침, 계정 메뉴↔설정, 모바일 화면을 같은 가상 연구에서 확인한다. 연구 보관·복원과 자료 보관·복원은 각 진입점과 되돌리기까지 비교한다.

기존 감사에서 온보딩 4번째 질문의 ‘계속’을 최종 버튼으로 읽었던 부분은 실제 흐름과 달랐다. 화면은 별도 검토 단계로 이어지고, 그 다음 ‘내 연구 홈으로’가 나온다. `건너뛰고 빈 연구로 시작`이 어떤 입력을 저장하는지는 다른 문제로 남는다. 참고 사례를 보강하면서 `크레딧 %를 쓰는 곳이 없다`는 표현도 범위를 좁혔다. 매니패스트 공식 안내는 잔량이 적을 때 입력창에 퍼센트를 표시한다고 설명한다.
