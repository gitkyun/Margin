**교수 검토에서는 버튼을 누를 수 있는 사람과 화면 안내를 먼저 맞춰야 합니다. AI에서는 답변의 주장과 실제 근거가 연결되는지부터 봐야 합니다.** 교수 검토는 격리 계정에서, AI는 운영 마진에서 재현했습니다. 버전 이력, 저장 상태, PDF 검색은 기존 제품에서 비교할 기준을 확보했습니다. 자료 일괄 선택과 문단 댓글은 기존 동작에서 어디까지 확장할지 비교 시연이 필요합니다.

갤러리는 **280장**입니다. 이전 125장에 155장을 보강했습니다. 새 자료는 교수 검토 28장, 미팅·조율 17장, 원고·화면 설정 22장, 운영 AI 14장, 모의 AI 18장, 참고 서비스 45장, 공식 라이브러리 데모 11장입니다. 보강분을 포함해 토스증권 17장, 라이너 16장, 매니패스트 40장입니다.

여기서 5단계는 전달받은 인계서의 **사용자에게 검토 결과 제시**를 뜻합니다. 저장소의 정보 구조(IA) 개편 5단계는 11월 19일 병합 기록이 있습니다. 검토 결과에는 후보의 적합성까지 적었으며, 앱 코드와 운영 설정에 후보를 적용하지 않았습니다.
