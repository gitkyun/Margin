# 마진 라이브러리 후보 60개 대조

2026년 11월 25일 · 마진 기준 커밋 4fce15e · [화면 1:1 대조표](README.md) · [캡처 갤러리](index.html)

전달받은 인계서의 01~60번을 현재 코드와 수집 화면에 대조했다. **첫 시연은 AI 답변의 근거와 표·수식, 문서 버전 이력과 저장 상태, 자료 일괄 선택, 교수의 문장 위치와 댓글**을 권한다. 각각 근거의 본문을 열지 못하거나, 비교·저장·처리 상태를 읽기 어려운 장면과 연결된다.

- **화면**은 이번 갤러리 또는 앞선 수집본의 관찰이다. 운영 AI, 격리 브라우저, 주입 오류, 공식 제품 예시는 갤러리에 표시된 유형을 따른다. **코드**는 현재 파일에서 화면 연결이나 구현을 확인한 근거다. **신규 후보**는 전용 화면 또는 데이터 연결을 찾지 못한 작업으로, 이 표에서 제품 결정으로 확정하지 않았다.
- **P1**은 5단계에서 먼저 비교할 항목, **P2**는 마진 화면과 후보를 추가 대조할 항목, **P3**는 현행 유지나 후순위 판단이다. 후보 링크는 공식 페이지 또는 공식 소스다. 공개 프리뷰는 원본 동작의 관찰 범위이며, 마진의 실제 데이터와 키보드·모바일·다크 연결 검증은 채택 검토에서 따로 진행한다.
- Wanted Montage와 현재 Coss 연결은 기본으로 유지한다. Kokonut은 원본 연결을 기준으로 삼되 현재 렌더링 경로를 확인했다. 보관된 원본 18개라는 기록은 당시 가져온 파일 수다. 현재 일반 연구 대화의 자료 범위는 요청자가 읽을 수 있는 연구 기록이다. 실제 서버는 최신 항목 500개 범위와 연구 기록 본문 한도 48,000자 안에서 근거를 가져온다. 입력창의 자료 붙이기는 특정 기록에 한도를 먼저 배정한다. 일반 질문은 남은 한도에 연구 기록을 더 읽고, 웹 검색 요청은 질문만 사용한다. 화면에 남은 “선택한 기록과 질문만”은 일반 대화의 동작과 어긋난다. 지침에는 기록 선택 화면을 두지 않는다고 되어 있지만, 현재 입력창에는 글·자료·미팅을 고르는 대화상자가 있다. 이 버튼은 자동으로 포함되는 범위를 좁히는 설정처럼 보이지 않도록 판단할 필요가 있다. 작업 지침 (`../../../Margin-repo/AGENTS.md`, 저장소에 없음) · Kokonut 도입 기록 (`../../../Margin-repo/docs/design/kokonut-map.md`, 저장소에 없음) · AI 서버 (`../../../Margin-repo/apps/home-preview/supabase/functions/ai-assist/index.ts`, 저장소에 없음) · 계정 설정 (`../../../Margin-repo/apps/home-preview/src/pages/SettingsPage.tsx`, 저장소에 없음)
- 이 표의 5단계는 인계서에서 사용자에게 비교 결과를 제시하는 단계다. 저장소의 IA v2 로드맵에는 구현 0~5단계가 2026년 11월 19일에 병합됐다고 기록돼 있다. IA v2 로드맵 (`../../../Margin-repo/docs/design/ia-v2/11-roadmap.md`, 저장소에 없음)

## 공식 원본을 비교할 때 확인한 조건

- EasyUI의 공식 저장소는 MIT로 표시된다. Recovery Ledger는 스냅샷 목록 데모, Selection Basket은 선택·일괄 조작의 화면 예시다. 각각 마진의 버전 복원과 행 권한을 연결할 필요가 있다. [EasyUI 공식 저장소](https://github.com/Surajmaurya1/easyui) · [Recovery Ledger](https://easyui.site/components/recovery-ledger) · [Selection Basket](https://easyui.site/components/selection-basket)
- affectUI Comment Thread 공개 문서는 MIT를 명시한다. 예제는 한 스레드와 답글 위계 중심이다. 마진의 검토 차수, 공개 범위, 해결 권한은 현재 코드의 조건을 따르게 한다. [affectUI 공식](https://www.affectui.com/components/comment-thread)
- React Bits 무료판은 MIT + Commons Clause를 따른다. Pro는 구매 라이선스와 개발자 좌석 조건이 있으며 원본이나 일부 수정 소스를 공개 저장소에 배포하는 데 제한이 있다. 이 표의 Pro 항목은 공개 프리뷰 비교 후보다. [무료판 원문](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) · [Pro 라이선스](https://pro.reactbits.dev/license)
- ReUI의 Base UI 문서에는 Data Grid와 Filters의 공식 코드 예제가 있다. 올리기·삭제·공개 범위 등 마진의 작업 규칙은 붙지 않은 예시다. Streamdown은 Apache 2.0을 따르며, 공식 문서에는 표·수식·동아시아 문자 지원이 있다. 마진의 문장 옆 인용과 링크 규칙을 유지하는 화면 시험이 필요하다. [ReUI Data Grid](https://reui.io/docs/components/base/data-grid) · [ReUI Filters](https://reui.io/docs/components/base/filters) · [Streamdown](https://streamdown.ai/) · [라이선스](https://github.com/vercel/streamdown/blob/main/LICENSE)
