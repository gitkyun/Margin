## 확정하기 전에 대조할 설계

| 항목 | 현재 화면과 제안 | 다시 볼 장면 |
|---|---|---|
| 겸임 교수의 발신 동작 | 지정 교수와 편집자를 겸하면 공유 중지 후에도 편집자로 읽는다. 일반 편집자의 발송 권한과 지정 교수 본인의 알림 전송 거절 규칙이 다르다. 겸임 당사자의 수신자 변경·공유 중지·재확인 제한은 재검토 중이다. | 학생·겸임 교수·새 지정 교수·일반 편집자로 같은 검토를 열고 각 버튼의 결과와 이유를 확인한다. 기존 운영 역할만으로 새 기능을 가정하지 않는다. |
| 공유 중지 확인 | 일반 확인 버튼은 제안이다. 교수 응답이 막히는 조건과 공동편집 열람 여부를 확인 문구와 완료 피드백에 반영한다. | 중지 직후, 다시 열기, 재개, 지정 교수 교체 각 화면. |
| 휴지통 복원과 완전 삭제 | 현행 연구 복원 뒤 두 시험 검토는 모두 공유 중지였다. 연구 복원 시 과거 교수 링크도 다시 열지 여부는 미정이다. 6초는 할 일·글과 자료의 기존 되돌리기 시간이다. 연구에도 같은 시간을 쓸지, 완전 삭제를 이름 입력으로 바꿀지는 재검토한다. | 공유 중·중지 혼합 연구 복원, 닫기·오류·동시편집, 길고 같은 연구 이름, 한글 조합 입력·공백·유니코드 정규화. 실계정 영구 삭제 없이 격리 시험을 한다. |
| 홈 할 일 정렬 | 다음 미팅에 연결한 일이 먼저 온다. 사용자에게 첫 묶음의 기준이 붙지 않는다. 공동연구의 `내 할 일`에는 담당자가 없는 항목도 들어간다. | 먼저 제목을 붙여 이해되는지 본다. 동일 자료로 마감 순서, 미담당 표시, 첫 진입의 의미도 비교한다. |
| 글·자료 미리보기 열 | 넓은 목록에는 `함께 보기` 열이 있고 미리보기와 함께 열 때 가려진다. 개인 자료 자물쇠는 남는다. | 긴 제목, 공동·개인 자료, 390px과 미리보기, 여러 건 선택 및 일부 실패에서 공개 범위를 어디서 읽는지 본다. |
| 스크롤바 자리 | 현재 루트 스타일에 스크롤바 자리 고정이 있다. 조사 환경에서 제목 x=268px, 본문 폭 1,044px, 폭을 차지한 스크롤바 0px로 측정됐다. | 실제 폭을 차지하는 스크롤바 설정이 있는 브라우저에서 연구 셸과 외부 페이지를 각각 잰다. |
| 의견 수집 | 현재 레일의 의견은 메일 연결이다. 앱 안에서 입력·저장하는 방식은 재검토 안건이다. | 초안·취소·전송 실패, 사용자 조사 정보 첨부 및 현재 문의 주소와의 관계를 확인한다. |
| 퍼센트, 사용량과 모델 | 현행 화면의 월 크레딧·예약·사용 수치와 총 실행·성공·실패를 각각 읽어야 한다. 진행·취소도 총 실행에 포함된다. 25일 22:32과 26일 11:13 운영 화면에는 사용 75, 예약 36이 표시됐다. 표시의 반올림과 실제 잔액·예약 정산은 따로 조사한다. | 정수로 0%가 되는 낮은 사용량, 월 추가 지급, 예약 해제, 월 경계, 공급 모델별 가능·오류 결과. 기존 수치가 현재 잔액과 같은지는 운영 검증에서 다시 확인한다. |

위 행의 결정 근거는 [정정 결정표](../v2-2026-11-25-corrected/07-decision-ledger.md)와 [이후 재검토](../2026-11-25_5단계-전_라이브러리-기본값_v3/README.md)에 있다. 제안의 우선순위는 저장·복구와 레코드 연결을 확인한 뒤 적용한다.

## 설치 부품과 후보를 판단하는 기준

- **기본 조작**은 Montage 버튼·필드·창·세그먼트, Coss 탭과 Base UI 선택, Radix·shadcn 계열 메뉴, cmdk 검색, Sonner 알림이 맡는다. Coss 세그먼트 본체는 조사 커밋의 제품 호출에서 쓰이지 않았다. 설치판 라이트·다크에서 방향키, 닫기, 비활성, 초점을 비교한다.
- **작업 기능**은 Tiptap의 원고 편집, jsdiff와 React Compare Slider의 버전 비교, PDF.js 읽기와 React PDF 내보내기, React Dropzone 첨부, FullCalendar 일정과 Kokonut 오디오·도우미 구성 등을 실제 화면 경로에 맞춰 확인한다. 세부 버전과 원본 18개 매핑은 [설치판 대조](../2026-11-25_5단계-전_라이브러리-기본값_v3/라이브러리-1대1.md)에 있다.
- **신규 후보**는 전달받은 60개 표의 각 행을 기준으로 재검토한다. PDF 탐색, 문장 위치 댓글, 제안 채택, 자료 일괄 작업, 버전 이력, 입력·오류 상태가 기존 코드에서 어디까지 가능한지 확인한다. 먼저 작은 시연을 만들어 실제 작업 결과가 같은지 비교한다. 공식 문서와 고지에서 라이선스, 사용 조건, 패키지 버전을 확인한 뒤 도입을 논의한다. [후보 60개 대조표](../2026-11-25_5단계-전_화면수집_v2/라이브러리-후보-60개.md) · [받은 원문](첨부/이전_AI_라이브러리_검토_원문.txt)
