## 목표와 현재 위치

마진은 학생이 미팅과 피드백을 기록하고, 할 일을 거쳐 원고를 수정하고, 필요한 항목만 교수에게 보내 확인받는 연구 도구다. 다음 작업의 목표는 이 흐름을 일관되게 만들고, 5단계에서 제시할 설계 대안에 실제 화면과 버튼 조작 근거를 붙이는 것이다. 가입·첫 연구, 글·자료, 미팅·조율, 교수 검토, 도우미·대화, 설정·보관까지 비교 범위에 포함한다.

종합 재평가 1~4단계는 기존 진행표에 완료로 기록돼 있다. 5단계는 개선 방향과 대안 설계, 6단계는 실행 계획과 통합 보고서다. 이 인계 시점은 **5단계 진입 전**이다. 별도 AI가 쓴 원문 인계서는 사용자 검토를 5단계, 승인 후 구현을 6단계로 부른다. 저장소 정보 구조(IA) v2의 구현 5단계는 2026-11-19 병합 기록이 있다. 후속 기록에는 어느 단계표를 쓰는지 이름을 붙인다. ## 현재까지 확인한 문제와 추천 순서

| 순서 | 구체적인 장면 | 다음에 확인할 결과 |
|---|---|---|
| 1. 원고 보존과 저장 | 제목·굵기만 바꾼 원고를 복원하자 직전 상태가 이력에서 빠졌다. 마지막 버전 기록에 오류를 넣으면 화면과 저장본이 갈렸다. 본문 저장 중 `나만 보기`로 바꿨더니 화면만 바뀐 채 공유 상태가 남는 사례도 있었다. | 편집본·복원본 각각의 제목과 서식이 남고, 재시도와 새로고침 뒤에도 저장 상태가 일치한다. |
| 2. 기록과 할 일의 연결 | 가상 미팅에서 만든 할 일이 같은 미팅을 목록 필터에서 고르자 사라졌다. 필터를 풀면 `직접 추가`로 보였다. 목표만 적은 다음 미팅에는 준비가 없다고 표시했다. | 출처 이름과 필터 결과가 일치한다. 출처 생성, 피드백 연결, 다음 미팅에 가져가기의 결과를 각각 확인한다. |
| 3. 화면 너비와 공통 동작 | 넓은 피드백 목록에서 상태·연결 할 일 수가 사라진다. 320×680에서는 첫 할 일 행의 시작이 698px이다. 좁은 세부 화면에서 단계 라벨과 오디오 눈금이 잘 읽히지 않는다. | 실제 콘텐츠 폭을 바꿔 같은 정보를 읽을 수 있고, 저장·취소·다시 시도·되돌리기로 원래 작업을 이어간다. |
| 4. 교수 검토와 AI 안내 | 지정 교수와 공동편집을 겸하면 공유 중지 뒤에도 편집자로 읽을 수 있다. AI 사용량의 24시간 한도 문구는 현행 서버 규칙과 다르다. 원본으로 돌아갈 때 현재 접근 허용 여부와 위치 표기가 중요하다. | 볼 수 있는 대상·버튼을 누른 결과·다시 열 위치를 보여 준다. 역할 전체의 개편 여부는 후속 과제로 남긴다. |

위 순서는 후속 검토용 제안이다. 환경별 관찰과 09의 정정은 [09 교차 검토](../2026-11-26_09-교차검토_v1/README.md)와 [작업과 검수 목록](02_작업과검수.md)에 있다.

## 후속 AI의 작업 유형별 출발점

- **검토 요청을 받으면** 기준 커밋을 확인하고 요청 범위에 해당하는 화면과 상태를 다시 연다. 코드, 격리 브라우저, 이전 운영 캡처 중 어떤 근거인지 붙인다. 누락된 장면을 먼저 보강하고 원인과 설계안을 기록한다.
- **설계 요청을 받으면** 사용자 결정 및 현재 앱의 동작을 확인한다. 같은 가상 연구로 역할, 첫 진입, 성공, 실패, 나가기, 다시 열기를 비교한다. 실제로 차이를 확인한 대안을 제안하고 추가 사용자 결정이 필요한 경우 한두 가지로 좁힌다.
- **구현 요청을 받으면** 최신 `main`의 같은 경로를 먼저 재현한다. 별도 브랜치에서 요청된 단위의 공통 원인을 고치고 기존 데이터와 호출 경로를 확인한다. 수정 전후 화면, 저장 값과 검사를 같이 남긴다. 커밋·푸시·배포는 각각 해당 요청 범위에서 진행한다. 저장소 작업 지침 (`../../../Margin-repo/AGENTS.md`, 저장소에 없음) · 작업 가이드 (`../../../Margin-repo/docs/working-guide.md`, 저장소에 없음)

## 인계 기준

마진의 시각 기준은 Montage 토큰이다. 구조는 토스 공식 홈페이지의 소개, 토스증권의 설정·오른쪽 작업판, 라이너의 출처 탐색, 매니패스트의 답변 뒤 선택 흐름을 참고한다. 캡처의 동작, 설치 라이브러리 기본값, 앱에서의 실제 연결을 대조해 결정한다. 사용자 테스트 결과로 기록된 바가 없는 시안은 설계 가설로 둔다.

테스트 계정과 가상 자료로 필요한 조작을 할 수 있다. 결제는 제외한다. 새 로그인은 로그인 탭을 열고 사용자가 입력한다. 외부 전송·운영 변경·영구 삭제는 해당 작업에 대한 별도 요청과 영향을 확인한다. 기존 증거와 원문 보존을 위해 결과는 날짜와 버전을 붙여 저장한다.

같은 컴퓨터의 다음 AI에는 이 경로와 저장소 경로를 주면 된다. 다른 환경으로 옮길 때는 `margin-re-evaluation/`의 상대 위치를 유지해 자료를 전달하고 마진 저장소를 같은 커밋에서 준비한다. 참조 사이트의 로그인 세션이나 운영 키 없이 격리 재현을 실행할 수 있다.
