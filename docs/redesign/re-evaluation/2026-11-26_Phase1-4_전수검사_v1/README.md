## 결론

Phase 1~4는 큰 줄기(제품 지도, 화면 기록, 평가, 원인 묶음)는 갖췄다. 하지만 세 종류의 문제가 있다.

1. **사용자가 정하지 않은 것이 결정처럼 적혀 있다.** Phase 5 초안이 "검토"를 "확정"으로 올렸고, AI가 만든 해법을 "절대 준수" 전제에 섞었다.
2. **원인 분석 일부가 근거와 반대다.** RC-3·RC-6의 근거가 코드와 다르고, RC-2·RC-7·RC-8은 같은 코드 경로를 보이지 않은 채 묶었다.
3. **캡처 수집에 빈칸과 오기가 있다.** 이름과 내용이 다른 캡처가 있고, 실행계획이 요구한 360px·125% 확대·영상은 0건이다. 캡처를 다시 보니 문서에 없는 결함이 79건(A 49, B 30) 나왔다.

이 상태로 Phase 5에 들어가면 틀린 원인 위에 대안을 세우게 된다. 아래 6절의 정리를 먼저 하길 권한다.
