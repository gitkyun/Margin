1. **원본을 고치지 않는다.** 결과물 폴더 `2026-11-26_Phase5_보강_v1/` 밖의 파일은 읽기만 한다. 원본을 바꿔야 할 것 같으면 질문에 적는다.
2. `Margin-repo`에서 파일 수정, `git commit`, `git push`, 배포, 패키지 설치를 하지 않는다.
3. 운영 사이트에 로그인하거나 데이터를 바꾸지 않는다.
4. 결함·수치·결정·출처를 **지어내지 않는다.** 문서에 없는 문제는 판정표에 넣지 않는다. 직접 봤으면 '새 관찰'로 표시한다.
5. `assets/benchmarks/` 캡처는 쓰지 않는다. 개인정보(실명·이메일·IP)가 찍혀 있다.
6. 아래 캡처는 **증거로 쓰지 않는다**(이름과 내용이 다르거나 중복):

## 5. 결과물 규칙

- **폴더**: 모든 결과물은 `2026-11-26_Phase5_보강_v1/` 아래 카드가 정한 경로에만 만든다.
- **파일 이름**: 카드에 적힌 이름 그대로 쓴다. 바꾸지 않는다.
- **경로 표기**: 문서·데이터 안의 파일 경로는 모두 **자료 루트 기준 상대 경로**로 쓴다(예: `assets/live-desktop/30_review_detail_1440.png`). 절대 경로는 쓰지 않는다.
- **표 형식**: TSV는 탭으로 구분하고, 첫 줄은 카드에 적힌 열 이름 그대로 쓴다. 칸 안에 탭이나 줄바꿈을 넣지 않는다. 여러 값은 ` · `(가운데점)으로 잇는다.
- **화면 문구**: 해요체 한국어로 쓴다("저장했어요", "고칠 수 있어요"). 명령형("확인하세요")은 쓰지 않는다. 영어 버튼 이름은 쓰지 않는다.

### 7-3. 장면 주소(#) — 비교 페이지가 시안의 특정 장면을 열 때 쓴다

- 장면마다 `<section class="scene" id="NN-장면이름">`을 둔다. `NN`은 시안 번호 두 자리, 장면 이름은 영어 소문자와 `-`만 쓴다(예: `02-share-stop`).
- 탭으로 장면을 바꾸는 시안이면 `</body>` 바로 위에 아래 스크립트를 **그대로** 넣는다. 탭 버튼에는 `data-scene="장면 id"`를 단다.

```html
<script>
(function () {
  function show(id) {
    var target = document.getElementById(id);
    if (!target || !target.classList.contains('scene')) return;
    document.querySelectorAll('section.scene').forEach(function (s) { s.classList.toggle('on', s === target); });
    document.querySelectorAll('[data-scene]').forEach(function (b) { b.setAttribute('aria-selected', String(b.dataset.scene === id)); });
    target.scrollIntoView({ block: 'start' });
  }
  document.querySelectorAll('[data-scene]').forEach(function (b) {
    b.addEventListener('click', function () { history.replaceState(null, '', '#' + b.dataset.scene); show(b.dataset.scene); });
  });
  window.addEventListener('hashchange', function () { show(location.hash.slice(1)); });
  if (location.hash) show(location.hash.slice(1));
})();
</script>
```

- 모든 장면을 한 페이지에 세로로 늘어놓는 시안이면 `section.scene`에 `on` 클래스를 모두 붙여 두고 위 스크립트를 그대로 넣는다. 그러면 해당 장면으로 스크롤만 된다.
- 필요한 CSS: `section.scene { display: none; } section.scene.on { display: block; }`. 세로 나열형이면 모두 `on`이다.

### 7-4. 사용성 최소 기준

- 375px 폭에서 가로 스크롤이 없어야 한다(`document.documentElement.scrollWidth <= innerWidth`).
- 버튼과 입력칸 높이는 32px 이상이다.
- 키보드 Tab으로 모든 버튼에 갈 수 있고, 초점 테두리가 보여야 한다.
- 글자와 배경의 대비는 4.5:1 이상이다(위 색 변수를 쓰면 대체로 맞는다).
- 콘솔 오류가 0개여야 한다.
