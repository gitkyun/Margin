# 시각화 카드(T20~T32) 공통 절차

## 한 장면 = 한 화면

`시안배정.tsv`의 한 줄이 장면 하나다. 줄에 있는 칸을 그대로 쓴다.

| 칸 | 쓰는 곳 |
|---|---|
| `시안 파일` | 장면을 넣을 파일 (`2026-11-26_Phase5_보강_v1/prototypes/` 안) |
| `장면 id` | `<section class="scene on" id="…">`의 id. **글자 하나도 바꾸지 않는다** |
| `화면 이름` | 장면 제목 `<h2>` |
| `상태` | `확정` / `확정+제안` / `제안` (아래 '제안 표시' 참고) |
| `지금(전)` | 장면 설명의 '지금:' 문장 |
| `바뀐 뒤(후)` | **그릴 내용**. 이 문장에 없는 것은 그리지 않는다 |
| `지금 캡처` | 지금 화면 사진. 열어 보고 배치·글자를 참고한다. `없음`이면 `01-product-map.md`와 같은 구역의 다른 캡처를 참고한다 |

## 장면 하나의 모양

```html
<section class="scene on" id="06-pub-02">
  <h2>기능 둘러보기</h2>
  <p class="desc">지금: (지금(전) 문장) 바뀐 점: (바뀐 뒤 문장을 줄인 것)</p>
  <div class="mock"> … 바뀐 뒤 화면 모형 … </div>
</section>
```

- **세로 나열형**이다. 모든 장면에 `on`을 붙인다. 탭 막대는 만들지 않는다.
- 모형(`.mock`)은 그 화면의 **바뀌는 부분이 보이는 만큼만** 그린다. 화면 전체를 다시 그릴 필요는 없다. 예를 들어 버튼 이름이 바뀌면 그 버튼이 있는 메뉴나 머리 줄만 그린다.
- 모양은 `01-home-rail-assistant_v2.html`과 `04-settings-and-modals_v2.html`의 상단 줄·카드·버튼·입력칸을 참고해 단순하게 그린다. 그림 파일은 쓰지 않고 HTML·CSS로만 그린다.
- '지금/바뀐 뒤' 전환 버튼은 **만들지 않아도 된다**. 비교 페이지가 왼쪽에 지금 캡처를 보여 준다.

## 제안 표시 (가장 중요)

- `바뀐 뒤(후)`가 `제안:`으로 시작하면 → 장면 제목 옆에 `<span class="proposal">제안</span>`.
- 중간에 `제안:`이 있으면(`확정+제안`) → `제안:` **앞** 내용은 표시 없이 그리고, **뒤** 내용을 그린 요소 옆에 `제안` 표시.
- `확정`이면 → 표시 없음.
- 문장에 없는 수치(초, px, 개수), 색, 동작을 새로 넣지 않는다. 그려야 하는데 문장에 없으면 그 요소에 `제안`을 붙이고 보고서 '결정이 아닌데 넣은 것'에 적는다.
- 판정이 `제거`인 부분은 빠진 모습으로 그리고, 설명에 무엇을 뺐는지 쓴다.

## 파일 뼈대 (각 파일의 첫 카드가 만든다)

1. `00_공통지침.md` 7-1 색 블록을 `<style>` 맨 앞에 그대로 붙인다. 이어서 `section.scene { display: none; } section.scene.on { display: block; }`를 넣는다.
2. 7-2 머리. h1은 `시안 NN · (카드 README 표의 '화면' 칸)`. 예: `시안 06 · 공개·온보딩`. 'v2'는 붙이지 않는다.
3. 7-3 장면 주소 스크립트를 `</body>` 바로 위에 그대로 넣는다.
4. 제목 단계: h1 → h2(장면) → h3(모형 안 카드 제목). h4를 쓰려면 h3 아래에서만 쓴다.
5. 숫자로 시작하는 id는 `querySelector('#06-…')`로 고를 수 없다. 스크립트에서는 `getElementById`를 쓴다.

같은 파일의 다음 카드는 **마지막 장면 뒤, 스크립트 앞**에 장면을 덧붙인다. 앞 카드의 장면은 고치지 않는다.

## 카드마다 할 일

1. `시안배정.tsv`에서 `카드` 칸이 내 카드인 줄을 모두 찾는다(카드 파일에도 목록이 있다).
2. 줄마다 `지금 캡처`를 열어 보고 장면을 만든다.
3. 검사한다(자료 루트에서).
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 시안 Txx
   ```
   마지막 줄이 `통과`가 아니면 고친다. `경고:`는 모두 보고서에 붙인다. 같은 파일의 뒤 카드 장면이 아직 없다는 경고는 나오지 않는다. 대신 앞 카드 장면이 빠졌으면 실패가 난다.
4. 장면목록 줄 준비: 장면마다 `시안 파일 ⇥ 장면 id ⇥ 화면 이름 ⇥ — ⇥ 새 시안(2단계)`. 혼자 일하면 `prototypes/장면목록.tsv`에 바로 덧붙인다. 여럿이 동시에 일하면 보고서 '장면목록 줄' 칸에 적는다. 이 경우 `시안 Txx` 검사가 장면목록 줄이 없다고 실패한다. 그 실패만 남았으면 보고서에 그렇게 적고 끝낸다.
5. 브라우저가 있으면 `파일#장면id`로 열어 본다. 콘솔 오류 0, 375px 가로 스크롤 없음, 다크 모드 글자가 읽히는지 확인한다. 없으면 '못 한 것'에 "브라우저 없음"이라고 적는다(오케스트레이터가 확인한다).
6. 보고서 `2026-11-26_Phase5_보강_v1/보고/Txx_보고.md`를 공통지침 9절 양식으로 쓴다. 맨 끝에 `## 장면목록 줄` 칸을 더한다.

## 하지 말 것

- `시안배정.tsv`, `검사.py`, 지시서, 다른 시안 파일(01~05)을 고치지 않는다.
- 장면 id를 바꾸거나 장면을 합치지 않는다. 화면 하나에 장면 하나다.
- `바뀐 뒤(후)` 문장에 없는 기능을 그리지 않는다.
- 실제 사람 이름·이메일, 외부 폰트·CDN·이미지, 이전 토스 색을 쓰지 않는다.
- 가상 데이터는 공통지침과 같다: 연구 `대학원생 연구 기록 경험`, 학생 `김학생`, 교수 `지도교수`, 공동연구자 `이연구`.
