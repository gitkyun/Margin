# T33 비교 데이터 연결과 최종 검사

- **먼저 끝나야 하는 카드**: T20~T32 전부
- **목적**: 새 장면 62개를 비교 페이지에 연결하고 전체를 다시 검사한다. **새 장면을 그리지 않는다.**

## 단계

1. (여럿이 동시에 일했으면) T20~T32 보고서의 `## 장면목록 줄`을 모아 `2026-11-26_Phase5_보강_v1/prototypes/장면목록.tsv` 끝에 덧붙인다. 카드 번호 순서대로, 줄마다 칸 5개(탭으로 구분). 이미 들어 있는 줄은 다시 넣지 않는다.
2. 시안 파일별 마지막 카드 검사를 돌려 모두 `통과`인지 본다.
   ```bash
   cd "/Users/kyun/Downloads/스튜디오26-2/신정훈 교수님/문서_정리/margin-re-evaluation"
   for c in T21 T23 T26 T29 T31 T32; do python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 시안 $c | tail -1; done
   ```
3. 비교 데이터를 **도구로** 연결한다. `compare-items.js`를 손으로 고치지 않는다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 시안연결
   ```
   `연결했어요: 62개`와 `통과`가 나와야 한다.
4. 전체 검사.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 전체
   ```
   출력에 `시안 연결 107개`가 있어야 한다(108개 중 REV-03만 시안 없음).
5. 결과 `2026-11-26_Phase5_보강_v1/README.md`의 '열어 볼 것'에서 숫자를 고친다: 시안 5개 → 11개, 장면 32 → 94, 시안 연결 45 → 107.
