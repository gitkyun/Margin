2026-11-26 · 작성: Claude(오케스트레이터) · 받는 쪽: 작업을 맡을 다른 AI(이하 **작업자**)

## 이 문서 묶음이 하는 일

마진(Margin) 재평가 Phase 5에서 확정한 설계(쟁점 1~8, 모두 대안 A)를 보강한다. 결과물은 세 가지다.

1. **전체 화면 판정표**: 제품의 모든 화면·모달·메뉴를 6기준(유지·보완·통합·제거·재설계·추가)으로 판정한 표
2. **시안 v2**: 이전 시안 01·02·04를 확정안과 Montage 색에 맞춰 다시 만들고, 시안 03·05에 장면 주소(`#장면`)를 붙인다
3. **전후 비교 페이지**: 왼쪽에 지금 화면 캡처, 오른쪽에 바뀐 시안을 나란히 놓고 사용자가 항목별로 넘겨 보는 HTML 한 장

작업은 **작업 카드 18장(T00~T17)**으로 나눴다. 한 번에 **카드 한 장만** 한다. 카드를 끝내면 보고서를 쓰고 멈춘다.

## 작업자가 처음 할 일

1. 이 파일을 끝까지 읽는다.
2. [`00_공통지침.md`](00_공통지침.md)를 끝까지 읽는다. 모든 카드에 적용된다.
3. 아래 순서표에서 맡은 카드 파일을 연다. 맡은 카드가 없으면 **T00부터** 순서대로 한다.
4. 카드의 '완료 기준'을 모두 채우고, `보고/` 폴더에 보고서를 쓰고 멈춘다.
