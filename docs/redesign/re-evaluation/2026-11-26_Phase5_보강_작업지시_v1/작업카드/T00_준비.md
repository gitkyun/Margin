## 단계
1. 자료 루트로 이동한다.
   ```bash
   cd "/Users/kyun/Downloads/스튜디오26-2/신정훈 교수님/문서_정리/margin-re-evaluation"
   ```
2. 폴더를 만든다.
   ```bash
   mkdir -p 2026-11-26_Phase5_보강_v1/판정표 2026-11-26_Phase5_보강_v1/prototypes 2026-11-26_Phase5_보강_v1/비교 2026-11-26_Phase5_보강_v1/보고
   ```
3. `2026-11-26_Phase5_보강_v1/README.md`를 만들고 아래 내용만 쓴다.
   ```markdown
   # Phase 5 보강 결과물

   작업 지시: `../2026-11-26_Phase5_보강_작업지시_v1/README.md`
   이 폴더는 작업자 결과물만 둔다. 원본은 다른 폴더에 있다.
   ```
4. 검사를 돌린다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 준비
   ```
5. 마지막 줄이 `통과`인지 본다. 아니면 빠진 입력 파일 이름을 보고서 '질문'에 적고 멈춘다(파일을 만들어 채우지 않는다).
