# T01 화면 목록 뼈대 만들기

- **목적**: 제품의 모든 화면·모달·메뉴·창을 한 줄씩 적은 목록을 만든다. **판정은 하지 않는다.** 이 목록이 T02~T06의 바탕이다.
- **먼저 끝나야 하는 카드**: T00
- **예상 크기**: 15분

## 읽을 것
1. `v2-2026-11-25-corrected/01-product-map.md`의 2절(라우트, 전역 오버레이 쿼리)과 4절(화면별 기능·진입점·세부 인터랙션)
2. `2026-11-26_Phase5_개선설계_v1/README.md`의 2절 매트릭스(빠진 대상이 없는지 대조할 때)

## 만들 것
`2026-11-26_Phase5_보강_v1/판정표/A1_화면목록.tsv`

첫 줄(열 이름)은 정확히 아래와 같다. 탭으로 구분한다.
```
화면ID	구역	화면 이름	경로·진입	종류	보는 역할	출처
```

| 열 | 쓰는 법 |
|---|---|
| 화면ID | `구역코드-두자리번호`. 예: `HOM-01`. 구역 안에서 01부터 차례로 |
| 구역 | 아래 구역표의 이름 중 하나 그대로 |
| 화면 이름 | 사람이 알아볼 이름. 예: `연구 홈`, `완전 삭제 확인 창` |
| 경로·진입 | 라우트(`/r/:researchId`) 또는 여는 방법(`연구 카드 ⋯ 메뉴 > 휴지통으로 옮기기`) |
| 종류 | `페이지`·`탭`·`모달`·`시트`·`팝오버`·`메뉴`·`사이드 창`·`토스트`·`배너` 중 하나 |
| 보는 역할 | `비로그인`·`학생`·`공동연구자`·`지정 교수`·`겸임 교수` 중 해당하는 것을 ` · `로 이음 |
| 출처 | 01 문서의 절 번호. 예: `01 §2-2 H1`, `01 §4-6` |

## 단계
1. 01 문서 2-1절의 공개·인증 라우트를 한 줄씩 넣는다(`/`, `/features`, `/pricing`, `/guide`, `/privacy`, `/login`, `/signup`, `/join`, 404).
2. 2-2절의 로그인 후 라우트(R1, R2, H1, M1, T1, W1, W2, W3, F1, M3/X2, M4)를 넣는다. 한 라우트에 탭이나 보기가 여러 개면(예: R1 `진행 중·완료·보관함·휴지통`, F1 `로드맵·달력`) **각각 한 줄**로 넣는다.
3. 2-3절의 전역 오버레이를 넣는다.
   - `?detail=` 다섯 종류(할 일·피드백·결정·질문·결과): 각 한 줄, 구역 `항목 상세`
   - `?settings=` 열 개 섹션: 각 한 줄. `profile`·`display`·`notifications`·`assistant`·`usage`·`shortcuts`는 구역 `설정`(profile만 `계정`), `research`·`people`·`schedule`·`danger`는 구역 `설정`
   - `?panel=` 네 탭(도우미·할 일·기록·자료): 각 한 줄, 구역 `셸`(도우미 탭은 `도우미`)
   - `?new=` 열 종류: 각 한 줄. 구역은 만드는 대상에 맞춘다(미팅류는 `미팅`, `poll`은 `시간 조율`, `doc`·`material`은 `글·자료`, `task`·`feedback`·`result`는 `할 일`, `review`는 `검토`)
4. 4절을 처음부터 끝까지 읽으면서 위에서 안 나온 모달·메뉴·창·토스트·배너를 모두 넣는다.
5. 아래 **반드시 있어야 하는 항목**이 다 들어갔는지 하나씩 확인한다. 없으면 추가한다.

### 반드시 있어야 하는 항목 (빠지면 안 됨)

- 셸: 상단 줄, 오른쪽 레일, 사이드 창(열림·닫힘), 연구 전환기 드롭다운, `+` 만들기 메뉴, 의견(레일 아래), 토스트, 업로드 결과 트레이, 오프라인 배너, 미리보기 안내 배너, 하단 독(모바일)
- 알림·검색: 알림 창, ⌘K 검색 팔레트
- 계정: 계정 메뉴(프로필 버튼), 로그아웃 길게 누르기, 프로필 설정
- 연구 목록: 연구 카드 ⋯ 메뉴, 휴지통으로 옮기기 확인 창(이름 입력), 완전 삭제 확인 창(슬라이더), 휴지통 카드
- 가입·온보딩: 온보딩 1·2·3·4단계와 마지막 검토 화면(각 한 줄), 소개 화면(`intro=1`)
- 홈: 연구 홈, 다음 미팅 카드, 홈 할 일 목록, 연구 흐름 칩, 시작하기 체크리스트
- 미팅: 미팅 목록, 기록 추가 메뉴, 미팅 상세(기록 탭), 결정·질문 탭, 서면 기록, 다음 미팅 미리보기, 피드백·할 일 오른쪽 열
- 녹음: 녹음 패널, 음성 공유 버튼, 전사 보기, 오디오 클립(피드백 상세 안)
- 할 일: 할 일 목록, 피드백 목록, 할 일 행 ⋯/우클릭 메뉴, 모바일 스와이프, 완료 되돌리기 토스트
- 글·자료: 글·자료 목록, 폴더, 행 메뉴(⋯·우클릭), 파일 추가 창, 새 글 창, 미리보기 열린 목록
- 원고: 원고 편집기, 버전 메뉴, 버전 비교, 충돌 창, 수정 제안받기, 여백 할 일
- PDF·자료: PDF 상세, 새 버전 올리기 창, 텍스트 보기
- 검토: 검토 상세(학생), 검토 상세(지정 교수 단독), 공유 설정 창, 공유 중지 확인(슬라이더), 다시 확인 요청, 응답 변경 이력, 핀 찍기 모드, 댓글
- 도우미: 대화, 제안 탭, 실행 내역 탭, 대화 기록 메뉴, `/` 명령 메뉴, 시작 카드, 크레딧 표시
- 시간 조율: 시간 조율 만들기 창, 시간 조율 응답 화면

## 하지 말 것
- 판정·문제·개선안을 적지 않는다(T02~T06의 일).
- 01 문서에 없는 화면을 상상해서 넣지 않는다. 위 '반드시 있어야 하는 항목'은 01 문서와 캡처에 있는 것들이다.
