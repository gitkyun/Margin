# T02 판정 1: 공개·가입·온보딩·연구 목록·공통 셸·알림·검색

- **목적**: 아래 구역의 모든 화면을 6기준으로 판정한다.
- **먼저 끝나야 하는 카드**: T01
- **절차**: [판정_공통절차.md](판정_공통절차.md)를 먼저 끝까지 읽고 그대로 따른다.

## 맡은 구역
공개(PUB), 가입·온보딩(ONB), 연구 목록(HUB), 셸(SHL), 알림·검색(SRC)

## 이 구역에서 찾을 ID (모두 어느 한 줄에는 들어가야 한다)
- `D17`, `결정:휴지통`, `RC-4`, `A-N10`, `09-14`, `B-23`, `09-12`, `A-N24`(점·배지 의미, 셸 상단 `미팅` 탭 빨간 점)
- `P02-3`(연구 전환기), `A-N48`(개인정보 안내와 기능 소개의 전사 문구)
- 쟁점 6(완전 삭제 확인 창), 쟁점 7(의견 수집, 현재 `mailto:`)
- 온보딩: `08-#6`, `08-#7`(통합 결함목록 5절의 정정을 함께 읽는다)
- 전 화면 공통 표기: `A-N7`(같은 동작의 이름이 진입점마다 다름), `A-N8`(필수·선택 표시 5가지), `A-N9`(날짜 표기 형식 여러 가지). 특정 화면 하나의 문제가 아니므로 **셸 구역(SHL)의 첫 줄**에 넣고, 메모에 `전 화면 공통`이라고 적는다. 판정 `보완`, 바뀐 뒤는 `제안: 동작 이름·필수 표시·날짜 형식을 한 가지 규칙으로 맞춰요`(규칙 내용은 사용자가 정하지 않았으므로 `제안:`).

## 이 구역에서 특히 주의할 것
- 오른쪽 레일과 D17 사이드 창 기본 열림은 **유지**다. 레일의 활성 표시 보강 같은 것은 `제안:`이다.
- 휴지통 이동은 확정(버튼 + 되돌리기). 되돌리기 시간은 쓰지 않거나 `제안: 6초`로 쓴다.
- 소개 페이지는 결정상 토스 공식 홈페이지가 주 기준이다. 판정 `보완`, 바뀐 뒤는 Phase 5 README 2절 '공개 > 소개 페이지' 행을 그대로 쓴다.
- 의견 창(쟁점 7)은 판정 `재설계`, 바뀐 뒤는 공통지침 2-2 쟁점 7 문장을 줄여 쓴다.
