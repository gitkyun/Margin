# T03 판정 2: 홈·연구 흐름·할 일·항목 상세

- **목적**: 아래 구역의 모든 화면을 6기준으로 판정한다.
- **먼저 끝나야 하는 카드**: T01
- **절차**: [판정_공통절차.md](판정_공통절차.md)를 먼저 끝까지 읽고 그대로 따른다.

## 맡은 구역
홈(HOM), 연구 흐름(FLW), 할 일(TSK), 항목 상세(DET)

## 이 구역에서 찾을 ID (모두 어느 한 줄에는 들어가야 한다)
- `09-4`, `E-5`(다음 미팅 요약), `09-11`(320px 첫 할 일), `A-N4`(지난 단계 '예정'), `B-2`(넓은 화면 4단계 잘림)
- `09-3`, `E-4`(할 일 출처·필터), `09-21`, `E-6`(완료 취소 상태), `09-2`(넓은 피드백 행), `09-7`(상세 단계명), `A-N5`·`B-27`(홈 '공동연구자 2명' 칩. 결함목록에서 두 ID가 한 줄이므로 같은 칸에 함께 적는다)
- `09-20`(결정·질문 상세 본문이 읽기 전용이고 질문 배지가 미해결 수만 셈. 항목 상세 구역)
- `RC-7`(홈 정렬), `RC-10`, 쟁점 2, 쟁점 3, `결정:완료취소`

## 이 구역에서 특히 주의할 것
- 홈 할 일 **정렬 규칙은 바꾸지 않는다**(확정안 쟁점 3). 바뀌는 것은 첫 묶음 제목이다.
- 완료 취소는 결정이 '직전 상태'다. 바뀐 뒤: `완료 전 상태를 저장해 두고, 어느 화면에서 풀어도 그 상태로 돌아가요`.
- 할 일 출처 칩 문구는 공통지침 2-2 쟁점 2를 그대로 쓴다(`제5차 논문 지도에서`, `→ 제6차`, `비공개 기록에서`).
