# T05 판정 4: 글·자료·원고·PDF

- **목적**: 아래 구역의 모든 화면을 6기준으로 판정한다.
- **먼저 끝나야 하는 카드**: T01
- **절차**: [판정_공통절차.md](판정_공통절차.md)를 먼저 끝까지 읽고 그대로 따른다.

## 맡은 구역
글·자료(DOC), 원고(WRT), PDF·자료(MAT)

## 이 구역에서 찾을 ID (모두 어느 한 줄에는 들어가야 한다)
- `09-1`, `E-1`, `E-2`, `E-3`, `09-18`, `09-19`(원고 저장·복원·충돌·공개 범위), `RC-9`, 쟁점 1
- `A-N3`(목록 버전 열 '—'), `E-8`(폴더로 끌어 옮기기 코드 없음), `09-23`(보관 아이콘·다운로드 중복·텍스트 보기 표), `09-15`(파일 없이 제출), `09-17`(다시 시도 구분)
- `09-16`(수정 제안받기 이름, 쟁점 5와 공유), `B-20`(편집자에게 폴더 안 비공개 글 수가 보임, 폴더 화면 줄), `P09-1`(미리보기 중 열 숨김, 사용자 결정 '재검토')

## 이 구역에서 특히 주의할 것
- 원고 관련 줄은 대부분 판정 `재설계`, 쟁점 `1`이다. 바뀐 뒤 문장은 공통지침 2-2 쟁점 1을 화면에 맞게 나눠 쓴다(복원 화면에는 복원 문장, 충돌 창에는 충돌 문장).
- `E-8`은 동작을 확인하지 않은 코드 관찰이다. 근거 등급 `코드`, 바뀐 뒤는 `제안: 동작을 먼저 확인하고, 없으면 끌어 옮기기를 넣거나 안내 문구를 빼요`.
- 미리보기 중 열 숨김(`P09-1`)은 사용자 결정이 '재검토'일 뿐 확정안이 없다. 바뀐 뒤는 `제안:`으로 시작한다.
