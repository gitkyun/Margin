# T06 판정 5: 검토·도우미·설정·계정

- **목적**: 아래 구역의 모든 화면을 6기준으로 판정한다.
- **먼저 끝나야 하는 카드**: T01
- **절차**: [판정_공통절차.md](판정_공통절차.md)를 먼저 끝까지 읽고 그대로 따른다.

## 맡은 구역
검토(REV), 도우미(AST), 설정(SET), 계정(ACC)

## 이 구역에서 찾을 ID (모두 어느 한 줄에는 들어가야 한다)
- 검토: `A-N1`(상태 안내 띠 모순), `09-13`(삭제 댓글·핀), `09-24`, `RC-1`, 쟁점 4, `결정:공유중지`
- 협업: `B-19`(편집자의 연구 정보 수정), `B-11`(교수 화면 시험 데이터), `결정:연구정보`
- 도우미: `RC-5`, `RC-6`, `A-N13`(PDF 상세 맥락 칩), `E-7`(24시간 한도 문구), `A-N33`, `B-21`(사용량 수치·원가), 쟁점 5, `결정:크레딧%`
- 설정·계정: `A-N31`(탭 이름과 본문 제목), `A-N6`(같은 필드를 `연구 목적`·`연구 방향`으로 따로 부름. 설정 연구 정보 줄), `08-#1`~`08-#5`(설정 관련 미세 결함), 쟁점 8, `결정:계정`

## 이 구역에서 특히 주의할 것
- 겸임 교수 관련 줄은 학생 화면과 교수 화면을 **따로 한 줄씩** 판정한다(A1 목록에 둘 다 있다).
- `B-11`은 제품 결함이 아니라 시험 데이터 정리 문제다. 판정 `보완`, 바뀐 뒤 `운영 교수 계정의 시험 데이터를 정리해요(제품 수정 아님)`, 메모에 같은 뜻을 적는다.
- 계정(쟁점 8)은 '설계만' 결정이다. 판정 `추가` 또는 `재설계`, 바뀐 뒤는 공통지침 2-2 쟁점 8 문장을 화면별로 나눠 쓴다.
- `08-#5`의 원래 주장 중 '레거시 단축키'는 틀렸다(통합 결함목록 5절). 그 부분을 근거로 쓰지 않는다.
