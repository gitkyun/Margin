# T07 판정표 합치기와 자동 검사

- **목적**: T02~T06의 판정 파일 다섯 개를 한 표로 합치고, 빠진 화면·빠진 결함 ID가 없는지 검사한다.
- **먼저 끝나야 하는 카드**: T02, T03, T04, T05, T06 (다섯 개 모두)
- **예상 크기**: 10분

## 읽을 것
- `2026-11-26_Phase5_보강_v1/판정표/` 안의 `A1_화면목록.tsv`, `판정_T02.tsv` ~ `판정_T06.tsv`
- T02~T06 보고서의 '질문'과 '못 한 것'

## 만들 것
- `2026-11-26_Phase5_보강_v1/판정표/전체_판정표.tsv` (도구가 만든다)
- `2026-11-26_Phase5_보강_v1/판정표/전체_판정표.md` (도구가 만든다)
- `2026-11-26_Phase5_보강_v1/판정표/요약.md` (내가 쓴다)

## 단계
1. 합치기 도구를 돌린다. 손으로 복사해 붙이지 않는다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 합치기
   ```
2. 전체 검사를 돌린다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 판정표
   ```
3. 검사가 '빠진 화면ID'나 '어디에도 없는 결함 ID'를 알려 주면:
   - 빠진 화면ID → 그 구역을 맡은 판정 파일(T02~T06)에 줄을 추가한다(판정 공통절차를 그대로 따른다). 그다음 1단계부터 다시 한다.
   - 어디에도 없는 결함 ID → 그 결함이 어느 화면의 것인지 통합 결함목록에서 읽고, 해당 구역 판정 파일의 가장 가까운 줄 `문제 ID`에 추가한다. 1단계부터 다시 한다.
   - 판단이 안 되면 고치지 말고 보고서 질문에 적는다.
4. `요약.md`를 아래 양식으로 쓴다(숫자는 `전체_판정표.tsv`에서 센다).
   ```markdown
   # 전체 판정표 요약

   - 화면 수: N
   - 판정별: 유지 n · 보완 n · 통합 n · 제거 n · 재설계 n · 추가 n (두 판정이 붙은 줄은 둘 다 셈)
   - 쟁점별 화면 수: 1 n · 2 n · 3 n · 4 n · 5 n · 6 n · 7 n · 8 n
   - '제안:'으로 시작하는 바뀐 뒤: n줄
   - 캡처 없음: n줄 (화면ID 나열)
   - 새 관찰 메모: n줄 (화면ID 나열)
   ```

## 하지 말 것
- 판정이나 문장을 '더 낫게' 고치지 않는다. 검사가 지적한 것만 고친다.
