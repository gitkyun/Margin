# T08 시안 03·05 복사 + 장면 주소

- **목적**: 이미 확정안대로 만든 시안 03·05를 결과 폴더에 복사하고, 비교 페이지가 특정 장면을 열 수 있게 장면 주소(`#05-restore` 등)를 붙인다. 내용은 바꾸지 않는다.
- **먼저 끝나야 하는 카드**: T00
- **예상 크기**: 10분

## 읽을 것
- 공통지침 7절(특히 7-3 장면 주소)
- 원본: `2026-11-26_Phase5_개선설계_v1/prototypes/05-data-integrity.html`, `03-review-role-boundary.html`

## 만들 것
- `2026-11-26_Phase5_보강_v1/prototypes/05-data-integrity_v2.html`
- `2026-11-26_Phase5_보강_v1/prototypes/03-review-role-boundary_v2.html`
- `2026-11-26_Phase5_보강_v1/prototypes/장면목록.tsv` (새로 만들고, 이후 시안 카드가 줄을 덧붙인다)

`장면목록.tsv`의 첫 줄:
```
시안 파일	장면 id	보여 주는 것	쟁점	원본과 달라진 점
```

## 단계
1. 두 원본을 위 이름으로 복사한다(`cp`). 원본은 건드리지 않는다.
2. **05 v2**: 여섯 장면의 `id`를 아래처럼 바꾼다. 탭 버튼의 `data-scene` 값도 같이 바꾼다. 파일 안의 다른 곳(JS의 `getElementById('restore')` 같은 것)도 모두 찾아 바꾼다.

   | 지금 id | 바꿀 id |
   |---|---|
   | `restore` | `05-restore` |
   | `conflict` | `05-conflict` |
   | `visibility` | `05-visibility` |
   | `source` | `05-source` |
   | `next` | `05-next` |
   | `undo` | `05-undo` |

   그다음 공통지침 7-3의 장면 주소 스크립트를 `</body>` 바로 위에 넣는다. 05에는 이미 탭 전환 코드가 있다. 그 코드가 장면을 바꿀 때 주소도 바뀌도록, 기존 탭 클릭 코드 안에 `history.replaceState(null, '', '#' + t.dataset.scene);` 한 줄을 넣는다.
   - **주의**: 기존 JS는 `document.getElementById('restore')` 식으로 장면을 찾는다. id를 바꾼 뒤 `grep -n "getElementById('" 05-data-integrity_v2.html`로 모든 호출을 확인한다. 장면 id만 바꾸고 `r-go`, `c-mine` 같은 내부 요소 id는 바꾸지 않는다.
3. **03 v2**: 화면을 두 장면으로 감싼다.
   - 검토 상세 카드(`<section class="card" aria-label="검토 상세">`)에 `class="card scene on" id="03-review"`
   - 연구 정보 카드(`aria-label="연구 정보 설정"`)에 `class="card scene on" id="03-research-info"`
   - 두 장면 모두 늘 보이는 세로 나열형이다. 공통지침 7-3 스크립트를 넣는다. CSS의 `section.scene { display:none }`는 **넣지 않는다**(둘 다 보여야 함).
4. 두 파일의 `<h1>` 앞에 `v2`를 붙인다(`시안 05 v2 · …`).
5. `장면목록.tsv`에 여덟 줄을 쓴다(05 여섯 + 03 둘). '원본과 달라진 점'은 `장면 주소만 추가`라고 쓴다.
6. 검사한다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 시안 T08
   ```
7. 브라우저 도구가 있으면 `05-data-integrity_v2.html#05-undo`를 열어 '완료 풀기' 장면이 바로 보이는지, `03-review-role-boundary_v2.html#03-research-info`가 연구 정보 카드로 스크롤되는지 확인한다. 각 장면에서 버튼 하나씩 눌러 결과가 원본과 같은지 본다.

## 하지 말 것
- 문구·색·동작을 바꾸지 않는다. id와 주소 스크립트만 바꾼다.
