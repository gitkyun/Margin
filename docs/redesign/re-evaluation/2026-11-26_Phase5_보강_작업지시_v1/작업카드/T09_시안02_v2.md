| 장면 id | 장면 제목(h2) | 반드시 보여야 하는 것 | 근거 |

| `02-switcher` | 연구 전환기 | 상단 연구 이름을 누르면 열리는 목록. 긴 연구 이름은 **한 줄 말줄임**이고 마우스를 올리면 전체 이름이 보인다(`title` 속성). `모든 연구 보기`는 목록 맨 아래에 고정돼 스크롤해도 보인다. 연구 7개를 넣어 스크롤이 생기게 한다. 전체에 `제안` 표시(확정 쟁점이 아님) | `P02-3`, Phase 5 매트릭스 '연구 전환기' |
| `02-trash-move` | 휴지통으로 옮기기 | 두 진입점을 나란히 둔다: ① 연구 카드 ⋯ 메뉴 > `휴지통으로 옮기기` ② 설정 > 이 연구 > 보관·삭제 > `휴지통으로 옮기기`. 둘 다 **확인 창 없이 버튼 한 번**으로 옮기고, 토스트 `'대학원생 연구 기록 경험'을 휴지통으로 옮겼어요.` + `되돌리기` 버튼을 띄운다. 되돌리기를 누르면 카드가 돌아온다. 토스트 유지 시간 옆에 `제안: 6초` | `결정:휴지통` |
| `02-delete` | 완전 삭제 | 휴지통 탭의 카드 → `완전히 삭제` → 확인 창. 창에는 ① 영향 요약 `미팅 6건 · 원고 3건 · PDF 4개가 영구 삭제돼요. 되돌릴 수 없어요.` ② 연구 이름 표시와 `이름 복사` 버튼 ③ 이름 입력칸 ④ 입력이 이름과 같을 때만 활성화되는 빨간 `완전히 삭제` 버튼 ⑤ `취소`. 이름 비교는 앞뒤 공백을 무시하고 한글을 정규화한다(JS: `a.trim().normalize('NFC') === b.trim().normalize('NFC')`). 입력칸 아래 회색 안내 `연구 이름을 똑같이 적어 주세요.` | 쟁점 6 |
| `02-share-stop` | 검토 공유 중지 | 검토 상세의 `공유 중지` 버튼 → **일반 확인 창**(슬라이더 없음). 창 문구: `검토 공유를 중지할까요?` / `교수님 링크로는 더 볼 수 없어요. 교수님이 공동편집자라면 연구 안에서는 계속 볼 수 있어요. 다시 공유하면 지금 응답은 그대로 남아요.` / 버튼 `취소`, `공유 중지`. 중지 후 배지가 `공유 중지`로 바뀌고 토스트 `공유를 중지했어요.` + `다시 공유` | `결정:공유중지`, 쟁점 4 |
