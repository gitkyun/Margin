## 파일 뼈대 (이 카드에서 만든다)
- **형식: 탭형**(한 번에 한 장면만 보임). 공통지침 7-3 스크립트와 `section.scene { display:none } section.scene.on { display:block }`를 넣는다.
- 페이지 맨 위 머리(공통지침 7-2) 아래에 **장면 막대**를 둔다. 모든 장면으로 가는 버튼이 한 줄로 있고 각 버튼에 `data-scene="장면 id"`가 있다. 이 카드는 자기 장면 버튼만 넣고, T11·T12가 자기 버튼을 덧붙인다.
- 설정 장면은 **설정 창 모양** 안에 그린다: 왼쪽 목록 + 오른쪽 내용. 왼쪽 목록은 두 묶음이다.
  - `내 계정`: 프로필 · 화면 · 알림 · 연구 도우미 · 사용량 · 단축키
  - `이 연구`: 연구 정보 · 함께하는 사람 · 미팅 주기 · 보관·삭제
  - 왼쪽 목록 항목도 `data-scene` 버튼이다(장면이 없는 항목은 `disabled`).
- 첫 화면(주소에 #이 없을 때)은 `04-settings-nav`가 보이게 한다.
