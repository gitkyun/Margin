## 하는 일
T10이 만든 설정 창 안에 계정 장면 넷을 추가한다. 장면 막대와 왼쪽 목록(`내 계정 > 프로필`)에 버튼을 연결한다. 이 넷은 **설계 시안**이다(결정: 계정은 설계만).

## 장면 명세

| 장면 id | 장면 제목(h2) | 반드시 보여야 하는 것 | 근거 |
|---|---|---|---|
| `04-profile` | 프로필 | 표시 이름(편집), 로그인 이메일(읽기 전용), 아래로 이어지는 세 묶음 링크: `로그인 수단`, `데이터 내보내기`, `탈퇴`(각 장면으로 이동하는 `data-scene` 버튼) | 쟁점 8 |
| `04-login-methods` | 로그인 수단 | 가입 방식 전환 `이메일로 가입` / `카카오로 가입` / `LINE으로 가입`. 이메일이면 `비밀번호 바꾸기` 묶음이 보인다. 카카오·LINE이면 비밀번호 묶음 대신 `연결된 로그인: 카카오 · 연결됨`(배지)과 안내 `카카오 계정으로 로그인해요. 비밀번호는 카카오에서 관리해요.`. 연결 해제 버튼은 넣지 않는다(정하지 않음) | 쟁점 8 |
| `04-export` | 데이터 내보내기 | 연구 목록(가상 2개)과 각 줄의 `내려받기 준비` 버튼. 누르면 그 줄이 `준비 중…`(진행 막대) → 2초 뒤 `준비됐어요 · 내려받기` 로 바뀌고 토스트 `내려받을 준비가 됐어요.`. 안내 `기록·원고·자료를 연구별로 묶어요.` 파일 형식(zip 등)은 `제안` 표시 | 쟁점 8 |
| `04-delete-account` | 탈퇴 | 3단계 흐름. ① 안내: `탈퇴하면 7일 뒤 계정과 내 기록이 지워져요. 7일 안에 다시 로그인하면 되돌릴 수 있어요.` ② 내가 소유한 연구마다 선택 `공동연구자에게 넘기기`(받을 사람 선택) / `삭제`. 공동연구자가 없는 연구는 `삭제`만 선택 가능 + 이유 한 줄 ③ 마지막 확인: 이메일 입력 후 빨간 `탈퇴하기`. 완료 화면 `탈퇴를 요청했어요. 12월 3일까지 되돌릴 수 있어요.`(가상 날짜) | 쟁점 8 |

## 계정 메뉴 미니 시안 (`04-profile` 장면 안)
- 오른쪽 위에 작은 계정 메뉴 모형: 이름, 역할 표시(`학생`), `화면: 라이트 · 다크 · 시스템` 3단 선택(04-display와 **같은 모양**), `설정`, `로그아웃`.
- 로그아웃은 **일반 클릭**으로 확인 창을 띄운다(길게 누르기 아님). 이 부분은 결정이 아니므로 `제안` 표시.

## 완료 기준
- [ ] 네 장면이 명세대로 있고 장면 막대·왼쪽 목록에서 열린다
