## 장면 명세

| 장면 id | 장면 제목(h2) | 반드시 보여야 하는 것 | 근거 |
|---|---|---|---|
| `01-assistant-start` | 도우미 첫 화면 | 사이드 창 도우미 탭. 위에 탭 세 개 `대화 · 제안 · 실행 내역`(유지). 빈 대화에 시작 카드 **항상 3개**. '지금 보는 화면' 전환 `홈` / `원고` / `PDF 자료`에 따라 카드가 바뀐다: 맥락 카드(그 화면에 맞는 것) 먼저, 모자라면 일반 예시로 채워 3개. 예) 원고: `이 글에서 고칠 문장 찾기`, `받은 피드백과 이 글 대조하기`, `수정 제안받기`. 카드 문구는 예시이므로 `제안` 표시. 입력창 위 맥락 칩(`학위논문 2장 · 문서`)은 원고·PDF 모두 붙는다 | 쟁점 5, `RC-5`, `A-N13` |
| `01-suggestions` | 제안 정리 | 제안 탭에 제안 카드 6개(가상). 위에 **일괄 정리 막대**: `전체 선택`, `선택한 제안 반영`, `선택한 제안 넘기기`, `오래된 제안 비우기`. 비우기는 토스트 + `되돌리기`. 카드마다 반복되던 안내 문장은 **막대 위 한 번만** `선택한 제안만 기록에 남아요. 선택하지 않은 제안은 나만 볼 수 있어요.` | 쟁점 5, `A-N41` |
| `01-credit` | 크레딧 표시 | 입력창 아래 `남은 양 96%`(막대 포함). 누르거나 마우스를 올리면 작은 창: `남은 양 19,190 · 이번 달 지급 20,000 · 사용 479 · 예약 332` + `월 크레딧 안에서 쓰고, 1분에 6번까지 실행할 수 있어요.` 달러 원가·'토큰' 단어 없음. 기능 이름은 `수정 제안받기` 하나로 쓴다(`문장 점검`, `제안받기` 없음) | `결정:크레딧%`, 쟁점 5, `E-7`, `09-16` |
| `01-feedback` | 의견 보내기 | 레일 아래 `의견` 버튼 → 오른쪽 아래 작은 창(화면 가운데를 가리지 않음). 내용: 1~5점, 유형 칩 `불편해요 · 제안해요 · 오류예요`, 한 줄 입력, 체크박스 `현재 화면 주소와 창 크기 함께 보내기`(기본 꺼짐), `보내기`·`닫기`. 보내기 → `보냈어요. 고마워요.` 토스트. 체크했을 때만 보낼 값 미리보기(`/r/…/docs · 1440×900`)를 보여 준다. 저장 위치는 정하지 않았으니 `제안: 앱 안에 저장` | 쟁점 7 |
