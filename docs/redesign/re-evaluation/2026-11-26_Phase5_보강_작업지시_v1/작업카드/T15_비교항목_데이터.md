# T15 비교 항목 데이터 만들기

- **목적**: 전후 비교 페이지(T16)가 읽을 데이터 파일을 만든다. 판정표에서 '바뀌는' 화면마다 항목 하나다.
- **먼저 끝나야 하는 카드**: T07, T09, T10, T11, T12, T13, T14 (판정표와 시안 장면이 모두 있어야 함)
- **예상 크기**: 20분

## 읽을 것
- `2026-11-26_Phase5_보강_v1/판정표/전체_판정표.tsv`
- `2026-11-26_Phase5_보강_v1/prototypes/장면목록.tsv`

## 만들 것
`2026-11-26_Phase5_보강_v1/비교/compare-items.js`

**주의: JSON 파일이 아니라 JS 파일이다.** 브라우저는 `file://`로 연 페이지에서 `fetch()`로 JSON을 못 읽는다. 그래서 아래 모양으로 쓴다.

```js
window.COMPARE_ITEMS = [
  {
    "id": "CMP-001",
    "screenId": "HOM-02",
    "title": "다음 미팅 카드",
    "area": "홈",
    "issue": [2, 3],
    "verdict": "재설계",
    "problemIds": ["09-4", "E-5", "RC-10"],
    "beforeImage": "assets/live-desktop/14_home_main_1440.png",
    "beforeText": "목표만 적은 다음 미팅이 \"아직 준비한 내용이 없어요\"로 보여요.",
    "afterProto": "01-home-rail-assistant_v2.html#01-home",
    "afterText": "목표를 첫 줄에 보이고 준비 수는 따로 세요.",
    "status": "확정"
  }
];
```

| 필드 | 값 | 어디서 |
|---|---|---|
| `id` | `CMP-001`부터 세 자리 번호. 순서는 판정표 순서 | 직접 |
| `screenId`, `title`, `area` | `전체_판정표.tsv`의 '화면ID', '화면 이름', '구역' 열 그대로 | 판정표('구역' 열은 T07 합치기 도구가 A1 목록에서 붙여 둔 것) |
| `issue` | 쟁점 번호 배열. `—`이면 `[]` | 판정표 '쟁점' |
| `verdict` | 판정 문자열 그대로 | 판정표 '판정' |
| `problemIds` | 문제 ID 배열 | 판정표 '문제 ID'를 ` · `로 나눈 것 |
| `beforeImage` | 판정표 '지금 캡처'. `없음`이면 `null` | 판정표 |
| `beforeText` | 판정표 '지금(전)' | 판정표 |
| `afterProto` | 이 화면을 그린 시안 장면 `파일#장면id`. 없으면 `null` | 장면목록.tsv |
| `afterText` | 판정표 '바뀐 뒤(후)'. 앞의 `제안: `은 **떼어 낸다** | 판정표 |
| `status` | 바뀐 뒤가 `제안: `으로 시작했으면 `"제안"`, 중간에 `제안:`이 들어 있으면 `"확정+제안"`, 없으면 `"확정"` | 판정표 |

## 단계
1. 판정표에서 **판정이 `유지` 하나뿐인 줄은 뺀다.** 나머지 줄을 모두 항목으로 만든다.
2. 줄마다 장면목록.tsv에서 그 화면을 그린 장면을 찾는다. 기준: 장면의 '보여 주는 것'이 그 화면과 같은 대상인지, 쟁점 번호가 겹치는지. 맞는 장면이 없으면 `afterProto: null`. **억지로 맞추지 않는다.**
   - 참고 짝(맞으면 쓴다): 원고 복원 → `05-data-integrity_v2.html#05-restore`, 충돌 창 → `#05-conflict`, 원고 공개 범위 → `#05-visibility`, 할 일 목록 출처·필터 → `#05-source`, 다음 미팅 카드 → `#05-next` 또는 `01-…#01-home`, 완료 되돌리기 → `#05-undo`, 검토 상세 → `03-review-role-boundary_v2.html#03-review`, 설정 연구 정보 → `03-…#03-research-info` 또는 `04-…#04-research-info`, 연구 전환기 → `02-…#02-switcher`, 휴지통 이동 → `#02-trash-move`, 완전 삭제 창 → `#02-delete`, 공유 중지 → `#02-share-stop`
3. 문자열 안의 큰따옴표는 `\"`로 쓴다. 줄바꿈은 넣지 않는다.
4. 검사한다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 비교데이터
   ```
   검사가 '판정표에는 있는데 데이터에 없는 화면'이나 '없는 파일·장면'을 알려 주면 고친다.

## 하지 말 것
- 판정표에 없는 내용을 지어 넣지 않는다. 문장도 판정표 그대로 쓴다.
- `assets/benchmarks/` 이미지나 금지 캡처를 넣지 않는다.
