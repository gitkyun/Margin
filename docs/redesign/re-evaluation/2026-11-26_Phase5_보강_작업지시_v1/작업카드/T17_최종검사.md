# T17 최종 검사

- **목적**: 결과물 전체를 한 번 더 검사하고, 사용자가 볼 첫 페이지를 정리한다. **새 기능을 만들지 않는다.**
- **먼저 끝나야 하는 카드**: T16
- **예상 크기**: 15분

## 단계
1. 자동 검사를 모두 다시 돌리고 결과를 보고서에 붙인다.
   ```bash
   cd "/Users/kyun/Downloads/스튜디오26-2/신정훈 교수님/문서_정리/margin-re-evaluation"
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 전체
   ```
2. 브라우저 확인(도구가 있으면). 아래 표를 보고서에 채운다.

   | 확인 | 방법 | 결과 |
   |---|---|---|
   | 비교 페이지 1440px | `비교/compare.html`을 넓은 창으로 열기 | |
   | 비교 페이지 375px | 좁은 창(또는 모바일 보기) | |
   | 다크 모드 | OS·브라우저를 다크로 바꾸고 다시 열기 | |
   | 시안 장면 주소 | `장면목록.tsv`의 모든 장면을 `파일#장면id`로 열어 바로 보이는지 | 열어 본 수 / 전체 수 |
   | 콘솔 오류 | 비교 페이지와 시안 5개 | |
   | 깨진 이미지 | 비교 페이지에서 항목을 끝까지 넘기며 | 깨진 항목 id |

3. 문제가 있으면 **그 카드의 결과물만** 고친다. 고친 내역을 적는다. 큰 수정(장면을 새로 그려야 함)이 필요하면 고치지 말고 질문에 적는다.
4. `2026-11-26_Phase5_보강_v1/README.md`에 아래를 덧붙인다(숫자는 실제 값).
   ```markdown
   ## 열어 볼 것
   - 전후 비교: `비교/compare.html` (항목 n개, 확정 n · 제안 n)
   - 전체 판정표: `판정표/전체_판정표.md` (화면 n개)
   - 시안: `prototypes/` 5개 (장면 n개, `장면목록.tsv`)

   ## 남은 것
   - (보고서들의 '못 한 것'과 '질문'을 모아서)
   ```
