# 시안 카드(T09~T14) 공통 절차

시안 카드는 이전 시안(원본)을 **복사한 뒤 고쳐** v2를 만든다. 카드 파일과 이 파일을 함께 읽는다.

## 원칙
1. **원본은 읽기만 한다.** `prototypes/01-…`, `02-…`, `04-…`는 고치지 않는다.
2. v2는 새 파일로 만든다. 원본을 복사해 고쳐도 되고 새로 써도 된다. **카드의 '장면 명세'에 있는 것은 모두 있어야 한다.** 원본에 있던 좋은 배치는 살려도 된다.
3. 색·글자·버튼·머리·장면 주소는 공통지침 7절을 그대로 따른다.
4. 화면 글은 공통지침 2절의 확정안 문장을 **그대로 옮긴다.** 표현을 바꾸고 싶으면 뜻이 같아야 하고, 보고서에 적는다.
5. 확정안에 없는 수치·기능을 보여야 하면 그 옆에 `<span class="proposal">제안</span>`을 붙인다.
6. 각 장면 맨 위에 장면 제목(h2)과 한두 줄 설명을 둔다. 설명에는 '지금 문제'와 '바뀐 점'을 쓴다. 예: `지금: 공유 중지에 밀어서 확인하는 슬라이더를 써요. 바뀐 점: 일반 확인 버튼과 결과 안내로 바꿔요.`
7. 가능하면 장면 안에 '지금 동작 / 바뀐 뒤' 전환 버튼을 둔다(05 시안처럼). 어려우면 '바뀐 뒤'만 그려도 된다.
8. 데이터는 가상이다. 연구 이름은 `대학원생 연구 기록 경험`, 학생 `김학생`, 교수 `지도교수`, 공동연구자 `이연구`를 쓴다. 실제 사람 이름·이메일을 쓰지 않는다(`professor@margin.com` 같은 시험 주소는 괜찮다).

## 작업 순서 (카드마다)
1. 카드의 '장면 명세' 표를 읽는다.
2. 원본 시안을 브라우저나 편집기로 열어 해당 부분을 찾는다.
3. v2 파일에 장면을 하나씩 만든다. 장면 하나를 만들 때마다 브라우저로 열어 확인한다.
4. 모든 장면을 만든 뒤 검사를 돌린다.
   ```bash
   python3 -I 2026-11-26_Phase5_보강_작업지시_v1/도구/검사.py 시안 Txx
   ```
   `Txx`에는 **지금 하는 카드 번호**를 쓴다(예: `시안 T10`). 파일 이름을 쓰지 않는다. 도구가 그 카드까지 있어야 할 장면을 알고 있다.
5. 브라우저 확인(도구가 있으면):
   - 장면마다 `파일#장면id`로 열어 그 장면이 바로 보이는지
   - 장면 안의 버튼을 모두 한 번씩 눌러 오류가 없는지(콘솔 오류 0). `검사.py`는 실행 중 오류를 잡지 못한다. 브라우저를 쓸 수 없으면 '못 한 것'에 적고, 카드를 끝냈다고 하지 않는다
   - 숫자로 시작하는 id(`01-feedback` 등)는 `querySelector('#01-…')`로 고를 수 없다. `getElementById` 또는 `[id="01-…"]`를 쓴다
   - 375px 폭에서 가로 스크롤이 없는지
   - 다크 모드(브라우저 또는 OS 설정)에서 글자가 읽히는지
6. `prototypes/장면목록.tsv`에 장면마다 한 줄을 덧붙인다(헤더는 T08이 만들었다). '원본과 달라진 점'은 구체적으로 쓴다. 예: `원본은 공유 중지에 슬라이더 → 일반 확인 버튼 + 결과 토스트`.
7. 보고서를 쓴다. '결정이 아닌데 넣은 것(제안)'에 화면에 `제안` 표시를 붙인 것을 모두 적는다.

## 하지 말 것
- 다른 카드의 장면을 미리 만들지 않는다(같은 파일이면 다음 카드가 덧붙인다).
- 외부 폰트·CDN·이미지를 쓰지 않는다.
- 원본 시안의 토스 색(`#3182f6`, `#191f28`, `#f04452`, `#e8f3ff`, `#4e5968`, `#8b95a1`)을 남기지 않는다.
