## 사용자 결정 (2026-11-25, 채팅)
- 위 표의 '사용자 선택' 칸에 기록했다. 재검토 안건 6개: 교수 겸임 권한(D1), 완전 삭제 확인 방식(이름 입력), 의견 수집(앱 안), 스크롤바 자리 고정, 미리보기 중 열 숨김, 홈 할 일 정렬.
- 새로 정한 방향(Phase 5 검토 기준):
  - **크레딧 표기: 퍼센트(%)**. 검수자는 '잔여/총 + 막대'를 추천했으나 사용자가 %를 골랐다.
  - **휴지통 이동: 두 진입점 모두 버튼 한 번 + 되돌리기 토스트**로 맞춘다.
  - **공유 중지: 슬라이더 대신 일반 확인 버튼** 검토.
- 주의: 완전 삭제를 이름 입력으로 바꾸려면 `AGENTS.md:21` 불변 조건 변경이 함께 필요하고, 이름 비교 정규화(공백·한글 NFC/NFD)와 서버 `confirmationName` 자동 채움도 같이 고쳐야 한다.

## 결정 기록이 없는 것 (재검토가 아니라 새로 정할 것) — 위에서 결정됨
- 크레딧 표기 방식(% / 잔여·총 + 막대 / 숫자). '% 전환이 기획 의도였다'는 기록은 없다.
- 휴지통 이동 확인 방식(연구 카드 = 이름 입력, 설정 = 일반 확인). 둘 중 무엇이 기준인지 정한 기록이 없다.
- 되돌릴 수 있는 `공유 중지`에 슬라이더를 쓰는 것.
